 # Best Practice: Use External Load Balancers with Docker Swarm
Use external load balancers to distribute traffic to Docker Swarm services for improved performance, high availability, and easier scalability.

# Explanation
Docker Swarm allows you to create a swarm of nodes that can run and scale applications. However, Swarm itself does not provide advanced load balancing features. By using an external load balancer, you can distribute network traffic more efficiently, handle increased traffic more effectively, and enable seamless scaling. External load balancers offer more advanced features such as SSL termination, health checks, and session persistence.

# Why It Matters
- External load balancers offer more advanced load balancing features than Docker Swarm, ensuring optimal performance and reliability for your applications.
- Integrating an external load balancer makes it easier to scale your applications as the need arises, without having to manage the load balancer within the Docker environment.
- By using an external load balancer, you can maintain a clean separation of concerns between your applications and the networking infrastructure.

# Example
```
# In your docker-compose.yml file:
version: '3.7'
services:
  web:
    image: my-app:latest
    ports:
      - "80:80"
    networks:
      - swarm
networks:
  swarm:
    driver: overlay

# On your load balancer configuration file:
backend_server {
  server 192.168.0.1:80 max_conns 1000 check healthcheck.php
  server 192.168.0.2:80 max_conns 1000 check healthcheck.php
}

server {
  listen 80;

  location / {
    proxy_pass http://backend_server;
  }
}
```
