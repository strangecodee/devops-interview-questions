 # Use Multi-Stage Builds for Docker Images
Build your Docker images using multi-stage builds to reduce image size and improve security.

# Explanation
Multi-stage builds allow you to build your application in one stage and then copy only the necessary artifacts to a second stage for running the application. This results in smaller image sizes and removes unnecessary files, such as build tools and dependencies. It also enhances security by isolating the build environment from the runtime environment.

# Why It Matters
- Smaller image sizes lead to faster deployment times and reduced network bandwidth usage.
- Reduced attack surface area by removing unused components from the container.
- Separation of build and runtime environments ensures a clean and secure build process.

# Example
```Dockerfile
FROM node:14 as build

WORKDIR /app
COPY package.json yarn.lock .
RUN yarn install

COPY . .
RUN yarn build

FROM nginx:1.19
COPY --from=build /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
