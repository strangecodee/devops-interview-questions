 # Best Practice: Use External Load Balancers with Docker Swarm Mode
Use external load balancers instead of relying on Docker Swarm's built-in load balancing for production workloads to ensure high availability, scalability, and security.

# Explanation
Docker Swarm mode provides a native load balancing feature, which distributes network traffic to services running in a Swarm. However, this built-in load balancer may not provide the required level of resilience, scalability, and security for production workloads. External load balancers offer advanced features like health checks, session persistence, and SSL termination. Moreover, they can be integrated with popular load balancing solutions, providing additional features and better visibility into the traffic flows.

# Why It Matters
- **High Availability**: External load balancers can ensure high availability by automatically detecting and removing failed nodes, thus directing traffic only to healthy nodes.
- **Scalability**: External load balancers can easily handle increased demand by adding additional capacity and distributing traffic accordingly.
- **Security**: External load balancers can offer features like SSL termination, improving security and protecting sensitive data.

# Example
To deploy a Docker application with Swarm mode and an external load balancer, follow these steps:

1. Configure your load balancer (e.g., HAProxy, NGINX, NLB) to listen on the target port of your application (e.g., 80).
2. Build and publish your Docker image using a registry like Docker Hub.
3. Create a `docker-compose.yml` file defining your Swarm services and networking settings.

```yaml
version: "3.8"

networks:
  my_network:
    driver: overlay

services:
  my_service:
    image: my_registry/my_image:latest
    name: my_service
    ports:
      - "80:80"
    networks:
      - my_network
```

4. Start the Swarm manager and worker nodes.

```bash
docker swarm init --advertise-addr <manager_ip_address>
docker swarm join --token <swarm_token> <manager_ip_address>:<swarm_port>
```

5. Deploy your service using `docker stack deploy`.

```bash
docker stack deploy --compose-file docker-compose.yml my_app
```

6. Configure your load balancer to forward traffic to the Swarm nodes. You can find the Swarm nodes' IP addresses by running `docker node ls` on the Swarm manager.

7. Start the load balancer and test your application by accessing it through the load balancer's IP address.
