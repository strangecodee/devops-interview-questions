 # Best Practice: Keep Your Base Images Lean and Up-to-date
<Use a minimal base image to reduce attack surface area and improve build and run time>

# Explanation
Maintaining lean and up-to-date base images is an essential best practice in Docker. Using a minimal base image helps reduce the attack surface area by limiting the number of unused packages and services. Moreover, it improves build and run time by reducing the image size and dependencies. Keeping base images up-to-date ensures that you use the latest security patches and bug fixes.

# Why It Matters
- Reducing attack surface area by minimizing the number of unused packages and services
- Improving build and run time by reducing image size and dependencies
- Ensuring the use of the latest security patches and bug fixes

# Example
```Dockerfile
FROM alpine:latest as base

# Application code goes here

# Use multi-stage build to keep the runtime image lean
FROM alpine:latest
RUN apk update && \
    apk add --no-cache <dependencies> && \
    cp -R <source> /app && \
    chdir /app && \
    run <build-command>
```

# Example (Using multi-stage build)
```Bash
# Build stage
$ docker build -t myapp . --no-cache

# Runtime stage
$ docker run --rm myapp:latest <run-command>
```
