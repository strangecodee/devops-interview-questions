 # Use Multi-Stage Builds to Reduce Image Size
Build Docker images using multi-stage builds to minimize image size and improve security by separating build tools from runtime dependencies.

# Explanation
Using multi-stage builds in Docker allows you to create multiple build stages, each with its own set of dependencies and tools. In the final stage, only the application and its required dependencies are copied into the output image. This approach reduces image size and eliminates unnecessary build tools and libraries.

# Why It Matters
- Smaller image size leads to faster build times and less bandwidth usage.
- Reducing image size also makes it easier to manage and distribute images, especially in a large-scale environment.
- Keeping build tools and runtime dependencies separate minimizes security risks.

# Example
```Dockerfile
# Use a base image for building and run the application
FROM node:14 as build

# Set working directory and copy the application
WORKDIR /app
COPY package.json yarn.lock ./
RUN yarn install

# Build the application
RUN yarn build

# Copy the built files to a new stage
FROM nginx:latest
COPY --from=build /app/dist .
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
