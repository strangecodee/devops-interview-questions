 # Use Multi-Stage Builds for Docker Images
Construct Dockerfiles using multi-stage builds to minimize image size and improve security.

# Explanation
Multi-stage builds allow you to create a Docker image using multiple Dockerfiles, each with a different purpose. The final image is built using the last Dockerfile and only includes the necessary files and dependencies. This approach reduces image size as you don't carry unused artifacts from earlier stages, and improves security by keeping sensitive data (like keys, credentials, or runtime dependencies) separated from the production image.

# Why It Matters
- Minimizes image size by eliminating unnecessary files
- Enhances security by isolating sensitive data
- Optimizes resource usage by having cleaner images

# Example
```Dockerfile
# Use an initial stage for building and caching dependencies
FROM node:14 as build

# Install project dependencies
RUN npm install

# Copy .env file to this stage for building
COPY .env .

# Build application
RUN npm run build

# Final stage for running the application
FROM nginx:alpine

# Copy the contents of the build stage
COPY --from=build /app/build /usr/share/nginx/html

# Expose the port and set the default command
EXPOSE 80
ENTRYPOINT ["nginx", "-g", "daemon off;"]
```
