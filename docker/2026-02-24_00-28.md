 # Best Practice: Implement Docker Container Monitoring Using Prometheus and Grafana
Use Prometheus and Grafana for monitoring Docker containers to effectively observe and analyze container metrics and visualize performance data.

# Explanation
Prometheus is an open-source monitoring system and Grafana is a popular visualization tool that, when used together, enable efficient container monitoring. Prometheus scrapes container metrics and stores them in a time-series database, while Grafana provides visual dashboards to analyze and display the data.

# Why It Matters
- Ensuring container availability, performance, and resource utilization is critical for maintaining a stable and efficient containerized infrastructure.
- Prometheus and Grafana simplify monitoring by allowing easy configuration, querying, and visualization of container metrics.
- Real-time monitoring enables quick identification and resolution of issues, reducing downtime and minimizing potential losses.

# Example
```Dockerfile
# Use an official Prometheus image as a base
FROM prom/prometheus:v2.31.0

# Install Grafana and its dependencies
RUN apt-get update && apt-get install -y curl gpg gettext
RUN mkdir -p /etc/grafana
RUN curl -fsSL https://dl.grafana.com/oss/release/grafana-8.3.0.deb > grafana-8.3.0.deb
RUN dpkg -i grafana-8.3.0.deb

# Set up Prometheus to scrape container metrics
RUN echo "global:scrape_interval 15s" >> /etc/prometheus/prometheus.yml
RUN echo "scrape_configs:" >> /etc/prometheus/prometheus.yml
RUN echo "  - job_name: 'docker'" >> /etc/prometheus/prometheus.yml
RUN echo "    static_configs:" >> /etc/prometheus/prometheus.yml
RUN echo "      - targets: ['localhost:9323']" >> /etc/prometheus/prometheus.yml
RUN echo "    metrics_path: '/metrics'" >> /etc/prometheus/prometheus.yml

# Set up Grafana to use Prometheus as a data source
ENV GF_INSTALL_PLUGINS=grafana-piechart-panel,grafana-statalert
RUN adduser --system grafana
RUN chown grafana:grafana /var/lib/grafana

# Start Prometheus and Grafana at container launch
CMD ["prometheus", "--config.file=/etc/prometheus/prometheus.yml", "--web.listen-address=0.0.0.0:9090"]
CMD ["grafana-cli plugins install"]
CMD ["grafana-cli plugins update"]
CMD ["grafana-cli login --non-interactive --username 'admin' --password 'admin'"]
CMD ["grafana-cli config file runtime.json --path /etc/grafana/provisioning/provision.json --template 'file:/path/to/template.json'"]
CMD ["grafana-server web"]
```
Replace `/path/to/template.json` with the path to a JSON template file for configuring Grafana dashboards. This Dockerfile sets up a container with Prometheus and Grafana, scrapes container metrics, and configures Grafana to use Prometheus as a data source.
