 # Use Multi-Stage Builds for Performance Optimization
Build Docker images using multi-stage builds to minimize image size and optimize performance.

# Explanation
Multi-stage builds allow you to create a Docker image using multiple Dockerfiles in a single build process. Each stage can be optimized for a specific task, such as building the application and producing the production image. This approach reduces the image size by eliminating unnecessary dependencies and tools used only during the build process.

# Why It Matters
- Reduces the final image size by eliminating unnecessary dependencies and large build tools.
- Improves build and run-time performance by omitting unnecessary steps during the Docker build process.
- Enhances security by isolating the build environment from the production environment.

# Example
```Dockerfile
# Stage 1: Build the application
FROM node:14 as builder
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

# Stage 2: Create the production image
FROM nginx:latest
COPY --from=builder /app/dist /usrs/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
This example demonstrates using a multi-stage build to create the application and then create a production image based on the Nginx image. The first stage builds the application, and the second stage creates the production image, which only includes the necessary dependencies for running the application.
