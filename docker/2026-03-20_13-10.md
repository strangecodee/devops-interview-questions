 # Best Practice: Implement Resource Limits in Docker Compose Files
Use Docker Compose files to set resource limits for containers to ensure optimal system performance and prevent container resource hogging.

# Explanation
Docker Compose files allow setting resource limits for containers via the `limits` configuration option in the `docker-compose.yml` file. By defining resource limits, you can effectively manage container resource usage, prevent containers from monopolizing system resources, and maintain a stable Docker environment.

# Why It Matters
- Ensuring containers do not consume excessive resources, such as CPU and memory, can help maintain system performance and availability.
- Preventing resource hogging can prevent containers from negatively impacting other applications and services running on the same host.
- Effective resource management contributes to a stable and predictable Docker environment.

# Example
```
version: '3.8'
services:
  myapp:
    image: myregistry/myapp:latest
    container_name: myapp
    limits:
      cpus: '0.5'
      memory: 512M
    restart: always
```
In this example, the `myapp` service is limited to consuming 0.5 CPU cores and 512MB of memory. These limits can be adjusted based on the specific resource requirements of your application.
