 # Best Practice: Implement Resource Limits for Docker Containers
<Implement resource limits for Docker containers to ensure efficient use of system resources and prevent container misbehavior>.

# Explanation
Docker containers are designed to be isolated environments for running applications, but without proper resource management, containers can consume excessive system resources and impact the performance of other containers or the host system. By setting resource limits, you can ensure that each container is allocated a specific amount of CPU, memory, network, or I/O resources, preventing container misbehavior and improving overall system efficiency.

# Why It Matters
- Prevents container misbehavior and ensures fair allocation of system resources among containers
- Improves system stability and reliability by preventing containers from consuming excessive resources
- Enables better utilization of resources by guaranteeing that each container gets the resources it needs to operate effectively

# Example
```Dockerfile
# Set CPU and memory limits
RUN echo "cpu.shares=512" >> /etc/docker/container.d/<container-name>.conf
RUN echo "memory.limit_in_bytes=2150000000" >> /etc/docker/container.d/<container-name>.conf
```

```bash
# Set CPU and memory limits using docker run
docker run --cpus=0.5 --memory=2g <image-name>
```
