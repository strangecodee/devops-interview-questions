 # Docker Image Versioning Best Practice
Use semantic versioning for Docker image tags to ensure consistent and controlled upgrades.

# Explanation
Semantic versioning consists of three numbers separated by dots: major.minor.patch. Each part has a specific meaning. Major indicates a significant change, minor a new feature, and patch a bug fix. This standardized approach allows for easier tracking of changes and compatibility.

# Why It Matters
- Ensures backward compatibility for consumers
- Prevents unexpected behavior due to unintended upgrades
- Facilitates easier dependency management

# Example
```
# Dockerfile
FROM nebula/base:v1.0.0

# Docker CLI
docker pull nebula/my-app:1.2.3
```
