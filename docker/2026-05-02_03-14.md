# Best Practice: Use a Multi-Container Docker Compose Application for Load Balancing
Implement load balancing functionalities by using a multi-container Docker Compose application instead of relying on a single container.

# Explanation
Docker Compose is a tool for defining and running multi-container Docker applications. By using multiple containers within a Compose file, it becomes possible to implement load balancing using external tools such as Traefik or Nginx. This approach decouples the load balancer from the application container, improving scalability and fault tolerance.

# Why It Matters
- Scalability: By separating the load balancer from the application container, it becomes easier to scale the load balancer horizontally to handle increased traffic.
- Fault tolerance: In case of an application container failure, the load balancer can automatically redirect traffic to remaining healthy application containers, ensuring application availability.
- Simplified configuration: Using a multi-container Docker Compose application for load balancing also simplifies the configuration process, as the load balancer, application, and other required services can all be defined within a single file.

# Example
```yaml
# docker-compose.yml
version: "3"

services:
  web:
    image: example/app:latest
    ports:
      - "80:80"
      - "443:443"

  loadbalancer:
    image: traefik:latest
    ports:
      - "8080:8080"
      - "80:80"
      - "443:443"
    networks:
      - my_network

networks:
  my_network:
    driver: bridge
```

```bash
# Building Docker image
docker build -t example/app .

# Running Docker Compose
docker-compose up -d
```
