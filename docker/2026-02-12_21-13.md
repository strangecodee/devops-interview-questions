 # Use Multi-Stage Builds for Optimized Docker Images
Build Docker images using multi-stage builds to minimize image size and improve security.

# Explanation
Multi-stage builds allow you to build an image using one or more base images, and copy only the necessary files from one stage to the next. This results in smaller image sizes and reduces the attack surface area by avoiding unnecessary packages and configurations.

# Why It Matters
- Reduces image sizes by eliminating unnecessary packages and configurations
- Minimizes the attack surface area by not carrying unneeded software
- Enhances security by starting the final runtime image from a clean base

# Example
```Dockerfile
# Use a base image for building and installing dependencies
FROM node:14.17.3 AS build

WORKDIR /app
COPY package.json yarn.lock ./
RUN yarn install

# Use a different base image for the final runtime environment
FROM nginx:1.19
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```
