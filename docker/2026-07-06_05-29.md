 # Best Practice: Maintain a Lean Docker Image
<Build images with only the necessary components to run your application>

# Explanation
Docker images should be kept as lean as possible by only including the necessary components to run your application. This reduces the image size and the attack surface area. It also ensures that updates to your base image do not unintentionally impact your application.

# Why It Matters
- Reduces image size, improving build and deployment times
- Minimizes attack surface area
- Ensures that updates to base image do not unintentionally impact your application

# Example
```Dockerfile
# Use an official base image and only install your application dependencies
FROM node:14 as build
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .

# Use a production image as runtime
FROM node:14-alpine
WORKDIR /app
COPY --from=build /app .
EXPOSE 8080
CMD ["npm", "start"]
```
