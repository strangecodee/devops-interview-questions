 # Interview Question
Can you explain how you have implemented and configured a high availability load balancer using Amazon Elastic Load Balancer (ELB) in a production environment?

# Answer
In my previous role as a DevOps Engineer, I was responsible for implementing and managing a high availability load balancing solution using Amazon Elastic Load Balancer (ELB) in a production environment. I designed and executed the deployment process, ensuring the ELB was properly configured to distribute incoming application traffic across multiple Amazon Elastic Compute Cloud (EC2) instances.

Key Technical Points:
- I utilized ELB's health check feature to automatically detect and register or deregister instances based on their health status
- Implemented session persistence to maintain a stable user session across multiple instances
- Used Auto Scaling policies to automatically increase or decrease the number of instances based on traffic demands

# Real-World Example
```yaml
Resources:
  MyLoadBalancer:
    Type: "AWS::ElasticLoadBalancing::LoadBalancer"
    Properties:
      Listeners:
        - Protocol: "HTTP"
          LoadBalancerPort: "80"
          InstanceProtocol: "HTTP"
          InstancePort: "80"
      HealthCheck:
        TargetGroupArn: !Ref MyTargetGroup
        Interval: "30"
        Timeout: "3"
        UnhealthyThreshold: "2"
        HealthyThreshold: "2"
      Scheme: "InternetFacing"
      SecurityGroups:
        - !Ref MySecurityGroup

  MyTargetGroup:
    Type: "AWS::ElasticLoadBalancing::TargetGroup"
    Properties:
      TargetType: "ip"
      VpcId: !Ref MyVpcId
      Protocol: "HTTP"
      TargetGroupAttributes:
        StickinessConfig:
          Duration: "1800"
      HealthCheck:
        HealthyThreshold: "2"
        UnhealthyThreshold: "2"
        Interval: "30"
        Timeout: "3"
        Path: "/"
      Targets:
        - Id: !Ref MyEC2Instance1ID
          Port: "80"
        - Id: !Ref MyEC2Instance2ID
          Port: "80"
```
This example demonstrates a high availability load balancer setup using an ELB and a target group. The target group maintains a list of registered instances and their associated ports, while the ELB uses the health check to periodically probe the instances and update their health status. The session persistence is achieved through stickiness config, which keeps users sessions with the same instance for a specified duration.
