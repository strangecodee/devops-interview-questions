 # Interview Question
Please explain your experience with implementing security best practices in continuous integration and delivery pipelines using Ansible.

# Answer
During my tenure as a DevOps Engineer, I have successfully designed and implemented security-focused CI/CD pipelines utilizing Ansible for several enterprise clients. My responsibilities included integrating security scans, vulnerability assessments, and compliance checks at various stages of the pipeline to ensure that security was not compromised.

# Key Technical Points
- Implemented Ansible roles for integrating security scans from tools like SonarQube, Sonatype Nexus Lifecycle, and Black Duck.
- Automated the deployment of firewall rules using Ansible to secure infrastructure and limit access to specific IPs.
- Set up real-time monitoring and notifications using Ansible, Nagios, and Grafana to ensure the security of the infrastructure.

# Real-World Example
```yaml
---
- name: Configure firewall rules using Ansible
  hosts: web_servers
  tasks:
    - name: Allow SSH access to specific IPs
      ios_config:
        provider: esxi_network
        commands:
          - access-list extended allow_ssh
            permit ip host {{ ssh_ip }} ssh
            permit ip host {{ ssh_ip }} ssh key
          - exit
        when: ansible_os_family == 'RedHat'
    - name: Configure Windows Firewall using PowerShell
      hosts: win_servers
      tasks:
        - name: Create a new inbound rule
          win_firewall:
            name: Allow_SSH
            protocol: TCP
            local_port: 22
            remote_address: '{{ ssh_ip }}'
            state: enabled
          register: firewall_rule_create
        - name: Check if rule was created successfully
          assert:
            that:
              - eq: "{{ firewall_rule_create.changed }}"
              value: true
            msg: "Firewall rule 'Allow_SSH' creation failed."
```
