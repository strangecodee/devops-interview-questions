# Real-World Example
Suppose we have a microservices architecture with several services communicating with each other. To ensure secure communication between them, we would define authentication and authorization policies in Istio. With Atlas, we can easily deploy and manage these policies using YAML configuration files:

```yaml
apiVersion: authentication.istio.io/v1alpha1
kind: AuthenticationPolicy
metadata:
  name: my-auth-policy
spec:
  rule: 
  - source:
      principals: ["source.principal.com"]
    destinations: ["service1.com", "service2.com"]
    authentication:
      method: JWT
      jwt:
        issuerURL: "https://identity-provider.com"
```

In this example, we allow traffic from "source.principal.com" to reach both "service1.com" and "service2.com" only if the request contains a valid JWT token with the issuer URL "https://identity-provider.com".
