 # Interview Question
Can you explain how you have implemented infrastructure as code using Terraform in an enterprise environment?

# Answer
I have implemented Infrastructure as Code (IaC) using Terraform, a popular open-source tool for building, changing, and versioning infrastructure safely and efficiently. Terraform provides a declarative configuration language, allowing us to define the desired state for our infrastructure, enabling automation of infrastructure deployment and configuration management.

Key Technical Points
- Terraform uses a simple and human-readable configuration language, HCL (Hashicorp Configuration Language), to define infrastructure resources.
- The infrastructure is defined as code, which can be versioned, and changes can be tracked using Git or other version control systems.
- Terraform supports multiple cloud providers, including AWS, Azure, Google Cloud, and others, making it a versatile choice for building and managing infrastructure in a multi-cloud environment.

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
}

resource "aws_vpc" "example" {
 cidr_block = "10.0.0.0/16"
 enable_dns_support = true
 enable_dns_hostnames = true
 enable_nat_gateway = true
 enable_internet_gateway = true

 tags = {
 Name = "example-vpc"
}
}
```
This example demonstrates how to define an Amazon Virtual Private Cloud (VPC) using Terraform. The desired state is defined in the Terraform configuration file, and when we run `terraform apply`, Terraform will create the VPC if it doesn't exist or update it if the configuration has changed. This ensures that our infrastructure is always in the desired state and can be easily managed and tracked.
