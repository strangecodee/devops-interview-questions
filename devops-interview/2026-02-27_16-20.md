 # Interview Question
Can you explain how to use Terraform to deploy an Amazon Elastic Load Balancer (ALB) and configure it with HTTPS using Let's Encrypt certificates?

# Answer
Terraform is an open-source infrastructure as code software tool from Hashicorp used to provision and manage various cloud resources. To deploy an Amazon Elastic Load Balancer (ALB) with HTTPS using Let's Encrypt certificates, you need to follow these steps:

1. Set up an AWS provider and configure the necessary AWS credentials;
2. Create a new ALB resource with the desired load balancer configuration and listeners;
3. Implement a custom data source to interface with the Let's Encrypt API for certificate issuance;
4. Create a new AWS certificate manager certificate using the Let's Encrypt certificate and the private key.

# Key Technical Points
- Familiarity with Terraform syntax and AWS CLI is necessary;
- Understanding of the AWS provider and Let's Encrypt API;
- Knowledge of certificate management and SSL/TLS configurations.

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
}

resource "aws_lb" "example" {
 name               = "example-alb"
 internal           = false
 subnets            = ["subnet-1", "subnet-2"]
 security_groups     = ["sg-example"]

 listener {
   protocol          = "HTTP"
   port             = 80
 }

 listener {
   protocol          = "HTTPS"
   port             = 443
   certificate_arn    = aws_acm_certificate_v2.example.arn
 }
}

data "http" "acme_challenge" {
 url      = "https://acme-staging-v02.api.letsencrypt.org/directory/v2/issue/challenges/dns-01/<token>"
 method   = "GET"
}

resource "aws_acm_certificate_v2" "example" {
 domain_name = "example.com"
 subject_alternative_names = ["www.example.com"]
 issuer_arn = "arn:aws:acm:us-west-2:123456789012:acm-v2-certificate/<certificate_arn>"
 private_key = file("example.com.key")
 validation {
   dns {
     records = [aws_route53_record.example.name]
     zone_id = aws_route53_zone.example.id
   }
 }
}

resource "aws_route53_record" "example" {
 name    = "_acme-challenge.example.com."
 type    = "TXT"
 ttl     = 300
 records = [data.http.acme_challenge.response_body]
 zone_id = aws_route53_zone.example.id
}

resource "aws_route53_zone" "example" {
 name = "example.com"
}
```
This example demonstrates deploying an ALB with HTTP and HTTPS listeners, and obtaining a Let's Encrypt certificate using Terraform. Note that this is a simplified example, real-world implementation may require additional configurations and error handling.
