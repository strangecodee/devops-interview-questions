# Real-World Example
At Nebula Corporation, I implemented a Prometheus monitoring system to track the performance of our microservices architecture. I defined critical metrics such as CPU utilization, network latency, and error rates, set up alerts for CPU utilization exceeding 80% and network latency above 200ms. I also prioritized security by implementing RBAC and encrypting sensitive data.

```yaml
# prometheus.yml
global:
  scrape_interval:     15s
  evaluation_interval: 15s

# alerts.yml
groups:
  - name: CPU Utilization
    rules:
    - alert: HighCPU
      expr: (container_cpu_usage_shorted > 0.8)
      for: 5m
      annotations:
        summary: "Container CPU usage is too high"
        description: "This alert is triggered when container CPU usage is above 80% for 5 minutes"
```
