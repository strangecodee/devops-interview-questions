# Interview Question
Can you explain how to secure a Kubernetes cluster using RBAC and Network Policies?

# Answer
RBAC (Role-Based Access Control) and Network Policies are two essential security features in Kubernetes that help to secure clusters by controlling access to resources and limiting network traffic, respectively. RBAC allows you to manage access to Kubernetes resources based on roles and permissions, while Network Policies enable you to define and enforce traffic rules between pods. By combining these two features, you can create a robust security posture for your Kubernetes cluster.

# Key Technical Points
- RBAC allows you to define and manage fine-grained access control for Kubernetes resources such as pods, services, and namespaces.
- RBAC uses Role, RoleBinding, and ServiceAccount objects to define and assign roles and permissions to users, groups, and processes.
- Network Policies enable you to define and enforce network traffic rules between pods using labels and IP ranges.
- Network Policies can be used to allow or deny traffic based on protocol, port, source, and destination IP addresses.

# Real-World Example
To configure RBAC and Network Policies in a Kubernetes cluster, you can follow these steps:

1. Create a Role and RoleBinding for a specific user or group:

```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: my-role
  labels:
    app: my-app
rules:
- apiGroups: [""]
  resources: ["pods"]
  verbs: ["get", "watch", "list"]

---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: my-rolebinding
subjects:
- kind: User
  name: my-user
  apiGroup: rbac.authorization.k8s.io
  kind: User
roleRef:
  kind: Role
  name: my-role
  apiGroup: rbac.authorization.k8s.io
```

2. Create a Network Policy to allow traffic only from a specific IP range to a specific pod:

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: my-network-policy
spec:
  podSelector:
    matchLabels:
      app: my-app
  policyTypes:
  - Ingress
  ingress:
  - from:
    - ipBlock:
        cidr: 10.0.0.0/16
```

By combining RBAC and Network Policies, you can secure your Kubernetes cluster by controlling access to resources and limiting network traffic based on your organization's specific security requirements.
