# Real-World Example
To configure Eclipse Telemetry for a Java application, I created a `maven-plugin.xml` file with the following content:

```xml
<build>
  <plugins>
    <plugin>
      <groupId>io.eclipse.telemetry</groupId>
      <artifactId>maven-plugin</artifactId>
      <version>1.14.0</version>
      <configuration>
        <properties>
          <otel.exporter.endpoint>http://localhost:4317</otel.exporter.endpoint>
        </properties>
      </configuration>
    </plugin>
  </plugins>
</build>
```

This configuration adds the Eclipse Telemetry Maven plugin, sets the endpoint for the exporter, and sends the collected data to the exporter running on localhost.
