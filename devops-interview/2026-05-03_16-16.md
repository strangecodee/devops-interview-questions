# Real-World Example
In one project, I used Istio to implement rate limiting for a specific microservice to prevent abuse. I created a gateway resource and applied a custom rate limiter middleware to the corresponding virtual service. This configuration ensured that the service handled no more than 10 requests per second from any client, thus improving overall system stability and performance.

```yaml
apiVersion: networking.istio.io/v1alpha3
kind: Gateway
metadata:
  name: my-gateway
spec:
  selector:
    app: my-app
  servers:
  - hosts:
    - localhost
    ports:
    - name: http
      port: 80
      protocol: HTTP
---
apiVersion: networking.istio.io/v1alpha3
kind: VirtualService
metadata:
  name: my-virtual-service
spec:
  hosts:
  - my-app
  http:
  - route:
    - destination:
        host: my-service
        port:
          number: 80
    middlewares:
    - name: rate-limiter
---
apiVersion: security.istio.io/v1beta1
kind: Middleware
metadata:
  name: rate-limiter
spec:
  limitRequests:
    perSecond: 10
```
