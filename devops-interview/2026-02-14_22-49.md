 # Interview Question
Can you explain how to implement an auto-scaling group using Amazon Elastic Load Balancer and Auto Scaling in AWS, utilizing a custom scaling policy based on a specific metric called "pulse"?

# Answer
To implement an auto-scaling group using Amazon Elastic Load Balancer (ALB) and Auto Scaling in AWS, you first need to create a new Launch Configuration and an Auto Scaling Group. The Launch Configuration defines the Amazon Machine Image (AMI), instance type, and other instance launch settings. The Auto Scaling Group is associated with the Launch Configuration and uses the ELB for its load balancing. To create a custom scaling policy based on a specific metric called "pulse," you'll use the CloudWatch Alarm and the Scaling Policy.

# Key Technical Points
1. Create a Launch Configuration: Define the Amazon Machine Image, instance type, and other instance launch settings.
2. Create an Auto Scaling Group: Associate the Launch Configuration and the desired Auto Scaling policies, including the ELB for load balancing.
3. Use CloudWatch Alarm: Set up a CloudWatch Alarm that will trigger when the "pulse" metric exceeds or falls below a specific threshold.
4. Create a Scaling Policy: Attach the CloudWatch Alarm to a new Scaling Policy, which will scale the number of instances in the Auto Scaling Group based on the state of the Alarm.

# Real-World Example
```YAML
Resources:
  MyASG:
    Type: "AWS::AutoScaling::AutoScalingGroup"
    Properties:
      LaunchConfigurationName: "MyLaunchConfiguration"
      VPCZoneIdentifier: "us-east-1a-Subnet-1,us-east-1a-Subnet-2"
      LoadBalancers:
        - "arn:aws:elasticloadbalancing:us-east-1:123456789012:loadbalancer/app/MyALB/1771089582/12345678-1234-1234-1234-123456789012"
      Metrics:
        - "- MetricName": "PulseMetric"
          - "Namespace": "MyNamespace"
          - "MetricData":
              - { "MetricName": "InstanceIdMetricName", "Value": "{Ref: "MyASG-InstanceId"}" }

  MyCloudWatchAlarm:
    Type: "AWS::CloudWatch::Alarm"
    Properties:
      AlarmName: "MyAlarm"
      ComparisonOperator: "GreaterThanThreshold"
      EvaluationPeriods: "1"
      MetricName: "PulseMetric"
      Namespace: "MyNamespace"
      Period: "60"
      Statistic: "Average"
      Threshold: "50"
      AlarmActions:
        - "arn:aws:sns:us-east-1:123456789012:MyTopic"

  MyScalingPolicy:
    Type: "AWS::AutoScaling::ScalingPolicy"
    Properties:
      AutoScalingGroupName: "{Ref: "MyASG"}"
      ScalingPolicyName: "MyScalingPolicy"
      Adjustments:
        - "AdjustmentType": "ChangeInCapacity"
        - "AutomaticallyAdjustScalingGroupDesiredCapacity": "true"
      AlarmActions:
        - "AlarmName": "{Ref: "MyAlarm"}"
      Cooldown: "300"
```
