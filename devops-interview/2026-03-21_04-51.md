 # Interview Question
Can you explain how to securely provision infrastructure using Terraform and IAM roles?

# Answer
Terraform is an open-source infrastructure as code software that allows us to define and provide data center infrastructure safely and efficiently. In order to securely provision infrastructure using Terraform and IAM roles, we will first create an IAM role with the necessary permissions for Terraform to manage AWS resources. Then, we will configure Terraform to use the IAM role through a shared configuration file or an environment variable. This approach limits the access granted to the Terraform user account and enhances security by reducing the need for manual intervention and the risk of misconfiguration.

# Key Technical Points
- Define an IAM role with the required permissions for Terraform to manage resources
- Configure Terraform to use the IAM role through a shared configuration file or environment variable
- Reduces the risk of misconfiguration and eliminates the need for manual intervention

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
 version = "~> 2.16"

 # Set the IAM role ARN as an environment variable or in a shared configuration file
 variable "iam_role_arn" {
   default = "arn:aws:iam::123456789012:role/MyTerraformRole"
 }
}

output "instance_public_ip" {
 value = aws_instance.example.public_ip
}

resource "aws_instance" "example" {
 ami           = "ami-0c55b159cbfafe1f0"
 instance_type  = "t2.micro"
 iam_instance_profile = aws_iam_instance_profile.example.name

 tags = {
   Name = "example-instance"
 }
}

resource "aws_iam_instance_profile" "example" {
 name = "example-instance-profile"
 roles = ["arn:aws:iam::123456789012:role/MyTerraformRole"]
}
```
In this example, we have configured Terraform to use an IAM role named "MyTerraformRole" for managing AWS resources in the provided AWS provider configuration. By using an IAM role, we limit the access granted to Terraform, ensuring that it only has the necessary permissions for managing infrastructure.
