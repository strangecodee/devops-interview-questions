 # Interview Question
Can you explain how to set up a monitoring system using a configuration management tool like Ansible and a monitoring solution like Prometheus, for an application deployed on Kubernetes?

# Answer
In the context of modern DevOps practices, setting up monitoring for applications deployed on container orchestration platforms like Kubernetes is crucial for maintaining system health and performance. In this response, I will outline the process of implementing monitoring using Ansible for configuration management and Prometheus as the monitoring solution.

First, we need to ensure that the necessary Prometheus components are installed within our Kubernetes cluster. This includes the Prometheus server, node exporter, and kube-state-metrics. To accomplish this, we can leverage Ansible to create and apply the necessary Kubernetes manifests for these components.

Key Technical Points:
- Use Ansible to create Kubernetes manifests for Prometheus server, node exporter, and kube-state-metrics.
- Apply these manifests to the Kubernetes cluster using Kubernetes Ansible module.

# Real-World Example
```yaml
---
- name: Install and configure Prometheus, Node Exporter, and Kube-state-metrics on Kubernetes
  hosts: kubernetes_cluster
  become: true
  tasks:
  - name: Install Prometheus
    kubernetes_manifest:
      manifests: "{{ item }}"
      state: present
      validate_certs: no
      wait: yes
      args:
        dry_run: false
      src:
        src_dir: prometheus
        src_file: prometheus-deployment.yaml
      vars:
        release_name: "prometheus"
      connection: local

  - name: Install Node Exporter
    kubernetes_manifest:
      manifests: "{{ item }}"
      state: present
      validate_certs: no
      wait: yes
      args:
        dry_run: false
      src:
        src_dir: node_exporter
        src_file: node_exporter-deployment.yaml
      vars:
        release_name: "node-exporter"
      connection: local

  - name: Install Kube-state-metrics
    kubernetes_manifest:
      manifests: "{{ item }}"
      state: present
      validate_certs: no
      wait: yes
      args:
        dry_run: false
      src:
        src_dir: kube-state-metrics
        src_file: kube-state-metrics-deployment.yaml
      vars:
        release_name: "kube-state-metrics"
      connection: local

  tasks:
  - name: Ensure Prometheus is running
    kubernetes_pod:
      name: prometheus
      state: started
      namespace: monitoring
      connection: local
      validate_certs: no
  ```

This example showcases the use of Ansible to install and configure Prometheus, Node Exporter, and kube-state-metrics on a Kubernetes cluster. Ansible's Kubernetes module is employed to create and apply the required manifests. This setup can be customized to meet specific monitoring requirements.
