 # Interview Question
Can you explain how Terraform by Hashicorp is used to deploy infrastructure as code and what are its key benefits?

# Answer
Terraform is an open-source infrastructure as code software solution by Hashicorp that enables users to define, provision, and manage their data centers, public cloud services, and SaaS offerings through a declarative configuration file. It allows for the creation of infrastructure resources in a consistent and automated manner, reducing human error and increasing productivity.

# Key Technical Points
- Terraform uses a declarative configuration file, written in HCL (Hashicorp Configuration Language), to define the desired state of infrastructure resources.
- It supports multiple cloud providers and on-premises technologies, allowing for a unified management approach.
- Terraform uses a modular design, enabling easy reuse and sharing of infrastructure components.

# Real-World Example
Consider a scenario where you need to set up an Amazon Web Services (AWS) Elastic Load Balancer (ELB) and two Amazon Elastic Compute Cloud (EC2) instances. With Terraform, you would write a configuration file (HCL) describing these resources, and Terraform would ensure they are created and configured according to your definition.

```hcl
provider "aws" {
 region = "us-west-2"
}

resource "aws_elb" "example" {
 name            = "example-elb"
 subnets         = ["subnet-1a", "subnet-1b"]
 security_groups = ["sg-example"]

 listeners {
   lb_port     = 80
   lb_protocol = "HTTP"
   cb_protocol = "HTTP"
 }

 instances = [
   aws_instance.instance-1,
   aws_instance.instance-2
 ]
}

resource "aws_instance" "instance-1" {
 ami           = "ami-0c55b159cbfafe1f0"
 instance_type = "t2.micro"
 subnet_id      = "subnet-1a"
 vpc_security_group_ids = ["sg-example"]
 tags = {
   Name = "instance-1"
 }
}

resource "aws_instance" "instance-2" {
 ami           = "ami-0c55b159cbfafe1f0"
 instance_type = "t2.micro"
 subnet_id      = "subnet-1b"
 vpc_security_group_ids = ["sg-example"]
 tags = {
   Name = "instance-2"
 }
}
```

In this example, Terraform provisions an ELB, two EC2 instances, and configures the security groups and subnets. Once the configuration file is committed, Terraform takes care of the rest, ensuring a consistent and error-free infrastructure setup.
