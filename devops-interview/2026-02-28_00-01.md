 # Interview Question
Can you explain how to use Terraform to deploy an Amazon Elastic Kubernetes Service (EKS) cluster and an Eclipse Jetty application using a custom Kubernetes manifest file?

# Answer
Terraform is an open-source infrastructure as code (IaC) tool from Hashicorp that enables you to define, provide, create, and modify infrastructure safely and efficiently. In this scenario, we will deploy an Amazon Elastic Kubernetes Service (EKS) cluster and an Eclipse Jetty application using a custom Kubernetes manifest file.

Key Technical Points:
1. First, initialize the Terraform working directory and configure the necessary AWS provider:
```hcl
provider "aws" {
 version = "3.14.0"
 region = "us-west-2"
}

terraform {
 required_providers {
 aws = {
 source  = "hashicorp/aws"
 version = "3.14.0"
 }
 kubernetes = {
 source  = "hashicorp/kubernetes"
 version = "2.13.1"
 }
 }
}
```
2. Create an EKS cluster using the `aws_eks_cluster` resource:
```hcl
resource "aws_eks_cluster" "example" {
 name          = "example-cluster"
 version       = "1.23.2-x86_64"
 cluster_name   = "example-cluster"
 role_arn       = aws_iam_role.example.arn
 vpc_config {
 subnet_ids = [aws_subnet.subnet-1.id, aws_subnet.subnet-2.id]
}

managed_node_groups {
 name                 = "example-nodegroup"
 subnets               = [aws_subnet.subnet-1.id, aws_subnet.subnet-2.id]
 instance_types        = ["t2.micro", "t2.small"]
 ami_type              = "AL2_x86_64"
 disk_size             = 20
 min_size              = 1
 max_size              = 3
 desired_size           = 1
}

}
```
3. Create a Kubernetes secret for the Jetty application:
```hcl
resource "kubernetes_secret" "jetty_secret" {
 metadata {
 name = "jetty-secret"
 namespace = "example"
 }
 data = {
 "jetty.properties" = filebase64("${path.module}/jetty.properties")
}
}
```
4. Create a Kubernetes deployment for the Jetty application using a custom Kubernetes manifest file:
```hcl
resource "kubernetes_manifest" "jetty_deployment" {
 manifest = jsonencode({
 apiVersion = "apps/v1",
 kind = "Deployment",
 metadata = {
 name = "jetty-deployment"
 labels = {
 "App" = "jetty"
 }
 },
 spec = {
 replicas = 1,
 selector = {
 match_labels = {
 "App" = "jetty"
 }
 },
 template = {
 metadata = {
 labels = {
 "App" = "jetty"
 }
 },
 spec = {
 containers = [
 {
 name = "jetty",
 image = "eclipse/jetty:latest",
 ports = [
 {
 container_port = 8080
 }
 ],
 env = [
 {
 name = "JAVA_OPTS"
 value = "-Djetty.port=8080 -Djava.security.egd.file=/dev/./urandom"
 }
 ],
 volume_mount = [
 {
 mount_path = "/var/lib/tomcat8"
 name = "jetty-data"
 }
 ],
 volume = [
 {
 name = "jetty-data"
 config_map = {
 name = "jetty-config"
 }
 }
 ]
 }
 ]
 }
})
}
}
```
5. Finally, apply the Terraform configuration and watch as it deploys the EKS cluster and the Jetty application using the custom Kubernetes manifest file.

# Real-World Example
This example demonstrates how to deploy an Amazon Elastic Kubernetes Service (EKS) cluster and an Eclipse Jetty application using Terraform. The Jetty application is configured using a custom Kubernetes manifest file, which includes a secret and a deployment. The infrastructure is deployed in the `us-west-2` AWS region, with subnets `subnet-1` and `subnet-2`. The Jetty application runs on port `8080` and uses a Tomcat8 configuration stored in a Kubernetes ConfigMap named `jetty-config`. The example assumes you have the necessary IAM roles and permissions configured for the AWS and Kubernetes providers.
