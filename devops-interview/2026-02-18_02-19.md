 # Interview Question
Can you explain how you have implemented and configured a high-availability load balancer using AWS Elastic Load Balancer (ELB)?

# Answer
In my previous role at XYZ Corporation, I was responsible for implementing and managing our web application infrastructure. To ensure high availability and scalability for our growing user base, I designed and implemented a solution using Amazon Elastic Load Balancer (ELB). This service automatically distributes incoming application traffic across multiple Amazon EC2 instances, enabling automatic failover and scaling.

# Key Technical Points
- Set up an Application Load Balancer (ALB) or Network Load Balancer (NLB) based on application requirements
- Configured Health Checks: ELB continuously monitors the health of EC2 instances and automatically reroutes traffic to healthy instances
- Utilized Auto Scaling: Based on user traffic, EC2 instances were automatically scaled up or down, with ELB distributing traffic accordingly
- Security: Implemented SSL certificates and security groups to secure the communication between the load balancer and EC2 instances

# Real-World Example
```yaml
Resources:
  MyLoadBalancer:
    Type: "AWS::ElasticLoadBalancingV2::ApplicationLoadBalancer"
    Properties:
      Listeners:
        - Protocol: "HTTP"
          Port: "80"
          DefaultActions:
            - Type: "forward"
            - TargetGroupArn: !Ref MyTargetGroup
      HealthCheck:
        TargetGroupArn: !Ref MyTargetGroup
        Protocol: "HTTP"
        Port: "80"
        Path: "/healthz"
        Interval: 30
        Timeout: 2
        UnhealthyThreshold: 5
  MyTargetGroup:
    Type: "AWS::ElasticLoadBalancingV2::TargetGroup"
    Properties:
      TargetType: "instance"
      VpcId: !Ref MyVPC
      Targets:
        - Id: !Ref MyEC2Instance1
          Port: 80
        - Id: !Ref MyEC2Instance2
          Port: 80
```
In this example, I created an Application Load Balancer with a target group, configured health checks, and set up listeners for inbound traffic. This setup ensures high availability by distributing traffic to healthy instances and automatically scaling based on traffic demands.
