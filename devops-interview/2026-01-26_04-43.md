 # Interview Question
Can you explain how you would implement an on-call rotation system using Phoenix Projects in GitHub Actions for a large-scale application?

# Answer
In the context of Site Reliability Engineering (SRE), implementing an effective on-call rotation system is crucial for maintaining service availability and ensuring incident response. To achieve this in a large-scale application using GitHub Actions and Phoenix Projects, I would follow these steps:

First, create a new Phoenix project dedicated to handling on-call rotations. This project would include a simple web interface for managing team members and their schedules.

Next, set up a GitHub Actions workflow that automatically assigns on-call duties based on the configured schedule. The workflow would utilize a random number generator, such as the one built into bash, to select the next team member based on the current time and the defined rotation schedule.

Lastly, create and manage the rotation schedule as a separate GitHub repository in YAML format. This approach allows for easy modification and collaboration among team members, ensuring a transparent and fair on-call rotation.

# Key Technical Points
- Create a Phoenix project for handling on-call rotations
- Implement a GitHub Actions workflow for automatic on-call duty assignment
- Use a random number generator to select the next team member
- Manage the rotation schedule in a separate GitHub repository using YAML format

# Real-World Example
```bash
# on-call.sh
#!/bin/bash

# Include the random number generation function
. ./random.sh

# Get the list of team members and their schedules from the GitHub repository
TEAM_MEMBERS=$(curl --silent "https://api.github.com/repos/<ORG>/<REPO>/contents/schedules.yml" | jq -r '.content | fromjson | .[] | .name')

# Get the current time in Unix timestamp format
CURRENT_TIME=$(date +%s)

# Parse the current day of the week and month from the Unix timestamp
DAY_OF_WEEK=$(date -d @$CURRENT_TIME +%u)
MONTH=$(date -d @$CURRENT_TIME +%m)

# Define the function to get the team member based on the current day and month
get_team_member() {
  for TEAM_MEMBER in $TEAM_MEMBERS; do
    if [[ $TEAM_MEMBER == *"$1"*" ]]; then
      echo $TEAM_MEMBER
      return
    fi
  done
  echo "No matching team member found."
  return 1
}

# Get the team member responsible for on-call duties based on the current day and month
ON_CALL_MEMBER=$(get_team_member "$DAY_OF_WEEK-$MONTH")

# Assign the on-call duty to the selected team member using GitHub Actions
curl --request PATCH --header "Authorization: Bearer $GITHUB_TOKEN" --json '{"message": "Assigned on-call duty to $ON_CALL_MEMBER"}' "https://api.github.com/repos/<ORG>/<REPO>/issues/<ON_CALL_ISSUE>/comments" --data '{ "body": "Assigned on-call duty to $ON_CALL_MEMBER" }'
```
