# Interview Question
Can you explain how Terraform's "vector" data type is used to manage lists of resources in an infrastructure as code workflow?

# Answer
Terraform's "vector" data type is a dynamic list that allows managing multiple items of the same resource type in a single configuration. This is particularly useful when dealing with lists of resources that share similar attributes and require consistent configuration. Vectors enable infrastructure automation, improve configuration management, and facilitate scaling of resources.

# Key Technical Points
- Vectors in Terraform allow defining a list of resources as a single entity.
- The list elements within a vector can be accessed using indexing.
- Vectors can be populated with static values or dynamic data sources.

# Real-World Example
```hcl
variable "web_servers" {
  default = [
    {
      name        = "web-server-01"
      instance_type = "t2.micro"
      ami         = "ami-1774297842"
      subnet_id    = element(aws_subnet.subnets.*.id, 0)
    },
    {
      name        = "web-server-02"
      instance_type = "t2.micro"
      ami         = "ami-1774297842"
      subnet_id    = element(aws_subnet.subnets.*.id, 1)
    }
  ]
}

resource "aws_instance" "web_servers" {
  count         = length(var.web_servers)
  name          = var.web_servers[count.index]["name"]
  instance_type  = var.web_servers[count.index]["instance_type"]
  ami           = var.web_servers[count.index]["ami"]
  subnet_id      = var.web_servers[count.index]["subnet_id"]
}
```
In this example, the `web_servers` variable is a vector containing two elements, each of which specifies the name, instance type, AMI, and subnet ID for a web server instance. The `aws_instance` resource is configured to create a new instance for each element in the `web_servers` vector, resulting in two instances being created with consistent configurations.
