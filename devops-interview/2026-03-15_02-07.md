 # Interview Question
Can you explain your experience with configuring and managing Amazon Elastic Load Balancers using AWS CLI and Terraform?

# Answer
I have extensive experience in configuring and managing Amazon Elastic Load Balancers (ELBs) using both AWS Command Line Interface (CLI) and Terraform. ELBs distribute network traffic across multiple Amazon EC2 instances, improving application availability and scalability. With AWS CLI, I can perform various ELB management tasks such as creating, updating, and deleting load balancers, registering and deregistering instances, and modifying listener rules. Terraform, on the other hand, allows me to define and manage infrastructure as code, making it easier to automate and maintain ELB configurations as part of a larger infrastructure setup.

# Key Technical Points
- Familiarity with AWS CLI commands for creating, updating, and deleting load balancers, registering and deregistering instances, and modifying listener rules.
- Experience with Terraform to define and manage ELB configurations as part of a larger infrastructure setup.
- Understanding of how ELBs distribute network traffic and improve application availability and scalability.

# Real-World Example
```hcl
provider "aws" {
 region = "us-east-1"
}

output "load_balancer_url" {
 value = aws_lb.example.dns_name
}

resource "aws_lb" "example" {
 name               = "example-loadbalancer"
 internal           = false
 subnets            = [aws_subnet.example_subnet_1.id, aws_subnet.example_subnet_2.id]
 security_groups      = [aws_security_group.example_sg.id]

 listener {
   protocol        = "HTTP"
   port            = "80"
   default_action {
     target_group_arn = aws_lb_target_group.example.arn
   }
 }

 tags = {
   Name = "example-loadbalancer"
 }
}

resource "aws_lb_target_group" "example" {
 name        = "example-targetgroup"
 port        = 80
 protocol    = "HTTP"
 target_type = "instance"
 vpc_id       = aws_vpc.example.id
 health_check {
   port           = "traffic-port"
   protocol = "HTTP"
 }
}

resource "aws_instance" "example_instance" {
 count             = 2
 ami               = "ami-17735206769123456"
 instance_type     = "t2.micro"
 subnet_id          = aws_subnet.example_subnet_1.id
 vpc_security_group_ids = [aws_security_group.example_sg.id]
 tags = {
   Name = "example-instance-${count.index}"
 }

 provisioner "userdata" {
   file     = "userdata.sh"
 }

  tags = {
    Name = "example-instance-${count.index}"
  }
}

resource "aws_security_group" "example_sg" {
 name        = "example-security-group"
 description = "Example security group"
 vpc_id       = aws_vpc.example.id

 ingress {
   from_port   = 80
   to_port     = 80
   protocol    = "tcp"
   cidr_blocks = ["0.0.0.0/0"]
 }

 egress {
   from_port   = 0
   to_port     = 0
   protocol    = "-1"
   cidr_blocks = ["0.0.0.0/0"]
 }
}
```
This example demonstrates the usage of both AWS CLI and Terraform for creating and managing an Amazon Elastic Load Balancer, a target group, an instance, and a security group. The load balancer is configured to distribute traffic on port 80 using the HTTP protocol, and the target group is associated with the instances to receive the traffic. The security group allows incoming traffic on port 80 from any IP address.
