 # Interview Question
Please explain how you have implemented infrastructure as code using Terraform in a previous project.

# Answer
Infrastructure as code (IaC) is the practice of managing and provisioning computing infrastructure through machine-readable definition files, rather than through manual processes. Terraform is an open-source IaC tool from Hashicorp that provides a consistent CLI workflow to manage hundreds of cloud services. I have utilized Terraform in a previous project to provision and manage resources on AWS.

# Key Technical Points
- Terraform uses a declarative configuration language and a provider for the underlying cloud platform.
- The configuration files are written in Hashicorp Configuration Language (HCL) and can be versioned in Git.
- Terraform plans the desired state of your infrastructure and applies the minimum set of actions required to reach that state.

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
}

resource "aws_s3_bucket" "example_bucket" {
 enabled_encryption = "ServerSideEncryption-AES256"
 versioning {
 enabled = true
}
 tags = {
 Name = "example-bucket"
 Environment = "dev"
}
}
```
This example shows the creation of an AWS S3 bucket using Terraform. The bucket is encrypted at rest, versioning is enabled, and tags are added. Terraform's output can be used to view the created bucket's details. By having versioned and automatable configuration files, Terraform ensures consistency and reduces the risk of human error.
