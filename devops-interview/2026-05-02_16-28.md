# Interview Question
Please explain your experience with using Terraform to manage infrastructure as code, with a focus on security.

# Answer
I have extensive experience in implementing infrastructure as code using Terraform, a popular open-source tool from Hashicorp. Terraform allows us to define and provide data center infrastructure using a simple and consistent CLI workflow. I have implemented various security measures in Terraform, such as encrypting sensitive data using the Hashicorp Vault provider, implementing access controls using AWS IAM roles, and configuring secure network connections using SSL certificates.

# Key Technical Points
- Encrypting sensitive data using Hashicorp Vault provider
- Implementing access controls using IAM roles
- Configuring secure network connections using SSL certificates

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
}

provider "vault" {
 address = "http://localhost:8200"
}

locals {
 ssm_password = sha1("password123")
}

resource "aws_instance" "example" {
 ami           = "ami-0c55b159cbfafe1f0"
 instance_type = "t2.micro"

 vault {
 secret_id = "example-secret"
 data_json = jsonencode({
 username = "admin",
 password = local.ssm_password,
 })
}

tags = {
 Name = "example-instance"
}
}
```
In this example, we use Terraform to launch an EC2 instance, and we store the SSM password as a sensitive data within Vault. The password is encrypted and not stored in plaintext within the Terraform configuration. This approach enhances the security of our infrastructure by eliminating the need to store sensitive data in configuration files or share it via other means.
