 # Interview Question
Can you explain how to use Terraform to create and configure an Amazon S3 bucket?

# Answer
Terraform is an open-source infrastructure as code software tool from Hashicorp that enables you to safely and effectively provision and manage various cloud infrastructure services, including Amazon Web Services (AWS). To create and configure an Amazon S3 bucket using Terraform, you'll first need to install the Terraform provider for AWS, initialize your Terraform working directory, and write a Terraform configuration file (.tf) defining the S3 bucket resource.

# Key Technical Points
- Install the Terraform provider for AWS (`terraform init`) and authenticate it with your AWS account (`terraform configure`)
- Create a new S3 bucket using the `aws_s3_bucket` data source or resource in Terraform configuration file
- Configure bucket properties, such as versioning, server-side encryption, and lifecycle policies, using the `default_object_acl`, `versioning`, `server_side_encryption_configuration`, and `lifecycle_rule` attributes

# Real-World Example
```hcl
provider "aws" {
  region = "us-west-2"
}

resource "aws_s3_bucket" "example" {
  bucket_name = "example-bucket"
  versioning {
    enabled = true
  }
  server_side_encryption_configuration {
    rule {
      apply_server_side_encryption_by_default {
        sse_algorithm = "AES256"
      }
    }
  }

  lifecycle_rule {
    id      = "example-rule"
    prefix   = "infrequent"
    enabled  = true

    transition {
      days      = 30
      storage_class = "INTELLIGENT-GLACIER"
    }
  }
}
```
In this example, we create an S3 bucket named 'example-bucket', enable versioning, server-side encryption with AES-256, and apply a lifecycle rule that transitions objects in the 'infrequent' prefix to 'INTELLIGENT-GLACIER' storage class after 30 days.
