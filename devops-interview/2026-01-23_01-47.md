 # Interview Question
Can you explain how to securely configure Istio's Envoy filter chains using Istio's `Policy` and `DestinationRule` resources?

# Answer
Istio's Envoy filter chains can be secured by defining policies and destination rules using Istio's Custom Resource Definitions (CRDs). The `Policy` resource allows defining traffic access control rules, while the `DestinationRule` resource manages traffic routing. These resources are essential components of Istio's traffic management and security features.

# Key Technical Points
- The `Policy` resource enables defining rules for traffic access control and can be configured to drop, allow, or modify traffic based on conditions such as source and destination IP addresses, ports, and labels.
- The `DestinationRule` resource manages traffic routing by defining traffic policies for specific services, including traffic mirroring, rate limiting, and circuit breaking.
- Together, policies and destination rules help secure Istio's filter chains by allowing you to control traffic access and routing based on your organization's security policies.

# Real-World Example
```yaml
apiVersion: networking.istio.io/v1alpha3
kind: Policy
metadata:
  name: allow-traffic-from-corp-network
spec:
  match:
    source:
      sources:
      - ipBlocks:
          cidr: 10.0.0.0/16
  rules:
  - actions:
    - allow:
      ports:
      - number: 80
      protocol: TCP

---
apiVersion: networking.istio.io/v1alpha3
kind: DestinationRule
metadata:
  name: rate-limit-example
spec:
  host: my-app.example.com
  trafficPolicy:
    tls:
      mode: ISTIO_MUTUAL
    filters:
    - name: ratelimiter.istio.io/v1alpha1
      args:
        limit: 100
        burst: 20
        period: 60s
```
In this example, we create a `Policy` that allows traffic from the corporate network (IP range 10.0.0.0/16) to access the application hosted on `my-app.example.com`. We also define a `DestinationRule` for the same application that implements rate limiting with a limit of 100 requests per second and a burst of 20 requests.
