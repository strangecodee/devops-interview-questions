# Real-World Example
To monitor the Apache web server in Phoenix Project, I configured Prometheus to scrape metrics and store them in a time-series database. I set up Grafana to create interactive dashboards for visualizing the metrics, and created custom alerts for CPU usage and response time thresholds. Here is an example of a Prometheus configuration file for monitoring the Apache server:

```yaml
scrape_configs:
  - job_name: 'apache'
    static_configs:
      - targets: ['localhost:80']
    metrics_path: '/metrics'
    params:
      ModStatus: ['server_status']
    relabel_configs:
      - source_labels: [__address__]
        target_label: instance
        replacement: localhost:80
    label_match:
      __address__:
        regex: 'localhost:([0-9]+)'
    metrics:
      - __metrics
      - http_requests_total{code}
      - http_requests_duration_sum
      - http_requests_duration_bucket{le}
```

This configuration file allows Prometheus to scrape metrics from the Apache server and store them in the database, enabling real-time monitoring and alerting for critical KPIs.
