 # Interview Question
Can you explain how to configure a high availability load balancer using AWS Elastic Load Balancer (ELB) and Auto Scaling Group?

# Answer
The Amazon Elastic Load Balancer (ELB) is a fully managed service in AWS that automatically distributes incoming application traffic across a group of Amazon EC2 instances. By integrating ELB with an Auto Scaling Group (ASG), we can ensure high availability and automatic scaling of our application based on traffic demand.

Key Technical Points
- To set up ELB and ASG, begin by creating an ASG with at least 2-3 instances in different Availability Zones (AZs). Configure the instances with the required security groups and launch configurations.
- Create a new ELB load balancer, configure the listener protocol and port, and then add the ASG as a target group.
- Set up the health check for the ELB to monitor the instances' health based on custom URLs or port.
- Configure the Auto Scaling policies, such as scaling based on CPU utilization or network traffic, to maintain the desired capacity and handle traffic spikes.

# Real-World Example
```yaml
# ASG Launch Configuration
{
  "ImageId": "ami-0c94855ba95c574c8",
  "InstanceType": "t2.micro",
  "SecurityGroupIds": ["sg-01234567890abcdef0"],
  "KeyName": "my-instance-key"
}

# ASG Auto Scaling Policy
{
  "ScalingPolicies": [
    {
      "AdjustmentType": "ChangeInCapacity",
      "AdjustmentValue": 1,
      "Cooldown": 300,
      "ScalingSteps": [
        {
          "ChangeInCapacity": 1,
          "MetricInterface": "ELBCapacityUtilization",
          "ThresholdType": "UpperThreshold",
          "ThresholdValue": 80
        }
      ]
    }
  ]
}

# ELB Configuration
{
  "LoadBalancerName": "my-load-balancer",
  "Listener": {
    "ListenerName": "my-listener",
    "LoadBalancerPort": "80",
    "InstanceProtocol": "HTTP",
    "Protocol": "HTTP"
  },
  "AvailabilityZones": ["us-west-2a", "us-west-2b"],
  "HealthCheck": {
    "HealthCheckName": "my-healthcheck",
    "HealthCheckProtocol": "HTTP",
    "HealthCheckPort": "80",
    "HealthCheckPath": "/",
    "Interval": 300,
    "Timeout": 60,
    "UnhealthyThreshold": 2,
    "HealthyThreshold": 2
  },
  "Instances": [
    {
      "AvailabilityZone": "us-west-2a",
      "InstanceId": "i-12345678901234567",
      "InstanceHealth": "InService"
    },
    {
      "AvailabilityZone": "us-west-2b",
      "InstanceId": "i-09876543210987654",
      "InstanceHealth": "InService"
    }
  ],
  "TargetGroupArn": "arn:aws:elasticloadbalancing:us-west-2:123456789012:targetgroup/my-targetgroup/abcdef1234567890"
}
```
In this example, we create an ASG with a launch configuration, set up an Auto Scaling policy for scaling based on ELB capacity utilization, and create an ELB load balancer with a listener, health check, and target group configured with the ASG instances.
