 # Interview Question
Can you explain how you would configure a secure load balancer using a popular infrastructure-as-code tool like Terraform?

# Answer
I would configure a secure load balancer using Terraform by defining the necessary backend, provider, and load balancer resources with appropriate configurations. This includes setting up SSL certificates for secure communication, defining listener configurations for secure protocols like HTTPS, and configuring health checks to ensure only healthy instances are served.

# Key Technical Points
- Define backend and provider configurations to set up Terraform
- Configure SSL certificates for secure communication
- Define listener configurations for secure protocols (HTTPS)
- Set up health checks to ensure healthy instances

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
}

terraform {
 backend "s3" {
 bucket = "tf-bucket-name"
 key = "path/to/state/file"
 region = "us-west-2"
}
}

resource "aws_acm_certificate" "example_cert" {
 name = "example_cert"
 domain_name = "example.com"
 subject_alternative_names = ["www.example.com"]
}

resource "aws_lb" "example_lb" {
 name               = "example_lb"
 internal           = false
 load_balancer_type  = "application"
 security_groups = [aws_security_group.example_sg.id]
 subnet_ids         = [subnet_id_1, subnet_id_2]

 listener {
 id      = "http"
 port    = "80"
 protocol = "HTTP"
 default_action {
 type             = "forward"
 target_group_arn  = aws_lb_target_group.example_tg.arn
}
 ssl_certificate_arn = aws_acm_certificate.example_cert.arn
}

listener {
 id        = "https"
 port      = "443"
 protocol = "HTTPS"
 default_action {
 type             = "forward"
 target_group_arn  = aws_lb_target_group.example_tg.arn
}
 ssl_certificate_arn = aws_acm_certificate.example_cert.arn
}

health_check {
 name = "example_hc"
 target_port = "80"
 protocol = "HTTP"
 healthy_threshold = 3
 interval = 30
 timeout = 5
 unhealthy_threshold = 3
}

resource "aws_lb_target_group" "example_tg" {
 name = "example_tg"
 port = 80
 protocol = "HTTP"
 health_check = aws_health_check.example_hc.arn
 target_type = "ip"
 vpc_id = vpc_id
}
```
In this example, we configure an AWS load balancer using Terraform with SSL certificates, HTTP and HTTPS listeners, health checks, and target group resources. This results in a secure load balancer that serves traffic only over HTTPS and ensures only healthy instances are served.
