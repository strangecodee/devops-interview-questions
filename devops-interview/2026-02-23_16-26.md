 # Interview Question
Can you explain how to configure a high availability load balancer using a matrix of availability zones and health checks in Amazon Elastic Load Balancing (ALB)?

# Answer
In Amazon Elastic Load Balancing (ALB), you can configure a high availability load balancer by creating a listener and registering targets across multiple availability zones (AZs). ALB uses health checks to evaluate the health status of targets and distributes traffic to healthy targets. To ensure high availability, we can configure a listener to distribute traffic across multiple AZs using a listener rule with a target group and a listener rule protocol.

# Key Technical Points
- Create a target group with targets in multiple availability zones and configure health checks.
- Create a listener with a protocol (HTTP/HTTPS) and a listener rule to distribute traffic to the target group.
- Configure a listener rule to distribute traffic evenly across availability zones.

# Real-World Example
```yaml
Resources:
  TargetGroup:
    Type: "aws_lb_target_group"
    Name: "example-tg"
    VpcId: "vpc-12345678"
    Protocol: "HTTP"
    Port: "80"
    HealthCheck: {Ref: HealthCheck}
    Targets:
      - Id: "target-1-id"
      - Id: "target-2-id"
      - Id: "target-3-id"

  Listener:
    Type: "aws_lb_listener"
    Name: "example-listener"
    LoadBalancerArn: "arn:aws:elasticloadbalancing:us-west-2:123456789012:loadbalancer/app/example-lb/123456789012/1771844194"
    Protocol: "HTTP"
    Port: "80"

  ListenerRule:
    Type: "aws_lb_listener_rule"
    Name: "example-rule"
    ListenerArn: {Ref: Listener}
    TargetGroupArn: {Ref: TargetGroup}
    Action: "forward"
```
In this example, we create a target group with three targets and configure health checks. We then create a listener and register a listener rule that distributes traffic to the target group evenly across availability zones.
