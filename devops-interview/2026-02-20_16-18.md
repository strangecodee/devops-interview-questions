 # Interview Question
Can you explain how to use Terraform to deploy an Eclipse environment on AWS using an IAM role for security?

# Answer
Terraform is an open-source infrastructure as code software tool by Hashicorp that allows you to safely and efficiently manage infrastructure resources. In this context, we'll discuss deploying an Eclipse environment on Amazon Web Services (AWS) using Terraform and an IAM role for enhanced security.

First, configure your Terraform working directory with the required provider, AWS credentials, and version for the Eclipse AMI. Next, create an AWS IAM role with appropriate policies to grant permissions to the Terraform execution.

# Key Technical Points
- Configure Terraform with the AWS provider, credentials, and Eclipse AMI details.
- Create an IAM role for Terraform with necessary AWS permissions.
- Use Terraform data sources to reference and attach the IAM role to the launched EC2 instance.

# Real-World Example
```hcl
provider "aws" {
  region = "us-west-2"
}

data "aws_ami" "eclipse_ami" {
  most_recent = true
  filter {
    name   = "name"
    values = ["Eclipse-Photon-R-2021-03"]
  }
  filter {
    name   = "virtualization-type"
    values = ["hvm"]
  }
  filter {
    name   = "architecture"
    values = ["x86_64"]
  }
  owners = ["099720109477"] # Canonical
}

resource "aws_iam_role" "iam_for_ec2" {
  name = "iam_for_ec2"

  assume_role_policy = jsonencode({
    Version = "2012-10-17",
    Statement = [
      {
        Effect = "Allow",
        Principal = {
          Service = "ec2.amazonaws.com"
        },
        Action = "sts:AssumeRole"
      },
    ]
  })

  policies = [
    jsonencode({
      Name        = "PolicyForEC2Instances",
      Description = "Policy granting access to EC2 instances.",
      Policy = {
        Version = "2012-10-17",
        Statement = [
          {
            Effect = "Allow",
            Action = [
              "ec2:DescribeInstances",
              "ec2:DescribeInstanceStatus",
              "ec2:DescribeTags",
              "ec2:AttachVolume",
            ],
            Resource = "*"
          },
          {
            Effect = "Allow",
            Action = [
              "iam:PassRole",
              "iam:GetRole",
              "iam:ListRoles",
            ],
            Resource = aws_iam_role.iam_for_ec2.arn
          },
        ]
      }
    })
  ]
}

resource "aws_instance" "example" {
  ami           = data.aws_ami.eclipse_ami.id
  instance_type  = "t3.medium"
  iam_instance_profile = aws_iam_instance_profile.example.name
  associate_public_ip_address = false

  tags = {
    Name = "example-instance"
  }
}

resource "aws_iam_instance_profile" "example" {
  name = "example"
  role = aws_iam_role.iam_for_ec2.name
}
```

This example illustrates setting up an Eclipse environment on AWS using Terraform and an IAM role for enhanced security. It covers configuring Terraform, creating an IAM role, and attaching the role to the launched EC2 instance.
