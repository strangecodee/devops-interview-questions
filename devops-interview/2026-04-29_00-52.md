# Real-World Example
In a previous role, I set up a monitoring dashboard using Grafana and Prometheus to display system metrics and application performance data. By integrating alerting rules and escalation procedures, we were able to proactively identify and resolve issues before they impacted our users.

```yaml
# Monitoring Configuration (Excerpt)
prometheus:
  scrape_interval:     15s
  evaluation_interval: 15s

# Alerting Configuration (Excerpt)
alerting:
  alertmanagers:
    - alertmanager:
        web:
          path: "/alerts"
          scheme: "http"

# Grafana Configuration (Excerpt)
datasources:
  - name: Prometheus
    type: prometheus
    access: proxy
    url: "http://prometheus:9090"
```
