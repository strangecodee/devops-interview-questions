 # Interview Question
Can you explain how to set up monitoring for a containerized application using Prometheus and Grafana in a multi-node Kubernetes cluster?

# Answer
To monitor a containerized application in a multi-node Kubernetes cluster using Prometheus and Grafana, you should first install Prometheus as a Kubernetes daemon set for automatic discovery and scraping of container metrics. Subsequently, configure Prometheus to collect metrics from your application containers. Next, install Grafana as a Kubernetes deployment and set up a data source pointing to your Prometheus server. Lastly, create dashboards in Grafana to visualize and analyze the collected metrics.

# Key Technical Points
- Deploy Prometheus as a Kubernetes DaemonSet for automatic discovery and scraping of container metrics.
- Configure Prometheus to collect metrics from your application containers using a YAML configuration file.
- Install Grafana as a Kubernetes Deployment and set up a data source pointing to your Prometheus server.
- Create custom dashboards in Grafana to visualize and analyze the collected metrics.

# Real-World Example
```yaml
# Prometheus configuration
apiVersion: monitoring.coreos.com/v1
kind: ServiceMonitor
metadata:
  name: my-app
spec:
  selector:
    matchLabels:
      app: my-app
  endpoints:
  - port: http
    interval: 30s
    path: /metrics
---
# Grafana data source configuration
apiVersion: monitoring.grafana.org/v1beta1
kind: Datasource
metadata:
  name: prometheus
spec:
  type: prometheus
  access:
    proxy: false
  url: http://prometheus-server.default.svc.cluster.local:9090
```
In this example, Prometheus is configured as a Kubernetes ServiceMonitor to automatically discover and scrape metrics from containers labeled with the app name `my-app`. Meanwhile, Grafana is set up as a Kubernetes Datasource with the Prometheus server URL.
