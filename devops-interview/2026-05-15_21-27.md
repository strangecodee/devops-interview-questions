# Interview Question
Can you explain how to use Terraform's matrix data source for creating multiple instances with different configurations?

# Answer
Terraform's `matrix` data source allows creating multiple instances with distinct configurations based on a provided list of combinations. The configurations can be defined using maps, where keys represent unique instance identifiers, and values are configuration blocks.

# Key Technical Points
- Define a `matrix` data source with an input list of maps as arguments. Each map contains keys representing configuration parameters and their corresponding values.
- Use the `for_each` meta-argument in the resource block to iterate through the list of configurations generated by the `matrix` data source.
- Ensure that the configuration parameters are defined as input variables or hardcoded within the Terraform file to be passed as arguments to the `matrix` data source.

# Real-World Example
```hcl
provider "aws" {
  version = "4.35.0"
  region  = "us-west-2"
}

data "terraform_meta_arguments" "args" {
  # Define a list of maps with different instance configurations
  input = jsonencode([
    {
      instance_name = "instance-1",
      ami           = "ami-12345678",
      instance_type  = "t2.micro"
    },
    {
      instance_name = "instance-2",
      ami           = "ami-87654321",
      instance_type  = "t2.small"
    }
  ])
}

# Use the matrix data source
data "aws_ami" "ubuntu" {
  most_recent = true

  filter {
    name   = "name"
    values = ["ubuntu/images/hvm-ssd/ubuntu-focal-20.04-amd64-server-*"]
  }

  filter {
    name   = "virtualization-type"
    values = ["hvm"]
  }
}

# Define the matrix data source
data "terraform_data_matrix" "instances" {
  # Input comes from Terraform's built-in meta-argument
  input_data = data.terraform_meta_arguments.args.input

  # Define the instance resource using for_each
  for_each = { for config in data.terraform_data_matrix.instances : config.instance_name => config }

  instance_config {
    # Use the instance configuration from the matrix data source
    ami           = each.value.ami
    instance_type  = each.value.instance_type
    instance_name  = each.key

    # Launch the instance
    tags = {
      Name = each.key
    }

    vpc_security_group_ids = [aws_security_group.instance_security_group.id]
  }
}

# Output the instance IDs
output "instance_ids" {
  value = [for inst in data.terraform_data_matrix.instances : inst.instance_config.id]
}
```

In this example, we use the `terraform_meta_arguments` data source to define a list of maps representing different instance configurations. We then use the `terraform_data_matrix` data source with the `for_each` meta-argument to create multiple instances using the configurations from the list.
