# Real-World Example
Using Jenkins, I implemented a pipeline that automated the deployment of a microservice to production, including testing, security scanning, and rollback capabilities. I also established a rolling update strategy with canary releases, ensuring minimal downtime and maximum system availability.

```yaml
pipeline {
  agent any

  stages {
    stage('Build') {
      steps {
        maven {
          args '-B -DskipTests=true'
          keepsFile 'pom.xml'
        }
      }
    }

    stage('Test') {
      steps {
        junit '**/junit.xml'
      }
    }

    stage('Deploy') {
      environment {
        credentialsId 'my-credentials-id'
      }

      steps {
        withCredentials([credentials('my-credentials-id')]) {
          sh 'ssh user@remote-server "sudo docker pull my-image:latest"'
          sh 'ssh user@remote-server "sudo docker stop my-service"'
          sh 'ssh user@remote-server "sudo docker pull my-image:${env.BUILD_NUMBER}"'
          sh 'ssh user@remote-server "sudo docker stop my-service"'
          sh 'ssh user@remote-server "sudo docker run --rm -it -p 8080:8080 my-image:${env.BUILD_NUMBER}"'
          sh 'ssh user@remote-server "sudo systemctl restart my-service"'
        }
      }
    }
  }
}
```
