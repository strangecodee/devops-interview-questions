 # Interview Question
Can you explain how Terraform's "vector" data type is used to configure multiple resources in a single application?

# Answer
Terraform's "vector" data type allows users to define and manage lists or arrays of resources in a single application configuration. Vectors can be used to provision multiple instances of a resource with similar configurations, ensuring consistency across the environment. This can save time and effort in managing individual resource configurations.

# Key Technical Points
- Vectors can be defined using lists with square brackets [ ] in the Terraform configuration file.
- Each element in the vector can have unique configuration settings, but they must conform to the same resource type.
- Vectors can be used to create multiple instances of the same resource, such as EC2 instances, RDS instances, or load balancers.

# Real-World Example
```hcl
resource "aws_instance" "web_servers" {
  ami           = "ami-0c55b159cbfafe1f0"
  count         = length(var.instance_names)
  instance_name = element(var.instance_names, count.index)
  subnet_id     = aws_subnet.public_subnet.id
  key_name      = "my_key"

  tags = {
    Name = element(var.instance_names, count.index)
  }
}

output "instance_ids" {
  value = [for inst in aws_instance.web_servers : inst.id]
}
```
In this example, we define a vector of instance names in the `instance_names` variable, and use the `count` and `element` functions to create multiple instances of the `aws_instance` resource with unique names based on the vector elements. The resulting output will be a list of instance IDs.
