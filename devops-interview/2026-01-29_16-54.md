# Real-World Example
In one project, I used Ansible to automate the deployment and configuration of HAProxy load balancers. I wrote Ansible playbooks to install HAProxy, configure health checks, and define server pools. The configuration was version-controlled using Git, allowing for easy rollbacks and collaboration.
```yaml
---
- name: Deploy and Configure HAProxy
  hosts: loadbalancer
  tasks:
    - name: Install HAProxy
      apt: name=haproxy state=present
    - name: Configure HAProxy
      template: src=templates/haproxy.cfg dest=/etc/haproxy/haproxy.cfg
      notify: reload haproxy
```
This example illustrates the use of Ansible to automate the deployment and configuration of HAProxy on a load balancer. The `haproxy.cfg` template contains the HAProxy configuration, and the `reload` handler is used to restart the HAProxy service after configuration changes.
