# Interview Question
How would you approach setting up monitoring for a new microservice using Eclipse MicroProfile and Prometheus?

# Answer
To implement monitoring for a new microservice utilizing Eclipse MicroProfile and Prometheus, you would first ensure that the MicroProfile Metrics and Health checking JAX-RS endpoints are enabled in your application. Then, you would configure Prometheus to scrape metrics from the microservice by adding the microservice's endpoint to the Prometheus `prometheus.yml` configuration file. Key Technical Points:

- Enable MicroProfile Metrics and Health checking endpoints in your application
- Add the microservice's endpoint to the Prometheus configuration file

# Real-World Example
Consider an application named `my-microservice`:

1. Add the following dependencies to your `pom.xml` file:

```xml
<dependency>
  <groupId>io.micronaut</groupId>
  <artifactId>micronaut-metrics-registry-prometheus</artifactId>
</dependency>
<dependency>
  <groupId>io.micronaut.health</groupId>
  <artifactId>micronaut-health-io</artifactId>
</dependency>
```

2. Enable the Metrics and Health checking in your `application.properties` file:

```properties
micronaut.health.endpoint.enabled=true
micronaut.metrics.global.enabled=true
```

3. Configure Prometheus to scrape metrics:

```yaml
---
global:
  scrape_interval:     15s
  evaluation_interval: 1m

scrape_configs:
  - job_name: 'my_microservice'
    static_configs:
      - targets: ['localhost:8080/actuator/prometheus']
```
