# Real-World Example
In my previous role, I configured Nagios to monitor a highly-available Node.js application using custom checks and alerting. I created a performance-optimized check script using Node.js and NPM to monitor application response time. The script was set up as a custom Nagios plugin, which was then added to the Nagios configuration file. This allowed us to receive timely alerts whenever the application's performance degraded, ensuring we could address the issue before it affected end-users.

```bash
# Nagios configuration for Node.js application check
define check_command {
    command_name node_app_check
    script /path/to/node_check.sh
}

# Service definition for the Node.js application
service {
    host node_server
    service_description "Node.js Application"
    check_command node_app_check
}
```
