 # Interview Question
Can you explain how to configure Eclipse WASN with a HAProxy load balancer for high availability?

# Answer
To configure Eclipse WASN (WebSphere Application Server Natural) with a HAProxy load balancer for high availability, you need to perform the following steps:

First, ensure that your Eclipse WASN instance is properly installed and configured. Then, set up the HAProxy load balancer with the required backend servers. This involves defining the backend servers and their health checks in the HAProxy configuration file.

Next, you need to modify the Eclipse WASN configuration to listen on the IP address and port that the HAProxy load balancer will use. This can be done by editing the server.xml file.

Key Technical Points:
- Properly configure HAProxy with backend servers and health checks
- Modify Eclipse WASN configuration to listen on the HAProxy IP and port
- Ensure both HAProxy and Eclipse WASN are securely configured

# Real-World Example
To configure HAProxy with Eclipse WASN, first, define the backend servers in haproxy.conf:

```yaml
backend wasn
  mode http
  balance roundrobin
  option httpchk HEAD /healthcheck HTTP/1.1/1.1
  server wasn-server1 10.0.0.1:9080 check
  server wasn-server2 10.0.0.2:9080 check
```

Then, modify the Eclipse WASN configuration (server.xml) to listen on the HAProxy IP and port:

```xml
<server description="node0" name="node0" id="node0">
  <listenAddress interface="eth0" port="9080" />
  <adminListenAddress interface="eth0" port="9043" />
  <adminSecurity realm="was" loginConfig="LoginConfig">
    <loginConfig id="LoginConfig" className="com.ibm.ws.security.auth.WASLoginConfig">
      <property name="authMethod" value="BASIC"/>
    </loginConfig>
  </adminSecurity>
</server>
```

Finally, reload the HAProxy configuration and restart Eclipse WASN for the changes to take effect.
