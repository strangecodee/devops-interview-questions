# Real-World Example
Let's consider a scenario where we're using HAProxy to load balance traffic for an application named "Nebula" with three backend servers (identified by their IP addresses: 192.168.1.1, 192.168.1.2, and 192.168.1.3). To ensure high availability, we configure HAProxy to use a virtual server with the following details:

```haproxy
frontend nebula
bind *:80
default_backend servers

backend servers
server 192.168.1.1:80 check inter 5s rise 2 fall 2
server 192.168.1.2:80 check inter 5s rise 2 fall 2
server 192.168.1.3:80 check inter 5s rise 2 fall 2
```

This configuration sets up a frontend on port 80 and a backend named "servers". The backend servers are configured with health checks using the `check` directive, which ensures that HAProxy performs periodic inter 5s health checks. If a server fails two consecutive health checks, HAProxy will remove it from the load balancing rotation. Overall, this setup ensures that Nebula's traffic is distributed evenly across all three backend servers while also maintaining a high level of availability.
