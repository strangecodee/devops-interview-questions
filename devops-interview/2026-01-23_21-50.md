 # Interview Question
Please explain how you would implement a secure Terraform configuration for deploying an Amazon Elastic Kubernetes Service (EKS) cluster using Hashicorp Vault for secrets management.

# Answer
To implement a secure Terraform configuration for deploying an Amazon Elastic Kubernetes Service (EKS) cluster using Hashicorp Vault for secrets management, we'll first set up an IAM role with the necessary Amazon Web Services (AWS) permissions for Terraform, configure Terraform to use Vault as a backend for storing sensitive data, and then define the EKS cluster resources.

# Key Technical Points
1. Set up an IAM role for Terraform with the required AWS permissions.
2. Initialize Terraform with Hashicorp Vault as the backend and secure the API token.
3. Configure the Terraform provider for Amazon EKS and ECR, and define the EKS cluster and node group resources.
4. Use Vault to securely store and retrieve sensitive information (e.g., Amazon EKS Kubernetes worker node authentication data).

# Real-World Example
```hcl
provider "aws" {
  region     = "us-west-2"
  version    = "4.5.0"
}

provider "kubernetes" {
  version = "2.15.2"
}

provider "vault" {
  address = "http://localhost:8200"
  token   = data.vault_token.root.secret_id
}

data "vault_token" "root" {
  path = "root"
}

locals {
  eks_cluster_name = "quantum-eks-cluster-${md5(random_id.random.hex)}"
  eks_cluster_version = "1.22"
  eks_node_instance_type = "t3.medium.xlarge"
}

resource "aws_iam_role" "eks_cluster_role" {
  name = "${local.eks_cluster_name}-role"
  assume_role_policy_json = jsonencode({
    Version = "2012-10-17",
    Statement = [
      jsonencode({
        Effect = "Allow",
        Principal = {
          Service = "eks.amazonaws.com"
        },
        Action = "sts:AssumeRole"
      })
    ]
  })
}

resource "aws_iam_role_policy_attachment" "k8s_cluster_policy" {
  name       = "k8s-cluster-policy"
  policy_arn  = "arn:aws:iam::aws:policy/AmazonEKS_CNI_Policy"
  role       = aws_iam_role.eks_cluster_role.name
}

resource "aws_iam_role_policy_attachment" "k8s_AmazonEKSClusterPolicy" {
  name       = "k8s-AmazonEKSClusterPolicy"
  policy_arn  = "arn:aws:iam::aws:policy/AmazonEKSClusterPolicy"
  role       = aws_iam_role.eks_cluster_role.name
}

resource "aws_iam_role_policy_attachment" "k8s_AmazonEKSNodesPolicy" {
  name       = "k8s-AmazonEKSNodesPolicy"
  policy_arn  = "arn:aws:iam::aws:policy/AmazonEKSNodesPolicy"
  role       = aws_iam_role.eks_cluster_role.name
}

resource "aws_eks_cluster" "eks_cluster" {
  name     = local.eks_cluster_name
  role_arn  = aws_iam_role.eks_cluster_role.arn
  version  = local.eks_cluster_version

  vpc_config {
    subnet_ids = [aws_subnet.subnet_1.id, aws_subnet.subnet_2.id]
  }

  tags = {
    Name = local.eks_cluster_name
  }
}

resource "aws_eks_nodegroup" "eks_nodegroup" {
  cluster_name = aws_eks_cluster.eks_cluster.name
  nodegroup_name = "${local.eks_cluster_name}-nodegroup"
  subnet_ids = [aws_subnet.subnet_1.id, aws_subnet.subnet_2.id]
  instance_role = aws_iam_role.eks_cluster_role.arn
  instance_types = [local.eks_node_instance_type]
  ami_type = "AL2_x86_64"

  scaling_config {
    min_size = 2
    max_size = 10
  }
}

output "k8s_config" {
  value = kubernetes_config.eks_config.raw_config
}

provider "kubernetes" {
  config_context = "eks-workshop"
}

resource "kubernetes_config" "eks_config" {}
```
This example demonstrates the setup of an IAM role for Terraform, AWS EKS cluster, and node group using Terraform, with Hashicorp Vault used for storing the API token securely.
