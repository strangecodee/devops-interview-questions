# Real-World Example
```yaml
apiVersion: networking.istio.io/v1alpha3
kind: VirtualService
metadata:
  name: my-microservice
spec:
  hosts:
    - my-microservice
  http:
    routes:
    - match:
        path: /api/*
      route:
        destination:
          host: backend-service
          port:
            number: 80
```
In this example, I create a virtual service for `my-microservice` using Istio, which routes incoming traffic to `backend-service` for the `/api/*` path. This configuration is just a small part of the larger Istio traffic management setup that I have implemented and managed in production environments.
