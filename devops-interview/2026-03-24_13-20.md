# Interview Question
Can you explain how to use Terraform to deploy infrastructure on AWS and ensure availability through Auto Scaling groups?

# Answer
Terraform is an open-source Infrastructure as Code (IaC) tool that enables you to define, provision, and manage infrastructure safely and efficiently. You can use Terraform to deploy and manage resources on AWS, including Auto Scaling groups to ensure high availability and scalability.

Key Technical Points:
- Terraform uses a declarative configuration language to define and provide data about your desired state for your IT infrastructure.
- It integrates seamlessly with AWS, allowing you to configure and deploy resources such as EC2 instances, S3 buckets, and Auto Scaling groups.
- Auto Scaling groups allow you to automatically adjust the number of instances in a pool based on demand, ensuring high availability and scalability.

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
}

resource "aws_launch_configuration" "example" {
 name_prefix = "example-lc"
 image_id = "ami-0c94855ba95b79866"
 instance_type = "t2.micro"
 user_data = file("userdata.sh")
 security_groups = ["sg-01234567890abcdef0"]
}

resource "aws_auto_scaling_group" "example" {
 name = "example-asg"
 launch_configuration = aws_launch_configuration.example.name
 vpc_zone_identifier = ["subnet-12345678", "subnet-23456789"]
 desired_capacity = 2
 min_size = 2
 max_size = 4
}
```
In this example, we define an AWS provider and create a launch configuration for an EC2 instance using Terraform. We then create an Auto Scaling group that uses this launch configuration and sets the desired capacity to 2 instances, with a minimum and maximum capacity of 2 and 4 instances, respectively. This ensures that the infrastructure stays within these limits while maintaining high availability through Auto Scaling.
