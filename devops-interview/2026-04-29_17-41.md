# Real-World Example
```yaml
image: docker:latest

stages:
  build:
    script:
      - apt-get update -y
      - apt-get install -y build-essential
      - git clone https://github.com/<username>/<repository>.git
      - cd <repository>
      - make

  test:
    stage: test
    script:
      - docker build -t <image-name>:<build-number> .
      - docker run <image-name>:<build-number> --rm <test-command>

  deploy:
    stage: deploy
    script:
      - echo "Deploying to production"
      - docker build -t <image-name>:<production> .
      - docker tag <image-name>:<production> <registry>:<port>/<image-name>:<production>
      - docker push <registry>:<port>/<image-name>:<production>
      - <deploy-command>
```
In this example, I demonstrate GitLab CI/CD pipeline configuration with Docker build and deployment. This pipeline includes building the Docker image, running tests, and deploying the container to a production environment. It also showcases the security-focused approach by using a private registry and keeping the image tags unique (using `<build-number>` and `<production>`).
