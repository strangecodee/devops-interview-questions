# Real-World Example
Here's an example of configuring Istio's traffic management using the VirtualService resource:

```yaml
apiVersion: networking.istio.io/v1alpha3
kind: VirtualService
metadata:
  name: my-service
spec:
  hosts:
  - my-service
  http:
  - route:
    - destination:
        host: target-service
        port:
          number: 80
```

This configuration sets up a virtual service for "my-service" that routes incoming traffic to "target-service" on port 80. By using Istio's traffic management features, we can easily manage and distribute traffic between different services in a production environment. (Seed: 1771598148)
