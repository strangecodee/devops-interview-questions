# Real-World Example
Consider a scenario where we are deploying a new version of a web application using the Phoenix web framework. To ensure a seamless transition, we will leverage Amazon Elastic Load Balancer (ELB) to distribute traffic between the old and new instances. We will configure ELB to use a health check that validates the health of the instances based on their response times. We will also configure ELB to use the Session Stickiness feature to ensure that users' sessions are maintained across requests to the same instance. Here is an example YAML configuration for the ApplicationLoadBalancer:

```yaml
Resources:
  MyApplicationALB:
    Type: 'AWS::ElasticLoadBalancing::ApplicationLoadBalancer'
    Properties:
      LoadBalancerName: 'MyApplicationALB'
      Scheme: 'internet-facing'
      SecurityPolicies:
        - Arn: 'arn:aws:elasticloadbalancing:region:us-east-1:policy/ElasticLoadBalancing_AddSecurityGroup'
          PolicyName: 'ELBSecurityPolicy'
          PolicyArns:
            - 'arn:aws:iam::aws:policy/ELB_ManagedPolicy'
      Listeners:
        - Protocol: 'HTTP'
          LoadBalancerPort: '80'
          InstanceProtocol: 'HTTP'
          InstancePort: '80'
          SSLCertificateId: 'ArnOfMySSLCertificate'
      AvailabilityZones: ['us-east-1a', 'us-east-1b']
      Subnets: ['SubnetID1', 'SubnetID2']
      SecurityGroups: ['SecurityGroupID']
      IdleTimeout: '300'
      ConnectionDraining: 'ENABLED'
      ConnectionDrainingTimeout: '300'
      HealthCheck:
        TargetGroupArn: 'ArnOfMyTargetGroup'
        Port: '80'
        Protocol: 'HTTP'
        HealthCheckPath: '/health'
        HealthCheckInterval: '30'
        HealthCheckTimeout: '5'
        HealthyThreshold: '2'
        UnhealthyThreshold: '2'
      Policies:
        - PolicyName: 'ELB_Policy_Name'
          PolicyArn: 'ArnOfMyELBPolicy'
          Type: 'REDIRECT_URL'
          RedirectUrl: 'https://{YourWebsite}/'
```
