 # Interview Question
Can you explain how to use Terraform to deploy an Amazon Elastic Kubernetes Service (EKS) cluster and an Auto Scaling Group (ASG)?

# Answer
Terraform is an open-source infrastructure as code software tool from Hashicorp that enables you to safely and effectively provision and manage infrastructure on various cloud platforms, including Amazon Web Services (AWS). In this scenario, we will demonstrate how to use Terraform to deploy an Amazon Elastic Kubernetes Service (EKS) cluster and an Auto Scaling Group (ASG) for the worker nodes.

Key Technical Points:
- Write a `.tf` file using Terraform configuration language to define the EKS cluster and ASG resources.
- Initialize your working directory with the Terraform provider for AWS by running `terraform init`.
- Apply the configuration with `terraform apply` to create the resources in your AWS account.
- Configure the EKS cluster and ASG through Terraform configuration, including setting up the node security group, desired number of instances, and other desired attributes.

# Real-World Example
```hcl
provider "aws" {
 region = "us-west-2"
 version = "4.54.0"
}

# Define the EKS Cluster
resource "aws_eks_cluster" "example" {
 name = "example-eks-cluster"
 version = "1.23.3-x86_64"
 cluster_configuration {
 worker_node_groups = [
 {
 name = "worker-node-group"
 subnets = [
 for subnet_id in aws_subnet.example.*.id : subnet_id
 ]
 instance_types = ["t3.medium.xlarge"]
 asg_desired_capacity = 2
 asg_max_size = 6
 asg_min_size = 2
 ami_type = "AL2_x86_64"
 vpc_security_group_ids = [aws_security_group.example.id]
 tags = {
 Name = "example-eks-cluster"
 Environment = "production"
 }
 }
 ]
 }

 # Define the EKS Node Security Group
 resource "aws_security_group" "example" {
 name = "example-eks-node-sg"
 description = "Example security group for EKS nodes"
 vpc_id = data.aws_vpc.example.id
 ingress {
 from_port = 0
 to_port = 0
 protocol = "-1"
 cidr_blocks = ["0.0.0.0/0"]
 }
}

 # Define the EKS Subnets
 data "aws_vpc" "example" {
 id = var.vpc_id
}

 resource "aws_subnet" "example" {
 count = 2
 cidr_block = "10.0.${count.index}.0/24"
 vpc_id = data.aws_vpc.example.id
 availability_zone = "us-west-2a${count.index % 2 + 1}"
 tags = {
 Name = "example-subnet-${count.index}"
 Environment = "production"
 }
}

 # Initialize Terraform
 terraform init

 # Apply the configuration
 terraform apply
```
In this example, we define an EKS cluster with a single node security group and two subnets, and a worker node group with an Auto Scaling Group (ASG) for the worker nodes. The ASG is configured to have a minimum size of 2 and a maximum size of 6 instances. This example demonstrates how to use Terraform to deploy an EKS cluster and an ASG in a simple and effective manner.
