# Real-World Example
Consider a scenario where I was tasked with ensuring the availability of a mission-critical application in an enterprise environment. I set up monitoring rules in Sentinel using a YAML configuration file:

```yaml
rules:
  - alert: AppAvailability
    expr: sum(rate(container_status_up{container_name="app"}[5m])) by (namespace,container) > 0
    for: 5m
    annotations:
      description: "App availability is above 0"
      message: "Application '{{$namespace}}/{{$container}}' is available"
      severity: warning
```

This rule monitors the availability of the application container and, when it detects more than one instance running within a 5-minute time window, triggers a warning alert. By leveraging Sentinel's powerful query language and alerting capabilities, I was able to quickly identify and resolve potential issues, ensuring the application remained available and functional for our users.
