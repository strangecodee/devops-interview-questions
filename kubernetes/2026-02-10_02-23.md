 # Kubernetes Concept
Deployment is a Kubernetes object used for creating, updating, and managing containerized applications.

# Explanation
A Deployment creates and manages replicas of a specified container image, ensuring a specified number of replicas are running and available. Kubernetes rolls out updates to the replicas in batches, allowing for easy and safe rollbacks if necessary.

# Best Practices
- Use rolling updates to minimize downtime during upgrades.
- Set up replica count and update strategy in the Deployment YAML.
- Monitor application health and performance using Liveness and Readiness probes.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: aws_account_id.dkr.ecr.region.amazonaws.com/phoenix:v1
        ports:
        - containerPort: 8080
        livenessProbe:
          httpGet:
            path: /healthz
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /healthz
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
```
