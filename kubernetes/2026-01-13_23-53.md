 # Kubernetes Deployment
This Kubernetes concept refers to the declaration and orchestration of a set of containers, their desired state, and updates thereof.

# Explanation
A Deployment in Kubernetes manages the lifecycle of a set of replicas for a desired application version. It ensures that a specified number of replicas are running at any given time and can perform rolling updates to upgrade the application version.

# Best Practices
- Use labels for easy identification and management of your deployments.
- Implement rolling updates to minimize downtime and ensure high availability.
- Use health checks and liveness probes to monitor the application's health.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-deployment
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
