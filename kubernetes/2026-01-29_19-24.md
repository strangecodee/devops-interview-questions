 # Kubernetes Concept
Deployment is a Kubernetes object used for creating and managing containerized applications. It ensures that a specified number of replicas of a container are running at any given time.

# Explanation
A Deployment creates and manages the lifecycle of containers, including automated rolling updates and self-healing, which restarts containers that fail. This is crucial to maintaining a desired state for applications.

# Best Practices
- Ensure proper resource utilization by configuring limits and requests for container resources.
- Use Rolling Update strategy for minimal downtime during updates.
- Implement Readiness and Liveness probes to ensure containers are ready to serve traffic and are functioning correctly.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
      imagePullSecrets:
      - name: my-secret
      readinessProbes:
      - apiVersion: v1
        kind: Probe
        name: readiness
        exec:
          command: ["/usr/local/bin/readiness"]
      livenessProbes:
      - apiVersion: v1
        kind: Probe
        name: liveness
        exec:
          command: ["/usr/local/bin/liveness"]
```
