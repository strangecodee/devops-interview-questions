 # Kubernetes Concept
Deployment is a Kubernetes object used for creating, updating, and managing containerized applications. It ensures availability, scalability, and rollbacks.

# Explanation
A Deployment creates and manages a desired state for a set of Pods, updating the population as new replicas are created and old ones are terminated. It also handles rolling updates and rollbacks, ensuring smooth transitions between versions.

# Best Practices
- Use rolling updates with progress deadlines for minimal downtime.
- Perform resource limiting and request optimization.
- Use liveness and readiness probes for monitoring application health.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula-container
        image: 1771876599.dkr.ecr.us-west-2.amazonaws.com/nebula:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
This YAML defines a Kubernetes Deployment named `nebula-app` with three replicas. The container image source is specified, and both liveness and readiness probes are defined. The container's port is also configured.
