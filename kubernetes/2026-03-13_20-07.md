 # Kubernetes Concept
Kubernetes Deployment is a declarative way to update and manage containerized applications at scale.

# Explanation
A Kubernetes Deployment creates and manages replicas of a containerized application, ensuring a specified number of instances are running and available. It also handles rolling updates and rollbacks, automating the process of updating the containers in the replicas with minimal downtime.

# Best Practices
- Use rolling updates with minimal replicas to ensure zero downtime.
- Set resource limits and requests for the containers to ensure optimal performance and resource utilization.
- Use health checks and liveness probes to automatically detect and recover from failures.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-app:v1.0.0
        ports:
        - containerPort: 80
        resources:
          limits:
            cpu: "1"
            memory: "512Mi"
          requests:
            cpu: "0.5"
            memory: "256Mi"
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
