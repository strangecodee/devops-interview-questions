 # Kubernetes Concept: DaemonSet
A DaemonSet ensures all or a specific number of replicas of a pod are running on each node in a cluster.

# Explanation
DaemonSets maintain a specific number of replicas of a pod on each node in the cluster. This is particularly useful for running system services or daemons as they should be running on all nodes for availability and consistency. DaemonSets automatically handle node joins and leaves by creating or deleting replicas as needed.

# Best Practices
- Use DaemonSets for system services and daemons that should be running on all nodes.
- Define custom labels and selectors to ensure DaemonSets are placed on the correct nodes.
- Use readiness and liveness probes to monitor and manage DaemonSet pods.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: nginx-daemonset
spec:
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
        readinessProbe:
          probes:
          - exec:
              command: ["nginx", "--test-log"]
            intervalSeconds: 5
        livenessProbe:
          probes:
          - exec:
              command: ["nginx", "--test-log"]
            intervalSeconds: 15
```
