 # Kubernetes Concept
Deployment is a Kubernetes resource that creates and manages a set of replicas for a containerized application.

# Explanation
A Deployment in Kubernetes ensures a specified number of replicas of a containerized application are running at any given time, and it can perform rolling updates and rollbacks.

# Best Practices
- Use rolling updates for minor changes to minimize downtime.
- Configure the minimum number of replicas to ensure availability.
- Use readiness and liveness probes to check the health of your containers.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
spec:
  selector:
    matchLabels:
      app: my-app
  replicas: 3
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app
        image: my-image:latest
        ports:
        - containerPort: 80
        readinessProbe:
          probes:
          - exec:
              command: ["/usr/local/bin/check-readiness"]
        livenessProbe:
          probes:
          - exec:
              command: ["/usr/local/bin/check-liveness"]
```
