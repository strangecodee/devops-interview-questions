 # Kubernetes Concept: Deployment
A Kubernetes Deployment manages the lifecycle of a set of replicas for a desired number of available instances of a container.

# Explanation
Deployments in Kubernetes provide declarative updates for applications by creating new replicas while old ones are rolled out. This ensures that the desired state for the application is always maintained. It also handles rolling back to a previous version if necessary.

# Best Practices
- Use rolling updates for minimal downtime.
- Set up readiness and liveness probes to ensure the health of your containers.
- Use labels and selectors efficiently for better management and scaling.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-deployment
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
          name: http
        readinessProbe:
          httpGet:
            path: /healthz
            port: 80
        livenessProbe:
          httpGet:
            path: /liveness
            port: 80
```
