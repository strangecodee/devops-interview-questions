 # Kubernetes Concept
Deployment is a Kubernetes object used for creating and updating containerized applications.

# Explanation
A Deployment manages the lifecycle of a set of replicas, maintaining a specified number of available instances of a Pod, and performs rolling updates or rollbacks as necessary.

# Best Practices
- Use rolling updates to update your applications gradually to minimize downtime and reduce the risk of errors.
- Set up readiness and liveness probes to ensure your containers are running properly and ready to receive traffic.
- Use labels to identify and manage your pods effectively.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-container
        image: my-container-image:latest
        ports:
        - containerPort: 80
        readinessProbe:
          probeType: HTTP
          httpGet:
            path: /healthz
            port: 80
        livenessProbe:
          probeType: HTTP
          httpGet:
            path: /liveness
            port: 80
```
