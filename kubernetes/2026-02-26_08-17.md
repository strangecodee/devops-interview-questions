 # Kubernetes Concept
Deployment is a Kubernetes object used for deploying and managing containerized applications. It provides declarative updates for containerized applications.

# Explanation
A Deployment creates and manages a set of replicas of a containerized application. It ensures that a specified number of replicas are running at any given time, and automatically creates new replicas if old ones fail, or if scaling is required.

# Best Practices
- Use rolling updates for minimal downtime.
- Use health checks to ensure that the containers are running as expected.
- Use readiness probes to check that the containers are ready to accept traffic.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:v1
        ports:
        - containerPort: 8080
          protocol: TCP
        readinessProbe:
          probeName: ready-probe
          exec:
            command: ["/usr/local/bin/check-ready.sh"]
          intervalSeconds: 5
      imagePullSecrets:
      - name: regcred
```
