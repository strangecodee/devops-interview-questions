 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications by declaring and updating their desired state.

# Explanation
A Kubernetes Deployment manages the rollout and scaling of pods, maintaining a specified number of available replicas. It allows rolling updates and can automatically rollback to a previous version if the new one fails. The newly created pods are subjected to a readiness probe and a liveness probe for efficient health assessment.

# Best Practices
- Use labels for easier management and selection of pods.
- Set up resource limits and requests to ensure adequate resources for the applications.
- Use rolling updates for minimal downtime and maximum availability.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: atlas-deployment
  labels:
    app: atlas
spec:
  replicas: 3
  selector:
    matchLabels:
      app: atlas
  template:
    metadata:
      labels:
        app: atlas
    spec:
      containers:
      - name: atlas
        image: registry.example.com/atlas:v1
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /readiness
            port: 80
```
