 # Kubernetes Concept
Deployment is a Kubernetes resource for managing containerized applications. It ensures that a specified number of replicas of a container image are running and available.

# Explanation
A Deployment in Kubernetes manages the lifecycle of containers and creates or updates Pods based on changes to container images, configuration, or other parameters. ReplicaSets are used under the hood to ensure the desired number of replicas are running and available. Rollouts and rollbacks can be performed seamlessly with minimal downtime.

# Best Practices
- Use labels for efficient filtering and management of your Deployments.
- Set up a rolling update strategy to minimize downtime.
- Implement a liveness and readiness probes for monitoring your application's health.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
          name: http
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 15
          periodSeconds: 30
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
          initialDelaySeconds: 15
          periodSeconds: 5
```
