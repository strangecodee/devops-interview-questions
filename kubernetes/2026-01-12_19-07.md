 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications. It ensures availability, rollouts, and rolling updates for an application.

# Explanation
A Deployment creates and manages ReplicaSets, which maintain a specified number of replicas of a desired pod. When a new version of an application is released, Deployments can perform rolling updates, gradually replacing old replicas with new ones.

# Best Practices
- Use rolling updates to minimize downtime and ensure high availability.
- Use labels to selectively update or manage pods based on specific attributes.
- Use a replica count higher than one to ensure availability in case of pod failure.

# YAML Example (Nginx deployment)
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    app: nginx
spec:
  selector:
    matchLabels:
      app: nginx
  replicas: 3
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
          name: http
        - containerPort: 443
          name: https
        readinessProbe:
          tcpSocket:
            port: 80
        livenessProbe:
          httpGet:
            path: /
            port: 80
          failureThreshold: 3
```
