 # Kubernetes Concept
Deployment is a kind of Kubernetes resource for creating and managing stateless applications. It guarantees a specified number of replicas of a container image.

# Explanation
A Deployment creates or updates containers in a Pod (a logical host for a running process) based on a predefined container image and configuration. Kubernetes maintains a desired state, managing the lifecycle of containers and rolling out updates as needed.

# Best Practices
- Use rolling updates: Update pods one at a time to reduce the risk of downtime.
- Use readiness and liveness probes: Monitor pods and containers for readiness and responsiveness.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: atlas
spec:
  replicas: 3
  selector:
    matchLabels:
      app: atlas
  template:
    metadata:
      labels:
        app: atlas
    spec:
      containers:
        - name: atlas
          image: atlas:1.0.0
          ports:
            - containerPort: 80
          readinessProbe:
            probeType: HTTP
            port: 80
            path: /healthz
          livenessProbe:
            probeType: HTTP
            port: 80
            path: /healthz
```
This example demonstrates a Kubernetes Deployment that creates three replicas of an `atlas` container with the image `atlas:1.0.0`. It sets up readiness and liveness probes using HTTP to check the `/healthz` endpoint.
