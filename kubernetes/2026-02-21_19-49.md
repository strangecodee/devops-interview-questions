 # Kubernetes Concept
Deployment is a Kubernetes resource for managing containerized applications by creating, updating, and scaling replicas.

# Explanation
A Deployment in Kubernetes manages the lifecycle of a set of replica Pods, ensuring availability and continuity of the application. It provides options for rolling updates and rolling back to previous versions, enabling Zero-Downtime Deployments.

# Best Practices
- Use a rolling update strategy to minimize downtime.
- Set up a rolling update strategy with a predefined percentage of new replicas before draining old ones.
- Implement readiness and liveness probes to monitor application health and maintain optimal availability.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 1
      maxSurge: 1
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:v1.0.0
        ports:
        - containerPort: 8080
        readinessProbe:
          probes:
          - exec:
              command: ["/app/bin/check-readiness"]
          intervalSeconds: 15
        livenessProbe:
          probes:
          - exec:
              command: ["/app/bin/check-liveness"]
          intervalSeconds: 30
```
