 # Kubernetes Concept
Deployment is a way to create, update, and manage containerized applications on the Kubernetes platform.

# Explanation
A Deployment creates a desired state for a set of replicas, ensuring that a specified number of pods are running at any given time. It can perform rolling updates, rolling back to previous versions, and scaling based on resource usage or external triggers.

# Best Practices
- Use labels for logical grouping and selective deletion or scaling.
- Configure horizontal pod autoscaling to maintain optimal resource usage.
- Implement readiness and liveness probes for efficient rolling updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
  labels:
    app: phoenix
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:v1.0
        ports:
        - containerPort: 8080
        livenessProbe:
          httpGet:
            path: /healthz
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /ready
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 5
```
