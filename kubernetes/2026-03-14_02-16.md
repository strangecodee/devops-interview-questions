 # Kubernetes Concept
Kubernetes DaemonSet is a deployment strategy that ensures a specified number of replicas of a Pod are running on each node in the cluster.

# Explanation
DaemonSets are useful for deploying processes that require special access to the node, such as a logging agent or a monitoring agent. By ensuring that the desired number of replicas is running on each node, DaemonSets help maintain system consistency and availability.

# Best Practices
- Use labels to target specific nodes.
- Use health checks to ensure the DaemonSet is functioning correctly.
- Use rolling updates for minimal downtime.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: logging-agent
  labels:
    app: logging-agent
spec:
  selector:
    matchLabels:
      app: logging-agent
  template:
    metadata:
      labels:
        app: logging-agent
    spec:
      containers:
      - name: logging-container
        image: logging-agent:latest
        ports:
        - containerPort: 514
        readinessProbes:
        - exec:
            command: ["/bin/sh", "-c", "wc -c < /dev/urandom > /tmp/output && [ $? -eq 0 ]"]
            intervalSeconds: 5
          failureThreshold: 3
```
This DaemonSet ensures that a `logging-agent` container is running on every node in the cluster, with a readiness probe to ensure the container is functioning correctly. The container listens on port 514 and runs a command to check that it can generate random output as a readiness check.
