 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications. It ensures that a specified number of replicas of a container image are running at any given time, and can perform rolling updates or rollbacks.

# Explanation
A Deployment creates and manages replica sets and replaces instances with new ones if needed, ensuring high availability and scaling. It also allows for rollbacks to previous versions and rolling updates with minimal downtime.

# Best Practices
- Use labels for better organization and selectors for easy updating or scaling of your application.
- Use rolling updates for minimal downtime and to ensure new versions are fully functional before rolling out to all replicas.
- Use a liveness probe to check if the container is running correctly and a readiness probe to check if the container is ready to receive traffic.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-app
  labels:
    app: nebula
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula-container
        image: nebula/image:1.0.0
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
