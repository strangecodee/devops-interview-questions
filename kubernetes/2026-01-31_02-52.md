 # Kubernetes Concept
This example demonstrates a simple `Deployment` for a containerized Java application using an `eclipse-jdk` image, managed by Kubernetes.

# Explanation
The `Deployment` is a Kubernetes resource for creating and managing a set of replicas for a containerized application. In this example, we create a `Deployment` for a Java application using the `eclipse-jdk` image. The `ReplicaSet` ensures that a specified number of replicas are running at any given time. The `Liveness Probe` checks the application's health, and the `Readiness Probe` verifies that the container is ready to receive traffic.

# Best Practices
1. Use `Labels` and `Annotations` for easier management and organization.
2. Use `Resource Limits` to ensure fair resource allocation.
3. Implement `Rolling Updates` for minimal downtime during updates.

# YAML Example

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: java-app
  labels:
    app: java
  annotations:
    app.kubernetes.io/managed-by: "Terraform"
spec:
  selector:
    matchLabels:
      app: java
  replicas: 3
  template:
    metadata:
      labels:
        app: java
    spec:
      containers:
      - name: java
        image: eclipse:openj9:alpine-jdk13
        ports:
        - containerPort: 8080
        livenessProbe:
          httpGet:
            path: /health-check
            port: 8080
        readinessProbe:
          httpGet:
            path: /
            port: 8080
        resources:
          limits:
            cpu: "1"
            memory: "512Mi"
          requests:
            cpu: "500m"
            memory: "256Mi"
```
