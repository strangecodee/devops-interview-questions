 # Kubernetes Concept
This is an example of a DaemonSet in Kubernetes, designed for monitoring nodes using Prometheus.

# Explanation
A DaemonSet ensures that a copy of the specified Pod runs on each node in the cluster, maintaining a consistent monitoring solution across the entire infrastructure. In this example, we deploy Prometheus as a DaemonSet to monitor nodes.

# Best Practices
- Use `imagePullSecrets` to securely pull Docker images.
- Run Prometheus as a non-root user for added security.
- Set up persistent storage for data retention.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: nebula-prometheus
  labels:
    app: nebula-prometheus
spec:
  selector:
    matchLabels:
      app: nebula-prometheus
  template:
    metadata:
      labels:
        app: nebula-prometheus
    spec:
      imagePullSecrets:
      - name: my-registry-secret
      containers:
      - name: nebula-prometheus
        image: prom/prometheus:v2.32.0
        ports:
        - containerPort: 9090
        args:
        - --config.file=/etc/prometheus/prometheus.yml
        volumeMounts:
        - name: prometheus-storage
          mountPath: /prometheus
      securityContext:
        runAsUser: 1001
      volumes:
      - name: prometheus-storage
        persistentVolumeClaim:
          claimName: nebula-prometheus-pvc
```
This YAML example demonstrates a DaemonSet named `nebula-prometheus` that ensures Prometheus is installed as a daemon on each node. The DaemonSet uses an image pull secret for security, runs Prometheus as a non-root user, and sets up persistent storage for data retention.
