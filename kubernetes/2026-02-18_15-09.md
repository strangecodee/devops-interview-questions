 # Kubernetes Concept
This example demonstrates a Deployment in Kubernetes for a Java application using the Eclipse Jetty web server, focusing on zero-downtime deployments.

# Explanation
A Kubernetes Deployment manages the lifecycle of a set of replicas for a desired application, ensuring high availability and scalability. In this example, we will use a single replica Deployment for an Eclipse Jetty Java application. The zero-downtime strategy is achieved by updating the new replicas with the latest configuration, allowing the old replicas to gracefully terminate.

# Best Practices
- Use rolling updates to minimize downtime and ensure smooth transitions between replicas.
- Set up readiness and liveness probes to monitor the application's health and determine when new replicas are ready to receive traffic.
- Configure a rolling update strategy with a small update window to minimize the time during which new replicas are started and old replicas are present.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse-jetty-deploy
  labels:
    app: eclipse-jetty
spec:
  replicas: 1
  selector:
    matchLabels:
      app: eclipse-jetty
  template:
    metadata:
      labels:
        app: eclipse-jetty
    spec:
      containers:
      - name: eclipse-jetty
        image: eclipse:jetty9
        ports:
        - containerPort: 8080
          protocol: TCP
        livenessProbe:
          httpGet:
            path: /probe-health
            port: 8080
          initialDelaySeconds: 15
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
      strategy:
        rollingUpdate:
          maxSurge: 1
          maxUnavailable: 0
  rollingUpdate:
    maxSurge: 1
    maxUnavailable: 0
```
This YAML file describes a Kubernetes Deployment managing a single replica of an Eclipse Jetty Java application. It sets up the required labels, defines the container image, ports, liveness and readiness probes, and rolling update strategy. By following best practices, we ensure a smooth zero-downtime deployment process with minimal downtime and optimal availability.
