 # Kubernetes Concept
Deployment is a Kubernetes object used for creating and updating containerized applications. it ensures availability, scalability, and rollouts.

# Explanation
A Deployment creates and manages a set of replicas for a desired state of an application. It can be used to perform rolling updates and rollbacks, as well as automatically replace failed replicas.

# Best Practices
- Use a single container per pod for simplicity and ease of management.
- Use labels to identify and select pods.
- Use a rolling update strategy to minimize downtime during updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: quantum-deployment
  labels:
    app: quantum
spec:
  replicas: 3
  selector:
    matchLabels:
      app: quantum
  template:
    metadata:
      labels:
        app: quantum
    spec:
      containers:
      - name: quantum
        image: quantum:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /
            port: 80
        readinessProbe:
          httpGet:
            path: /
            port: 80
status: {}
```
This YAML file creates a Kubernetes Deployment named "quantum-deployment" with 3 replicas, each running the container image "quantum:latest". The container exposes port 80 and both liveness and readiness probes are defined to check the application's health. The deployment uses labels for identification and selects pods based on the "app" label.
