# Kubernetes Concept
Deployment is a Kubernetes object used for managing containerized applications by creating and updating replicas.

# Explanation
A Deployment in Kubernetes ensures a specified number of replicas of a containerized application are running and available at any given time. It provides automated rollouts and rollbacks, allowing for easy updates and scaling.

# Best Practices
- Use rollouts for updating containers instead of directly manipulating pods.
- Set up proper resource limits and requests to ensure efficient use of cluster resources.
- Use labels for easy selection and management of Deployments.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-webapp
  labels:
    app: my-webapp
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-webapp
  template:
    metadata:
      labels:
        app: my-webapp
    spec:
      containers:
      - name: my-webapp-container
        image: my-docker-registry/my-webapp:v1
        ports:
        - containerPort: 80
          name: http
        readinessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 5
          periodSeconds: 10
          failureThreshold: 3
```
