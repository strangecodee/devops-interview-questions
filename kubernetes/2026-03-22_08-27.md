 # Kubernetes Deployment
Defines and creates a set of replicated pods in a Kubernetes cluster.

# Explanation
A Kubernetes Deployment is used to create and manage a stable set of replicas for a desired application. With Deployments, you can declare and automate the creation of new replicas to ensure high availability and Rollout updates for your applications.

# Best Practices
- Use Rolling updates for minimal downtime during updates.
- Set up health checks to ensure that the pods are functioning correctly.
- Implement resource limits and requests to optimize resource usage.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
          name: http
        readinessProbe:
          probes:
          - exec:
              command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
            intervalSeconds: 5
          timeoutSeconds: 2
      resources:
        limits:
          cpu: "1"
          memory: "512Mi"
        requests:
          cpu: "500m"
          memory: "256Mi"
```
