 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications at scale. It ensures the desired state of a set of pods by creating and updating them as needed.

# Explanation
A Deployment creates and manages the desired number of replicas of a containerized application using Pod templates. It offers several features such as rolling updates, rollbacks, and self-healing, making it an essential building block for running applications in Kubernetes.

# Best Practices
- Use rolling updates for minimal downtime and gradual scaling.
- Set appropriate resource limits to prevent noisy neighbors and maintain fair resource distribution.
- Use readiness and liveness probes to ensure your containers are healthy and ready to serve traffic.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  selector:
    matchLabels:
      app: nginx
  replicas: 3
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.14.2
          ports:
            - containerPort: 80
          livenessProbe:
            httpGet:
              path: /
              port: 80
          readinessProbe:
            httpGet:
              path: /
              port: 80
```
