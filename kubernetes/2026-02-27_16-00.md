 # Kubernetes Concept
This is an example of a Kubernetes Deployment for a simple web application using an Eclipse Jetty server, running on Amazon Elastic Container Service for Kubernetes (EKS).

# Explanation
A Kubernetes Deployment is used to create and manage a desired state for a set of replica Pods. In this example, a Deployment is employed to ensure high availability of the web application by managing the update process and scaling based on demand.

# Best Practices
- Use rolling updates to minimize downtime while updating the application.
- Use replicas for high availability and to distribute the workload evenly.
- Monitor the application using Kubernetes built-in probes or external monitoring solutions.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse-jetty
spec:
  selector:
    matchLabels:
      app: eclipse-jetty
  replicas: 3
  template:
    metadata:
      labels:
        app: eclipse-jetty
    spec:
      containers:
      - name: eclipse-jetty
        image: eclipse:jetty
        ports:
        - containerPort: 8080
          protocol: TCP
        livenessProbe:
          httpGet:
            path: /
            port: 8080
        readinessProbe:
          httpGet:
            path: /
            port: 8080
```
