 # Kubernetes Concept
Deployment is a Kubernetes object used for updating and managing containerized applications. It ensures availability and rollback capabilities for your applications.

# Explanation
A Deployment creates and manages a set of replicas of a container application. It provides progressive delivery via update rollouts and automatic rollbacks to a previous version if the new release fails.

# Best Practices
- Use rolling updates for minimal downtime.
- Keep at least 3 replicas for high availability.
- Monitor your application's health using Liveness and Readiness probes.

# YAML Example
---
apiVersion: apps/v1
kind: Deployment
metadata:
 name: my-app-deployment
spec:
 replicas: 3
 selector:
 matchLabels:
 app: my-app
 template:
 metadata:
 labels:
 app: my-app
 spec:
 containers:
 - name: my-app-container
 image: my-registry/my-app:v1
 ports:
 - containerPort: 80
 livenessProbe:
 exec:
 command: ["/usr/bin/check-health"]
 periodSeconds: 5
 readinessProbes:
 - exec:
 beforeStartProbe: true
 command: ["/usr/bin/check-readiness"]
 initialDelaySeconds: 30
 periodSeconds: 10
 # Rolling update strategy
 strategy:
 type: RollingUpdate
 rollingUpdate:
 maxSurge: 1
 maxUnavailable: 0
---
