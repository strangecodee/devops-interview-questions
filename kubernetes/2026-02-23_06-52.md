 # Kubernetes Deployment
Defines the desired state for a set of Pods.

# Explanation
A Deployment in Kubernetes manages the lifecycle of a set of replicas for a desired application. It creates new replicas with updates, scales the number of replicas, and ensures availability and rollback if necessary.

# Best Practices
- Use Rolling updates for minimizing downtime and ensuring smooth application updates.
- Set up Auto-scaling based on resource usage or external metrics to handle traffic fluctuations.
- Use readiness and liveness probes to monitor the health of your containers and ensure they are prepared to receive traffic.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-container-image:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
