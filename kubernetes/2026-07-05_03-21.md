 # Kubernetes Concept
This is an example of a Kubernetes Service, specifically a LoadBalancer Service, which exposes a stable IP to access a running application.

# Explanation
A LoadBalancer Service distributes incoming traffic across a set of Pods, providing high availability and scalability. Kubernetes automatically assigns an external IP to the Service, which can be used to access the application from outside the cluster.

# Best Practices
- Use a Service of type `LoadBalancer` only when external access is required. For internal services, use `ClusterIP` or `NodePort` instead.
- Use multiple replicas and configure the Service to use `Session Affinity` for better user experience.

# YAML Example
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  type: LoadBalancer
  ports:
  - name: http
    port: 80
    targetPort: 8080
```
