 # Kubernetes Deployment
Defines and creates a set of replicas for a containerized application.

# Explanation
A Kubernetes Deployment manages the lifecycle of a set of replicas for a containerized application. It ensures that a specified number of replicas are running at any given time, and it can perform rolling updates or rollbacks, making it a crucial part of deploying and managing applications in a Kubernetes cluster.

# Best Practices
- Use rolling updates to minimize downtime.
- Set up a health check using a LivenessProbe and a ReadinessProbe.
- Use resource limits and requests to ensure optimal resource utilization.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-app:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
      imagePullSecrets:
      - name: my-registry
```
