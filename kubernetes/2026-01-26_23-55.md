 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications. It ensures that a specified number of replicas of a container image are running and replaces any unhealthy replicas.

# Explanation
A Kubernetes Deployment creates and manages a desired state for a set of replicas, ensuring high availability and automatic rollouts and rollbacks. It uses labels to select Pods, and updates the state of these Pods based on new releases.

# Best Practices
- Use rolling updates to minimize downtime and maintain availability.
- Set up self-healing to automatically replace unhealthy replicas.
- Use readiness and liveness probes to determine the status of your containers.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
          name: http
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
