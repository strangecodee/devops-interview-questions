 # Kubernetes Concept
This example demonstrates a Kubernetes Deployment for a simple Java application using an Eclipse Jetty server, with a built-in Healthcheck Probe.

# Explanation
Kubernetes Deployments manage the rollout and scaling of containerized applications. In this example, the Java application is packaged as a container image, and the Kubernetes Deployment configures the desired state for a specified number of replicas. The Healthcheck Probe ensures the application is responsive and functional, and Kubernetes automatically restarts unhealthy containers to maintain application availability.

# Best Practices
1. Use resource requests and limits to ensure fair resource allocation for your application.
2. Set up rolling updates for Deployments to minimize downtime.
3. Monitor application logs and metrics using external tools or built-in Kubernetes solutions like Logging and Metrics Server.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse-deployment
spec:
  selector:
    matchLabels:
      app: eclipse
  replicas: 3
  template:
    metadata:
      labels:
        app: eclipse
    spec:
      containers:
      - name: eclipse-container
        image: eclipse:jakarta-ee-tomcat-9-jre8-openjdk
        ports:
        - containerPort: 8080
          name: jetty
        livenessProbe:
          httpGet:
            path: /
            port: 8080
        readinessProbe:
          httpGet:
            path: /healthz
            port: 8080
```
Using this YAML configuration, a Deployment is created named "eclipse-deployment" with 3 replicas, each containing an Eclipse container image that listens on port 8080. The liveness and readiness probes ensure the application is running and healthy.
