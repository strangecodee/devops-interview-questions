 # Kubernetes Concept
This YAML example demonstrates a Kubernetes Deployment for a Docker container using phoenix as the application name. It includes a description of the container image, necessary resources, and readiness and liveness probes.

# Explanation
The `Deployment` resource is used to create and manage a set of replicas for a desired application. In this example, the phoenix application container is defined with its image name, required resources and probes to ensure the container is healthy and ready.

# Best Practices
- Use labels to facilitate management and organization of your Kubernetes resources.
- Set up resource limits and requests to ensure containers operate efficiently and do not conflict with each other.
- Define readiness and liveness probes to ensure containers are ready for traffic and functioning correctly.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
  labels:
    app: phoenix
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:latest
        resources:
          limits:
            cpu: "1"
            memory: "512Mi"
          requests:
            cpu: "0.5"
            memory: "256Mi"
        ports:
        - containerPort: 4000
        readinessProbe:
          probeType: HttpGet
          httpGet:
            path: /api/readiness
            port: 4000
        livenessProbe:
          probeType: HttpGet
          httpGet:
            path: /api/liveness
            port: 4000
```
