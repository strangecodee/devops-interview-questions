 # Kubernetes Concept
Deployment is a Kubernetes resource for managing containerized applications and their replicas.

# Explanation
A Deployment creates and manages a set of replicas of a specified container image. It allows for rolling updates and automatic rollbacks, ensuring high availability and zero downtime. The Deployment controller updates the replicas by creating new pods and gradually draining old ones, while maintaining the desired number of replicas.

# Best Practices
- Use rolling updates for Deployments to minimize downtime and maintain availability.
- Implement readiness and liveness probes to ensure the container is readable and healthy.
- Use labels for selectors to manage and organize your Deployments.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-sre
  labels:
    app: phoenix
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: example/phoenix:latest
        ports:
        - containerPort: 8080
        readinessProbe:
          probes:
          - exec:
              command: ["curl", "-f", "/healthz"]
            initialDelaySeconds: 15
            periodSeconds: 10
            failureThreshold: 3
        livenessProbe:
          probes:
          - exec:
              command: ["curl", "-f", "/healthz"]
            initialDelaySeconds: 15
            periodSeconds: 10
            failureThreshold: 3
```
