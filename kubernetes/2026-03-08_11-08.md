 # Kubernetes Concept
Kubernetes DaemonSet: A way to ensure a copy of a pod runs on all nodes in a cluster.

# Explanation
A DaemonSet ensures that a copy of a specified pod is running on all nodes in the cluster, maintaining a consistent state across the cluster. This is particularly useful for running system components like logging agents or monitoring tools.

# Best Practices
- Define appropriate labels and selectors for the DaemonSet to ensure the pods are scheduled correctly.
- Use readiness probes and liveness probes to ensure the daemon pods are healthy and ready to serve.
- Leverage rolling updates for DaemonSets to minimize disruptions during updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: logging-daemonset
spec:
  selector:
    matchLabels:
      app: logging-daemon
  template:
    metadata:
      labels:
        app: logging-daemon
    spec:
      containers:
      - name: logging-container
        image: logging-image:latest
        ports:
        - containerPort: 514
          name: udp
          protocol: UDP
        livenessProbe:
          exec:
            command: ["/usr/bin/logger", "-t", "restarting"]
            intervalSeconds: 30
          failureThreshold: 3
        readinessProbe:
          exec:
            command: ["/usr/bin/logger", "--test"]
            initialDelaySeconds: 30
            periodSeconds: 5
```
