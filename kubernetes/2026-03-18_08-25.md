 # Kubernetes Concept
This YAML example demonstrates a Kubernetes `HorizontalPodAutoscaler` (HPA) for a deployment named `eclipse`, which is used for scaling Kubernetes applications based on observed CPU utilization.

# Explanation
The Kubernetes Horizontal Pod Autoscaler (HPA) automatically scales the number of replicas of a deployed application in response to observed CPU utilization. This ensures that the application maintains the desired level of performance and availability while minimizing resource wastage.

# Best Practices
- Practice 1: Set minimum and maximum replicas to prevent unexpected scaling.
- Practice 2: Use target CPU utilization as a metric for scaling.
- Practice 3: Monitor and review the scaling behavior regularly to ensure proper functioning.

# YAML Example
```yaml
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler
metadata:
  name: eclipse-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: eclipse
  minReplicas: 1
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      targetAverageUtilization: 70
```
This YAML configuration creates an HPA named `eclipse-hpa` that targets the `eclipse` deployment. The minimum and maximum number of replicas are set to 1 and 5, respectively. The HPA scales the number of replicas based on the average CPU utilization, which is set to 70%.
