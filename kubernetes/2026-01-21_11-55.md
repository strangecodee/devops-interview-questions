 # Kubernetes Concept
Deployment is a Kubernetes resource for defining, creating, and managing a set of replicas of a containerized application.

# Explanation
A Deployment in Kubernetes manages the lifecycle of a set of Pods, creating new instances when needed and removing old ones when they are no longer required. It ensures the desired number of replicas is running at any given time and can automatically replace unhealthy instances.

# Best Practices
- Use rolling updates to minimize downtime when deploying new versions of your application.
- Use readiness and liveness probes to ensure your applications are running correctly and ready to accept traffic.
- Use labels and selectors to manage and organize your deployments.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
  labels:
    app: phoenix
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:latest
        ports:
        - containerPort: 8080
          protocol: TCP
        readinessProbe:
          probes:
          - httpGet:
              path: /health
              port: 8080
        livenessProbe:
          probes:
          - httpGet:
              path: /health
              port: 8080
```
