 # Kubernetes Concept
Deployment is a Kubernetes object used for deploying and managing containerized applications. It ensures that a specified number of replicas of a container are running at any given time, and it can perform rolling updates and rollbacks.

# Explanation
A Deployment creates and manages the desired state for a set of replica Pods based on a container image or a Git repository. It provides declarative updates and automatic rollouts, allowing for zero-downtime updates. Kubernetes will update the replicas one at a time, ensuring that the desired number of replicas is always available.

# Best Practices
- Use Rolling Updates instead of Recreate to minimize downtime and maintain availability.
- Set `strategy.type: RollingUpdate` in the YAML file.
- Monitor the progress of updates using the `kubectl get deployments` command.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  selector:
    matchLabels:
      app: my-app
  replicas: 3
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
          name: http
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
          initialDelaySeconds: 5
          periodSeconds: 5
  strategy:
    type: RollingUpdate
```
