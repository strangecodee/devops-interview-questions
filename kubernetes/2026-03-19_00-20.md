 # Kubernetes Concept
Deployment is a Kubernetes object used for updating and rolling out new versions of a containerized application.

# Explanation
A Deployment creates and manages replicas of a specified Pod template, ensuring a desired number of replicas is available at any time. It also handles rolling updates and rollbacks, allowing seamless upgrades or downgrades of applications.

# Best Practices
1. Use labels for selector and selectors in Deployment to easily identify and manage instances of your application.
2. Statically define ports in the container image and configure them in the Deployment for efficient load balancing and service discovery.
3. Use rolling updates for minimal downtime during application upgrades.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-deployment
  labels:
    app: nebula
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
        - name: nebula
          image: nebula:latest
          ports:
            - containerPort: 80
          readinessProbe:
            probes:
              - httpGet:
                  path: /
                  port: 80
              intervalSeconds: 5
          livenessProbe:
            probes:
              - httpGet:
                  path: /
                  port: 80
              intervalSeconds: 15
```
This Deployment manages a replica set of `nebula` containers, with three replicas, each listening on port 80. The readiness and liveness probes are used to ensure that the containers are ready to receive traffic and are healthy, respectively.
