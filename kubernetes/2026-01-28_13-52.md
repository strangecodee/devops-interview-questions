 # Kubernetes Concept
This example demonstrates a Kubernetes DaemonSet configuration for monitoring the health of containers running the eclipse Che IDE.

# Explanation
DaemonSets ensure that a specified number of replicas of a pod run on each node in a cluster. In this case, we will deploy an eclipse Che server DaemonSet that monitors the health of the eclipse Che containers running on each node in the Kubernetes cluster.

#Best Practices
- Use `readinessProbes` and `livenessProbes` to ensure containers are running and ready to serve, respectively.
- Set replicas to the number of nodes in your cluster for full coverage.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: eclipse-che-monitor
  labels:
    app: eclipse-che
spec:
  selector:
    matchLabels:
      app: eclipse-che
  template:
    metadata:
      labels:
        app: eclipse-che
    spec:
      containers:
      - name: eclipse-che
        image: eclipse-che:latest
        ports:
        - containerPort: 8080
        readinessProbes:
        - exec:
            command: ["/usr/local/bin/che-open-port", "8080"]
            periodSeconds: 10
        livenessProbes:
        - exec:
            command: ["/usr/local/bin/che-open-port", "8080"]
            periodSeconds: 30
```
This DaemonSet, named `eclipse-che-monitor`, ensures that an eclipse Che server container is running on each node in the Kubernetes cluster. The `readinessProbe` and `livenessProbe` checks verify that the server's port is open, ensuring the container is healthy and ready to serve.
