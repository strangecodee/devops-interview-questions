# Kubernetes Concept
This example demonstrates a `Service` and a `Deployment` for a simple web application, using a `LoadBalancer` type service for external access.

# Explanation
A `Service` in Kubernetes is an abstraction over a set of pods that provides a stable DNS name and a single IP address. The `LoadBalancer` type creates an external load balancer which distributes incoming traffic across the designated pods. A `Deployment` is used for managing the lifecycle of containerized applications.

# Best Practices
- Use `replicas: 3` or more for high availability and better load distribution.
- Use `labels:` for easier identification and management of your pods.
- Use `readinessProbe:` and `livenessProbe:` to ensure the health and readiness of your containers.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-webapp
  labels:
    app: my-webapp
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-webapp
  template:
    metadata:
      labels:
        app: my-webapp
    spec:
      containers:
      - name: my-webapp
        image: my-webapp:latest
        ports:
        - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: my-webapp
  labels:
    app: my-webapp
spec:
  selector:
    app: my-webapp
  ports:
  - port: 80
  type: LoadBalancer
```
