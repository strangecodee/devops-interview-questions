 # Kubernetes Concept
This is an example of a Kubernetes DaemonSet configuration for monitoring the health and readiness of containers in a cluster using Prometheus and Grafana.

# Explanation
DaemonSets ensure that a specified number of replicas of a container run on each node in the cluster. In this configuration, we deploy Prometheus and Grafana as daemonsets to promote consistent monitoring across all nodes. Prometheus collects metrics from the cluster, while Grafana provides a user interface for visualizing and querying those metrics.

# Best Practices
- Ensure that Prometheus and Grafana have access to the Kubernetes API through proper RBAC roles and configurations.
- Enable the Prometheus service discovery annotation @ `prometheus.io/scrape` in the Kubernetes manifests of the services that should be monitored.
- Configure Grafana to pull data from Prometheus and create appropriate dashboards for your use case.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: prometheus
  labels:
    app: prometheus
spec:
  selector:
    matchLabels:
      app: prometheus
  template:
    metadata:
      labels:
        app: prometheus
    spec:
      containers:
      - name: prometheus
        image: prom/prometheus:v2.31.0
        ports:
        - containerPort: 9090
          name: web
          protocol: TCP
          nodePort: 30001
        ports:
        - containerPort: 9091
          name: metrics
          protocol: TCP
          nodePort: 30444
        command: ["/usr/local/bin/prometheus", "--config.file=/etc/prometheus/prometheus.yml", "--storage.tsdb.path=/prometheus"]
        volumeMounts:
        - name: prometheus-config
          mountPath: /etc/prometheus
          subPath: prometheus.yml
      volumes:
      - name: prometheus-config
        configMap:
          name: prometheus-config
---
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: grafana
  labels:
    app: grafana
spec:
  selector:
    matchLabels:
      app: grafana
  template:
    metadata:
      labels:
        app: grafana
    spec:
      containers:
      - name: grafana
        image: grafana/grafana:8.2.0
        ports:
        - containerPort: 3000
          name: web
          protocol: TCP
          nodePort: 30800
        env:
        - name: GF_INSTALL_PLUGINS
          value: "grafana-piechart-panel,grafana-statalert-panel"
        volumeMounts:
        - name: grafana-config
          mountPath: /var/lib/grafana
      volumes:
      - name: grafana-config
        emptyDir: {}
```
