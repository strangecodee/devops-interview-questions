 # Kubernetes Concept
Deployment is a Kubernetes resource for managing containerized applications. It ensures a specified number of replicas are running and available to serve user traffic.

# Explanation
A Deployment creates and manages a set of replica Pods based on a defined container image and configuration. The desired state of the application is maintained by continuously rolling out updates and rolling back if needed. This provides a resilient and scalable way to manage applications in a containerized environment.

# Best Practices
- Use Rolling Updates to minimize downtime while updating your application.
- Use a Health Check Liveness Probe to ensure your containers are running and ready to serve traffic.
- Use a Rollback Strategy to safely revert to a previous version if an update fails.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-app
spec:
  selector:
    matchLabels:
      app: nebula
  replicas: 3
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula
        image: nebula:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 30
          periodSeconds: 10
```
