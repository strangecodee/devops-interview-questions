 # Kubernetes Concept
This example demonstrates a Kubernetes Deployment for a containerized Java application using an Eclipse Jetty web server, running on Amazon Elastic Container Service for Kubernetes (EKS).

# Explanation
The Kubernetes Deployment file creates and manages a set of replicas for the Java application pods. The pods are defined with a container image, a port for external access, and readiness and liveness probes. The Deployment file also sets up a rolling update strategy for scaling and rolling back updates.

# Best Practices
- Use a container registry like Amazon Elastic Container Registry (ECR) to store your container images for better security and easier image management.
- Use Kubernetes secrets to store sensitive configuration data securely.
- Use a Kubernetes Ingress resource for external access to your application with TLS encryption and proper routing.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: jetty-deployment
  labels:
    app: jetty
spec:
  selector:
    matchLabels:
      app: jetty
  replicas: 3
  template:
    metadata:
      labels:
        app: jetty
    spec:
      containers:
      - name: jetty
        image: 1769978181.dkr.ecr.us-west-2.amazonaws.com/eclipse:jetty-java11
        ports:
        - containerPort: 8080
          name: http
        readinessProbe:
          httpGet:
            path: /
            port: 8080
          initialDelaySeconds: 15
          periodSeconds: 10
        livenessProbe:
          httpGet:
            path: /
            port: 8080
          initialDelaySeconds: 15
          periodSeconds: 20
---
apiVersion: v1
kind: Service
metadata:
  name: jetty-service
spec:
  selector:
    app: jetty
  ports:
  - name: http
    port: 80
    targetPort: 8080
  type: LoadBalancer
```
This YAML example includes a Kubernetes Deployment and Service file. The Deployment manages the replicas of the Java application, while the Service sets up external access to the application using a LoadBalancer. The readiness and liveness probes are also defined within the container definition.
