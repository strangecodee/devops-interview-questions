 # Kubernetes Concept
Deployment: A Kubernetes object used to create and manage containerized applications.

# Explanation
A Deployment creates and manages replicas of a containerized application. It ensures a specified number of replicas are running at any given time, and it can perform updates to the containers in a controlled manner. This includes updating container images, scaling the number of replicas based on demand, and rolling back to a previous version if necessary.

# Best Practices
- Use rolling updates to minimize downtime and ensure smooth application upgrades.
- Set up a self-healing mechanism by specifying a minimum number of replicas (replicaSet).
- Implement readiness and liveness probes to check the application's health and readiness before starting containers and marking them as ready.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: forge-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: forge
  template:
    metadata:
      labels:
        app: forge
    spec:
      containers:
      - name: forge-container
        image: my-registry/forge:v1.0.0
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
