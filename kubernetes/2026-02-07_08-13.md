 # Kubernetes Concept
Deployment is a Kubernetes object used for deploying and updating containers. It ensures availability and rolling updates for applications.

# Explanation
A Kubernetes Deployment creates and manages replicas of a container, ensuring a specified number of replicas are available at any given time. It also handles rolling updates, seamlessly updating containers to new versions while minimizing downtime.

# Best Practices
- Use labels for easy identification and management of replicas.
- Set up a liveness probe to check the application's health and readiness probe to check if the container is ready to accept traffic.
- Use rolling updates for seamless deployment of new container versions.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: atlas-deployment
  labels:
    app: atlas
spec:
  replicas: 3
  selector:
    matchLabels:
      app: atlas
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  template:
    metadata:
      labels:
        app: atlas
    spec:
      containers:
      - name: atlas
        image: atlas:latest
        ports:
        - containerPort: 80
          name: http
          protocol: TCP
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /healthz
            port: 80
```
This example creates a Deployment named `atlas-deployment` with three replicas, each running the `atlas:latest` container image. It sets up a liveness and readiness probe for the container and uses a rolling update strategy for seamless updates.
