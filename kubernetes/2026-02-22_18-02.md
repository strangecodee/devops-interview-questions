 # Kubernetes Deployment
Create and manage containerized applications in a cluster.

# Explanation
Deployments manage the rollout and scaling of containerized applications. Replicas are created from a template defined by a Pod specification. The desired state of the desired number of replicas and their readiness are monitored and maintained by the Kubernetes controller.

# Best Practices
- Use Rolling updates for minimum downtime during deployment.
- Use Readiness and Liveness probes to ensure container availability.
- Use Labels for easy selection of pods for scaling or rolling updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app
        image: my-registry/my-app:v1.0.0
        ports:
        - containerPort: 80
          name: http
        readinessProbe:
          probes:
          - httpGet:
              path: /healthz
              port: 80
        livenessProbe:
          probes:
          - httpGet:
              path: /healthz
              port: 80
```
