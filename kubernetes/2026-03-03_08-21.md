 # Kubernetes Concept
Kubernetes DaemonSet is a type of Kubernetes deployment that ensures a specified number of replicas of a pod are running on each node in the cluster.

# Explanation
DaemonSets are used to manage background services, such as monitoring agents, logging agents, or network components that need to run on all nodes in the cluster. They maintain the desired state of the pods across the nodes, even if the pods are deleted, and recreate them as needed.

# Best Practices
- Use labels to select the nodes where the DaemonSet should run.
- Use the `imagePullSecrets` property to securely pull images from private registries.
- Use the `securityContext` property to set container security policies.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: atlas-log-daemonset
  labels:
    app: atlas
    environment: logging
spec:
  selector:
    matchLabels:
      app: atlas
      environment: logging
  template:
    metadata:
      labels:
        app: atlas
        environment: logging
    spec:
      imagePullSecrets:
      - name: docker-registry-secret
      securityContext:
        runAsUser: 0
        fsGroup: 0
      containers:
      - name: atlas-log-container
        image: private-registry/atlas-log:latest
        ports:
        - containerPort: 5000
          name: atlas-log
        readinessProbe:
          probes:
          - exec:
              command: ["/bin/sh", "-c", "curl --fail http://localhost:5000 || exit 1"]
              intervalSeconds: 30
          timeoutSeconds: 5
        livenessProbe:
          probes:
          - exec:
              command: ["/bin/sh", "-c", "curl --fail http://localhost:5000 || exit 1"]
              intervalSeconds: 30
              timeoutSeconds: 5
```
This DaemonSet deploys the `atlas-log` container on each node in the Kubernetes cluster. It uses a secret named `docker-registry-secret` for securely pulling images from the private registry, sets the container security policies with `runAsUser` and `fsGroup` properties, and uses readiness and liveness probes to ensure that the container is healthy and ready to accept traffic.
