 # Kubernetes Concept
This YAML example demonstrates a Kubernetes `HorizontalPodAutoscaler` resource for monitoring and automatically scaling a Deployment based on CPU utilization.

# Explanation
The `HorizontalPodAutoscaler` is a Kubernetes resource used to automatically scale the number of replicas in a Horizontal Pod based on observed CPU utilization. This is an essential tool for maintaining optimal resource usage and ensuring application availability and performance.

# Best Practices
- Set proper target CPU utilization percentage for your workload.
- Use the `preStartepodsMaxSurge` and `preStartepodsMaxUnavailable` fields to control the number of new replicas and pods being drained before scaling.
- Monitor and adjust the autoscaler based on your application's requirements and resource utilization patterns.

# YAML Example

```yaml
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler
metadata:
  name: example-app
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: example-deployment
  minReplicas: 1
  maxReplicas: 5
  targetCPUUtilizationPercentage: 50
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 80
        averageUtilizationSmoothingPeriodSeconds: 300
```
