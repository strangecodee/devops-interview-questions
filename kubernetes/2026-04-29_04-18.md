# Kubernetes Concept: Deployment
A Kubernetes Deployment manages the rollout and scaling of a desired number of replicas for a container application.

# Explanation
A Deployment maintains a specified number of replicas for a container application by creating and updating the Pods in the cluster. It can perform rolling updates, rolling back to a previous version, and blue-green deployments.

# Best Practices
- Use `rolling-update` strategy for minimal downtime during updates.
- Use `readinessProbe` and `livenessProbe` for health checking.
- Use `strategicRollout` for canary releases.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: forge-webapp
spec:
  replicas: 3
  selector:
    matchLabels:
      app: forge
  template:
    metadata:
      labels:
        app: forge
    spec:
      containers:
      - name: forge-webapp
        image: forge/webapp:latest
        ports:
        - containerPort: 80
      readinessProbes:
      - apiVersion: v1
        kind: Probe
        name: readiness
        exec:
          command: ["/usr/local/bin/custom-readiness-check.sh"]
          intervalSeconds: 5
      livenessProbes:
      - apiVersion: v1
        kind: Probe
        name: liveness
        exec:
          command: ["/usr/local/bin/custom-liveness-check.sh"]
          intervalSeconds: 30
```
