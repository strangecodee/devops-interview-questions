 # Kubernetes Concept
Deployment is a Kubernetes resource for managing containers, ensuring their availability and scalability.

# Explanation
A Deployment creates or updates Replicas of a specified Pod template, maintaining a specified number of available instances. It also provides a way to automate updates throughRollingUpdate or Recreate strategies.

# Best Practices
- Create immutable containers with a multi-stage build to minimize image size and reduce attack surface.
- Deploy frequently and rollbacks with RollingUpdate strategy minimizing downtime and risk.
- Use labels for filtering and identifying resources.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
        readinessProbe:
          probes:
          - exec:
              command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
          intervalSeconds: 5
        livenessProbe:
          probes:
          - exec:
              command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
              initialDelaySeconds: 15
          intervalSeconds: 5
```
