# Kubernetes Concept
Kubernetes DaemonSet: A way to ensure a copy of a pod runs on all nodes in a cluster.

# Explanation
A DaemonSet ensures that a specific number of replicas for a pod run on each node in the cluster, maintaining a consistent state across nodes. This is useful for running critical services or agents, such as a log collector or monitoring system, on every node.

# Best Practices
- Use labels to target specific nodes or node labels for better control and management.
- Use readiness and liveness probes to maintain the desired state of the pods.
- Keep container images up-to-date to ensure security and functionality.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: atlas-log-daemon
spec:
  selector:
    matchLabels:
      app: atlas-log-daemon
  template:
    metadata:
      labels:
        app: atlas-log-daemon
    spec:
      containers:
      - name: atlas-log-container
        image: atlas/log-collector:latest
        ports:
        - containerPort: 514
        - containerPort: 9001
        readinessProbes:
        - exec:
            command: ["/usr/local/bin/check-log-agent-health.sh"]
        livenessProbes:
        - exec:
            command: ["/usr/local/bin/check-log-agent-liveness.sh"]
```
This DaemonSet example, named `atlas-log-daemon`, runs a container with the image `atlas/log-collector:latest` on each node in the cluster. It includes a readiness and liveness probe for monitoring the container's health.
