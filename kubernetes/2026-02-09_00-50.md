 # Kubernetes Concept
Kubernetes Secret is a storage volume that holds sensitive data such as passwords, OAuth tokens, and SSL certificates.

# Explanation
Secrets in Kubernetes are encrypted at rest and decrypted on the container runtime as needed. This mechanism protects the sensitive data from being exposed in the container image or in the configuration file. In this example, we'll create a Secret object named "my-secret" that stores a username and password.

# Best Practices
- Create separate Secrets for different environments (dev, staging, production).
- Use environment variables or configuration files in containers to access the data from the Secret.

# YAML Example
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: my-secret
  namespace: default
type: Opaque
data:
  username: cGFzc3dvcmQ=
  password: cGFzc3dvcmQ=
```
In this example, we define a Kubernetes Secret with the name "my-secret" and store base64-encoded strings for a username ("admin") and password ("password") values. The "type: Opaque" ensures that Kubernetes doesn't attempt to parse the data.
