# Kubernetes Concept
Deployment is a type of Kubernetes object used for deploying and updating containers. It ensures availability and scales applications.

# Explanation
A Deployment creates and manages a desired state for a set of containers, including updates and rollbacks. It maintains a specified number of replicas and performs automatic rollouts and rollbacks based on user-defined strategies.

# Best Practices
- Use a rolling update strategy to minimize downtime.
- Define a health check through a LivenessProbe or ReadinessProbe in the container.
- Implement a rolling update strategy with PreRoll and PostRoll hooks for added customization.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: atlas-deployment
  labels:
    app: atlas
spec:
  replicas: 3
  selector:
    matchLabels:
      app: atlas
  template:
    metadata:
      labels:
        app: atlas
    spec:
      containers:
      - name: atlas
        image: atlas:latest
        ports:
        - containerPort: 80
          name: http
        readinessProbes:
        - httpGet:
            path: /healthz
            port: 80
        livenessProbes:
        - httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 15
          periodSeconds: 5
      restartPolicy: Always
```
This performance-optimized example creates a Deployment named `atlas-deployment` with 3 replicas, using the `atlas:latest` image. It defines readiness and liveness probes, ensuring the containers are healthy and ready to receive traffic. The `restartPolicy` is set to `Always`, which restarts the container if it fails.
