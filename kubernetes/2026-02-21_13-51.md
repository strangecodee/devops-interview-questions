 # Kubernetes Concept
This is an example of a Kubernetes Deployment YAML file for a simple web application using a popular Java EE application server, GlassFish, via the open-source Helm chart for Eclipse GlassFish.

# Explanation
The Kubernetes Deployment YAML file below defines a Kubernetes Deployment that creates and manages the running instances of a Docker container that holds the GlassFish application server and the Java EE web application. The Deployment controller ensures the desired state of the application by creating and managing the replicas and rolling out updates when new container images are available.

# Best Practices
- Use Helm, an open-source package manager for Kubernetes, for easier and more consistent management of complex applications like GlassFish.
- Set up resource limits and requests for the container to ensure proper resource utilization and to avoid resource contention.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: glassfish-app
spec:
  selector:
    matchLabels:
      app: glassfish
  replicas: 3
  template:
    metadata:
      labels:
        app: glassfish
    spec:
      containers:
      - name: glassfish
        image: eclipse-container/glassfish:5.1.2
        ports:
        - containerPort: 8080
          name: http
        resources:
          limits:
            memory: "512Mi"
            cpu: "2"
          requests:
            memory: "256Mi"
            cpu: "1"
        env:
        - name: GF_DOMAINS
          value: myapp.local:8080
        readinessProbe:
          exec:
            command: ["sh", "-c", "curl --fail --head --max-time=1 http://localhost:8080/ | gre -q 'HTTP/1.1\|200\|OK'"]
        livenessProbe:
          exec:
            command: ["sh", "-c", "curl --fail --max-time=1 http://localhost:8080/ || exit 1"]
```
