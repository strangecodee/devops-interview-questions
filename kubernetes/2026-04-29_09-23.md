# Kubernetes Concept
Kubernetes DaemonSet is a type of Kubernetes deployment that ensures a copy of the specified pod is running on all nodes in the cluster.

# Explanation
DaemonSets maintain a consistent daemon process running on all nodes in a cluster. They are useful for deploying processes like logging agents, monitoring agents, or network proxies, which should be running on every node.

# Best Practices
- Define resource limits in the DaemonSet (CPU, memory) to ensure fair resource distribution.
- Use a rolling update strategy to minimize downtime and ensure the health of the running daemons.
- Implement security measures, such as deploying the daemon with a non-root user and using RBAC to manage access.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: atlas-daemon
spec:
  selector:
    matchLabels:
      app: atlas
  template:
    metadata:
      labels:
        app: atlas
    spec:
      containers:
      - name: atlas
        image: atlas:latest
        ports:
        - containerPort: 3000
          name: atlas
        securityContext:
          runAsUser: 1001
          capabilities:
            drop: ALL
        resources:
          limits:
            cpu: "0.5"
            memory: "512Mi"
          requests:
            cpu: "0.2"
            memory: "256Mi"
```
