# Kubernetes Concept
Deployment is a Kubernetes resource for managing containerized applications. It ensures available replicas of the specified container image are running in the cluster.

# Explanation
A Deployment creates and manages a set of replicas of a containerized application. When new versions of the application are released, rolling updates can be performed with zero downtime to replace old replicas with new ones. Kubernetes handles scaling and availability of the application by automatically replacing unhealthy replicas.

# Best Practices
- Use Rolling updates for new deployments to limit downtime and maintain availability.
- Set appropriate resource limits and requests to ensure proper resource allocation and prevent noisy neighbor effect.
- Use Readiness and Liveness probes to monitor the application's health and readiness.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: forge-app
  labels:
    app: forge
spec:
  replicas: 3
  selector:
    matchLabels:
      app: forge
  template:
    metadata:
      labels:
        app: forge
    spec:
      containers:
      - name: forge
        image: forge:latest
        ports:
        - containerPort: 80
      imagePullSecrets:
      - name: registry-secret
      terminationGracePeriodSeconds: 30
      readinessProbes:
      - exec:
          command: ["curl", "--fail", "/"]
          intervalSeconds: 5
          timeoutSeconds: 3
      livenessProbes:
      - exec:
          command: ["curl", "--fail", "/"]
          intervalSeconds: 15
          timeoutSeconds: 3
```
