 # Kubernetes Concept
The Deployment resource in Kubernetes is used for creating and managing containers in a cluster. It ensures that a specified number of replicas of a container are running at any given time, and it can perform rolling updates and rollbacks.

# Explanation
The Deployment resource is one of the core building blocks of Kubernetes, used to create and manage containerized applications. It maintains a specified number of replicas of a container, automatically scales based on demand, and performs rolling updates and rollbacks.

# Best Practices
- Use rolling updates to minimize downtime and ensure a smooth transition between deployments.
- Set up health checks using probes to ensure that only healthy replicas are serving traffic and to facilitate automated scaling.
- Use labels and selectors to manage and organize your containers effectively.

# YAML Example - AWS Elastic Container Service for Kubernetes (EKS)
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-deployment
  labels:
    app: nebula
    environment: production
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula
        image: 1772250462.dkr.ecr.us-west-2.amazonaws.com/nebula:v1
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 15
          periodSeconds: 10
```
In this YAML example, we create a Kubernetes Deployment named `nebula-deployment` that runs 3 instances of the container image `1772250462.dkr.ecr.us-west-2.amazonaws.com/nebula:v1`. The container listens on port 80, and we set up a liveness probe that checks the health of the container by sending an HTTP request to the `/healthz` endpoint. The probe checks the container's health every 10 seconds and has an initial delay of 15 seconds. The label `app: nebula` is set on both the Deployment and the container to facilitate selection and management.
