 # Kubernetes Concept
This example demonstrates a Kubernetes Deployment for a simple Java application using an Eclipse Jetty server, along with a corresponding Horizontal Pod Autoscaler and a Liveness Probe for monitoring.

# Explanation
The Kubernetes Deployment creates and manages the desired state of a group of Pods, ensuring they run with the specified container image, memory, and CPU limits. Here, we use an Eclipse Jetty image. The Horizontal Pod Autoscaler automatically scales the number of replicas based on the observed CPU utilization, ensuring optimal resource usage. Lastly, the Liveness Probe checks the application's health and restarts unresponsive containers to maintain a healthy application.

# Best Practices
- Use a Rolling Update strategy when updating your application, allowing for zero downtime deployments.
- Set up resource limits to ensure your containers don't consume excessive resources.
- Monitor both CPU and memory usage to maintain optimal performance.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse-deployment
spec:
  selector:
    matchLabels:
      app: eclipse
  replicas: 3
  template:
    metadata:
      labels:
        app: eclipse
    spec:
      containers:
      - name: eclipse-container
        image: eclipse:jetty
        ports:
        - containerPort: 8080
        resources:
          limits:
            cpu: "0.5"
            memory: "512Mi"
          requests:
            cpu: "0.2"
            memory: "256Mi"
---
apiVersion: v1
kind: Service
metadata:
  name: eclipse-service
spec:
  selector:
    app: eclipse
  ports:
  - port: 80
    targetPort: 8080
---
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler
metadata:
  name: eclipse-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: eclipse-deployment
  minReplicas: 3
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 50
```
This example includes a Deployment for an Eclipse Jetty application, a corresponding Service, and a Horizontal Pod Autoscaler to manage the number of replicas based on observed CPU utilization. Resource limits are set for both the container and the Horizontal Pod Autoscaler.
