 # Kubernetes Concept: DaemonSet
A DaemonSet ensures that a specified number of replicas of a pod run on each node in the cluster.

# Explanation
DaemonSets are particularly useful for deploying system daemons or background services that should run on every node in the cluster. They ensure that a consistent set of pods is running on each node, providing a reliable and uniform deployment of critical components.

# Best Practices
- Use labels to select nodes where the DaemonSet should run.
- Set the desired number of replicas to ensure adequate coverage of nodes.
- Use rolling updates to minimize downtime during updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: my-daemonset
spec:
  selector:
    matchLabels:
      app: my-daemon
  template:
    metadata:
      labels:
        app: my-daemon
    spec:
      containers:
      - name: my-container
        image: my-registry/my-image:latest
        ports:
        - containerPort: 80
          name: http
        readinessProbe:
          tcpSocket:
            port: 80
---
```
This DaemonSet ensures that "my-container" runs as a pod on every node labeled with "app: my-daemon". The container listens on port 80, and the readiness probe checks for the availability of the HTTP service on that port.
