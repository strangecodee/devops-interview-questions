 # Kubernetes Concept: Deployment
A Kubernetes Deployment manages the rollout and scaling of containerized applications. It ensures the desired number of replicas are running and available, and can perform rolling updates and rollbacks.

# Explanation
Deployments in Kubernetes abstract the complexity of updating and scaling containerized applications. They automatically create and manage the associated ReplicaSets and perform rolling updates or rollbacks to ensure minimal downtime and service disruption. With the use of readiness and liveness probes, the Deployment controller ensures only healthy instances are serving traffic.

# Best Practices
- Use rolling updates for gradual deployment of new versions
- Define rolling update strategies, such as '25%' or 'Blue-Green'
- Monitor the rollout progress using the 'kubectl rollout status' command

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula
        image: nebula:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbes:
        - httpGet:
            path: /ready
            port: 80
---
kind: Service
apiVersion: v1
metadata:
  name: nebula-service
spec:
  selector:
    app: nebula
  ports:
  - port: 80
```
