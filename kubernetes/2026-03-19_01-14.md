 # Kubernetes Concept
This is an example of a Kubernetes DaemonSet configuration for running a log collection DaemonSet on AWS Elastic K8s nodes.

# Explanation
A DaemonSet ensures that a specified number of replicas of a pod runs on each node in a cluster. In this example, we configure a DaemonSet to run the Elastic Stack (Elasticsearch, Logstash, and Kibana) on each node for centralized log collection and analysis on an AWS EKS cluster.

# Best Practices
1. Use AWS IAM Roles for Service Accounts to grant required permissions to the DaemonSet.
2. Set resource requests and limits to ensure appropriate resource allocation to Elastic Stack DaemonSets.
3. Monitor DaemonSets using Kubernetes Dashboard and AWS CloudWatch to ensure proper functioning.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: elk
  labels:
    app: elk
spec:
  selector:
    matchLabels:
      app: elk
  template:
    metadata:
      labels:
        app: elk
    spec:
      securityContext:
        runAsUser: 0
      containers:
      - name: elasticsearch
        image: elastic/elasticsearch:7.15.2
        ports:
        - containerPort: 9200
        - containerPort: 9300
        env:
        - name: ELASTIC_JAVA_OPTS
          value: "-Xms512m -Xmx512m"
        resources:
          limits:
            memory: "1Gi"
            cpu: "0.5"
          requests:
            memory: "512Mi"
            cpu: "0.1"
      - name: logstash
        image: docker.elastic.co/logstash/logstash:7.15.2
        ports:
        - containerPort: 5044
        env:
        - name: LOGSTASH_JAVA_OPTS
          value: "-Xms512m -Xmx512m"
        volumeMounts:
        - name: data
          mountPath: /usr/share/logstash/data
      - name: kibana
        image: docker.elastic.co/kibana/kibana:7.15.2
        ports:
        - containerPort: 5601
        env:
        - name: KIBANA_JAVA_OPTS
          value: "-Xms128m -Xmx128m"
        volumes:
        - name: data
          emptyDir: {}
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: elk-data
```
This YAML file creates a DaemonSet with three containers: Elasticsearch, Logstash, and Kibana. The DaemonSet runs on every node in the cluster, ensuring logs are collected and analyzed centrally. Security is addressed by setting the runAsUser to 0. Resource requests and limits are defined for proper resource allocation, and each container's environment variables and ports are also configured. The persistent volume `elk-data` is used to store and persist Elastic Stack data.
