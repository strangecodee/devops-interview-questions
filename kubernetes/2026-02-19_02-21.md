 # Kubernetes Concept
This Kubernetes YAML example demonstrates a deployment for a Java application using an eclipse-jetty container, managed through GitOps.

# Explanation
GitOps is a DevOps approach to application deployment and infrastructure management by using Git as the single source of truth for both the application code and the desired state of the infrastructure. In this example, we'll create a Kubernetes Deployment using eclipse-jetty as the container image, and configure it with readiness and liveness probes.

# Best Practices
1. Use a GitOps workflow, like FluxCD or ArgoCD, to manage your Kubernetes deployments.
2. Use container images with known vulnerabilities scanned and updated regularly.
3. Keep your container images small and light by only including necessary components.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse-jetty-deployment
spec:
  selector:
    matchLabels:
      app: eclipse-jetty
  replicas: 3
  template:
    metadata:
      labels:
        app: eclipse-jetty
    spec:
      containers:
      - name: eclipse-jetty
        image: eclipse:jetty-9-java11
        ports:
        - containerPort: 8080
          protocol: TCP
        livenessProbe:
          httpGet:
            path: /
            port: 8080
        readinessProbe:
          httpGet:
            path: /
            port: 8080
```
