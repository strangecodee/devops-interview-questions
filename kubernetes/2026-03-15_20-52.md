 # Kubernetes Concept
This YAML example demonstrates a Deployment for a simple web application using Kubernetes, focusing on zero-downtime deployments.

# Explanation
A Deployment in Kubernetes manages the lifecycle of a set of replicas, ensuring high availability and scalability for the application. By updating the container image in a new Deployment, Kubernetes creates a new set of replicas, rolling out the changes gradually while maintaining availability by keeping old replicas running until all new replicas are healthy.

# Best Practices
- Use rolling updates: This allows for minimal downtime, as Kubernetes updates replicas one at a time.
- Set up a readiness probe: A readiness probe checks the application's readiness before marking a new replica as healthy.
- Set up a liveness probe: A liveness probe checks the application's overall health while the container is running.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: myapp-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: myapp
  template:
    metadata:
      labels:
        app: myapp
    spec:
      containers:
      - name: myapp
        image: myregistry/myapp:v1.0.0
        ports:
        - containerPort: 80
        readinessProbe:
          exec:
            command: ["curl", "--fail", "/"]
          periodSeconds: 5
        livenessProbe:
          exec:
            command: ["curl", "--fail", "/"]
          periodSeconds: 15
---
apiVersion: v1
kind: Service
metadata:
  name: myapp-service
spec:
  selector:
    app: myapp
  ports:
  - port: 80
    targetPort: 80
  type: LoadBalancer
```
This example demonstrates a deployment for a simple web application using a rolling update strategy, and includes readiness and liveness probes to ensure the application's availability and health.
