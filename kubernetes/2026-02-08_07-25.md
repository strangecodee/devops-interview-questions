 # Kubernetes Concept
This YAML example demonstrates a Kubernetes Horizontal Pod Autoscaler (HPA) configuration for a deployment with monitoring enabled using Prometheus and Grafana.

# Explanation
The Kubernetes HPA automatically scales the number of pods in a deployment based on observed CPU utilization. In this example, we define a Prometheus and Grafana deployment that will be used to monitor and visualize the performance of the application. The HPA is set up to scale the number of replicas based on CPU utilization and a predefined minimum and maximum limit.

# Best Practices
- Practice 1: Use resource limits and requests to ensure that your containers are using resources efficiently and that the HPA can effectively make scaling decisions.
- Practice 2: Monitor both CPU and memory usage to get a holistic view of your application's resource utilization.
- Practice 3: Set up alerts and notifications to be notified when the HPA scales or when specific performance thresholds are exceeded.

# YAML Example
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  accessModes: ["ReadWriteOnce"]
  resources:
    requests:
      storage: 1Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-app:latest
        ports:
        - containerPort: 80
        env:
        - name: MY_APP_ENV_VAR
          value: "value"
        resources:
          limits:
            cpu: "1"
            memory: "512Mi"
          requests:
            cpu: "0.5"
            memory: "256Mi"
          securityContext:
            runAsUser: 1001
        volumeMounts:
        - mountPath: /data
          name: data-pvc
---
apiVersion: v1
kind: Service
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  ports:
  - protocol: TCP
    port: 80
    targetPort: 80
---
apiVersion: apps/v1
kind: HorizontalPodAutoscaler
metadata:
  name: my-app-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: my-app
  minReplicas: 1
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      targetAverageUtilization: 50
---
apiVersion: v1
kind: PersistentVolume
metadata:
  name: data-pv
spec:
  capacity:
    storage: 1Gi
  accessModes: ["ReadWriteOnce"]
  persistentVolumeReclaimPolicy: Retain
  storageClassName: standard
  nodeAffinity:
    requiredDuringSchedulingIgnoredDuringExecution:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - node-name
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: prometheus
spec:
  replicas: 2
  selector:
    matchLabels:
      app: prometheus
  template:
    metadata:
      labels:
        app: prometheus
    spec:
      containers:
      - name: prometheus
        image: prom/prometheus:v2.29.0
        ports:
        - containerPort: 9090
        env:
        - name: RBAC_AUTH_MODE
          value: "enable"
        - name: RBAC_ALLOW_ANONYMOUS_ACCESS
          value: "false"
        volumeMounts:
        - mountPath: /prometheus/data
          name: data-pvc
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  accessModes: ["ReadWriteOnce"]
  resources:
    requests:
      storage: 5Gi
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: grafana
spec:
  replicas: 1
  selector:
    matchLabels:
      app: grafana
  template:
    metadata:
      labels:
        app: grafana
    spec:
      containers:
      - name: grafana
        image: grafana/grafana:latest
        ports:
        - containerPort: 3000
        env:
        - name: GF_INSTALL_PLUGINS
          value: "grafana-piechart-panel,grafana-statalert-panel"
        volumeMounts:
        - mountPath: /var/lib/grafana
          name: data-pvc
---
apiVersion: v1
kind: PersistentVolume
metadata:
  name: data-pv-grafana
spec:
  capacity:
    storage: 10Gi
  accessModes: ["ReadWriteOnce"]
  persistentVolumeReclaimPolicy: Retain
  storageClassName: grafana-pvc
  nodeAffinity:
    requiredDuringSchedulingIgnoredDuringExecution:
      nodeSelectorTerms:
      - matchExpressions:
        - key: kubernetes.io/hostname
          operator: In
          values:
          - node-name
---
apiVersion: v1
kind: Service
metadata:
  name: grafana-service
spec:
  selector:
    app: grafana
  ports:
  - protocol: TCP
    port: 3000
    targetPort: 3000
```
