 # Kubernetes Concept
This is an example of a Kubernetes DaemonSet for monitoring the health and readiness of containers using the Prometheus vector database and Grafana dashboard.

# Explanation
A DaemonSet ensures that a specified number of replicas of a pod are running on each node in the cluster. In this case, we will use a DaemonSet to deploy Prometheus and Grafana for container monitoring. Prometheus is an open-source monitoring system and time series database. Grafana is used for data visualization.

# Best Practices
- Ensure that the Prometheus service is accessible from other services in the cluster by creating a Kubernetes ClusterRole and adding the necessary service accounts.
- Use TLS certificates for secure communication between the different components.
- Regularly backup the Prometheus data to prevent data loss.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: monitoring
  labels:
    app: monitoring
spec:
  selector:
    matchLabels:
      app: monitoring
  template:
    metadata:
      labels:
        app: monitoring
    spec:
      containers:
      - name: prometheus
        image: prom/prometheus:v2.31.0
        ports:
        - containerPort: 9090
          name: prom-http
        - containerPort: 9091
          name: prom-https
        env:
        - name: PROMETHEUS_CONFIG_FILE
          value: /etc/prometheus/prometheus.yml
        volumeMounts:
        - name: prometheus-config
          mountPath: /etc/prometheus
        - name: prometheus-data
          mountPath: /prometheus
      containers:
      - name: grafana
        image: grafana/grafana:8.3.0
        ports:
        - containerPort: 3000
          name: grafana
        env:
        - name: GF_INSTALL_PLUGINS
          value: "grafana-piechart-panel"
        volumeMounts:
        - name: grafana-persist
          mountPath: /var/lib/grafana
        - name: grafana-config
          mountPath: /etc/grafana
      volumes:
      - name: prometheus-config
        configMap:
          name: prometheus-config
      - name: prometheus-data
        emptyDir: {}
      - name: grafana-persist
        persistentVolumeClaim:
          name: grafana-persist
      - name: grafana-config
        configMap:
          name: grafana
```
This YAML file creates a DaemonSet with two containers: Prometheus and Grafana. The containers are run as daemons, ensuring they are always available on each node in the cluster. Prometheus is configured to listen on ports 9090 and 9091 for HTTP and HTTPS respectively, while Grafana is configured to listen on port 3000. The containers are also configured to mount various volumes for configuration and data storage. The Prometheus and Grafana containers are deployed from their respective Docker images, and the containers are linked to ensure that Grafana can access Prometheus data.
