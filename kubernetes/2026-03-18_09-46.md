 # Kubernetes Concept
Deployment is a Kubernetes resource for defining and managing containerized applications. It ensures predefined application versions are running.

# Explanation
A Deployment creates and manages replicas of a specified Pod template. When new revisions are created, Kubernetes rolls out the update in batches, ensuring high availability and minimal downtime.

# Best Practices
- Label replicas for easier management and scaling.
- Use rolling updates for minimal downtime.
- Monitor application health with liveness and readiness probes.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: atlas
  labels:
    app: atlas
spec:
  selector:
    matchLabels:
      app: atlas
  replicas: 3
  template:
    metadata:
      labels:
        app: atlas
    spec:
      containers:
      - name: atlas
        image: myregistry/atlas:v1.0
        ports:
        - containerPort: 80
          name: http
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
