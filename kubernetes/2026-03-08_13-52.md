 # Kubernetes Deployment
This is a YAML definition for a Kubernetes Deployment. It manages the rollout and scaling of a containerized application.

# Explanation
A Deployment in Kubernetes is used to create and manage replicas of a containerized application. It ensures availability and continuity through rolling updates and self-healing capabilities, which automatically restart containers that fail.

# Best Practices
- Use rolling updates for minimal downtime during upgrades
- Set up readiness and liveness probes to ensure application health
- Use resource limits to prevent container resource contention

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
      readinessProbe:
        probes:
        - exec:
            command: ["/usr/local/bin/readiness"]
      livenessProbe:
        probes:
        - exec:
            command: ["/usr/local/bin/liveness"]
---
kind: Service
apiVersion: v1
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  ports:
  - port: 80
```
This Deployment creates three replicas of `my-app` container with the specified image, and sets up a readiness and liveness probe for the container. The Service exposing the Deployment on port 80 is included for external access to the application.
