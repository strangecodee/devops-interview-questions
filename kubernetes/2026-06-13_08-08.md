 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications. It ensures that a specified number of replicas of an application are running at any given time.

# Explanation
A Kubernetes Deployment creates and manages replicas of a containerized application. It ensures that a desired number of replicas are always available, and it can roll out new container versions with minimal downtime. It also provides features like rolling updates and rolling back to a previous version if needed.

# Best Practices
- Use rolling updates with a small update percentage to minimize downtime.
- Set up a health check to ensure that only healthy replicas are serving traffic.
- Use readiness and liveness probes to detect and handle unhealthy containers.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/ phoenix:latest
        ports:
        - containerPort: 8080
        readinessProbe:
          probeType: HttpGet
          path: /health
          initialDelaySeconds: 5
          periodSeconds: 5
        livenessProbe:
          probeType: HttpGet
          path: /health
          initialDelaySeconds: 15
          periodSeconds: 10
```
