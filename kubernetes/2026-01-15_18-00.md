 # Kubernetes Concept
Deployment is a Kubernetes object used to manage the rolling update and scaling of containers.

# Explanation
A Deployment creates and manages replicas of a specified container image. It also ensures availability by rolling out updates in a controlled manner and rolling back if necessary. This provides zero-downtime deployments.

# Best Practices
- Use `rollout undo` to roll back to a previous version in case of issues.
- Monitor your deployments using Kubernetes Dashboard or monitoring tools like Prometheus.
- Use a strategy like `RollingUpdate` or `Recreate` as update types.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: quantum-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: quantum
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
    template:
      metadata:
        labels:
          app: quantum
      spec:
        containers:
        - name: quantum
          image: registry.example.com/quantum:latest
          ports:
          - containerPort: 80
          readinessProbe:
            probes:
            - exec:
                command: ["/bin/sh", "-c", "curl --fail http://localhost || exit 1"]
              intervalSeconds: 5
              timeoutSeconds: 1
          livenessProbe:
            probes:
            - exec:
                command: ["/bin/sh", "-c", "curl --fail http://localhost || exit 1"]
              intervalSeconds: 15
              timeoutSeconds: 1
```
