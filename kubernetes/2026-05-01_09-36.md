# Kubernetes Concept
Deployment is a Kubernetes resource for describing and managing a set of replicas for a container application.

# Explanation
A Deployment maintains a specified number of replicas for a container application, rolling out updates and rolling back to a previous version if needed. It ensures high availability and scales the application based on the desired replicas.

# Best Practices
- Use rolling updates for minimal downtime and gradual deployment of new versions.
- Use readiness and liveness probes to check the health of containers and manage the scaling accordingly.
- Use labels for selectors and rollouts to apply configurations and manage deployments.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app
        image: my-registry/my-app:v1.0.0
        ports:
        - containerPort: 80
          name: http
        readinessProbe:
          tcpSocket:
            port: http
        livenessProbe:
          httpGet:
            path: /healthz
            port: http
```
