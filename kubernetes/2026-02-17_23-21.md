 # Kubernetes Concept
Deployment is a Kubernetes object used for creating and updating applications. It ensures availability, scalability, and rollbacks.

# Explanation
A Kubernetes Deployment creates and manages replicas of containers. It rolls out updates following a strategy, such as RollingUpdate or Recreate, and performs self-healing.

# Best Practices
- Use RollingUpdate strategy for minimal downtime and maximum availability.
- Set up a readiness probe to ensure containers are ready to accept traffic before starting new replicas.
- Use a liveness probe to monitor containers and restart unresponsive ones.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse
spec:
  replicas: 3
  selector:
    matchLabels:
      app: eclipse
  template:
    metadata:
      labels:
        app: eclipse
    spec:
      containers:
      - name: eclipse
        image: openjdk:8-jdk-alpine
        ports:
        - containerPort: 8080
          protocol: TCP
        readinessProbe:
          probeType: HTTP
          httpGet:
            path: /actuator/health/ready
            port: 8084
          initialDelaySeconds: 15
          periodSeconds: 15
        livenessProbe:
          probeType: HTTP
          httpGet:
            path: /actuator/health/liveness
            port: 8084
          initialDelaySeconds: 15
          periodSeconds: 15
```
