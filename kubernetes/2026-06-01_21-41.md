# Kubernetes Concept
Deployment is a declarative way to create and manage containerized applications in Kubernetes.

# Explanation
Deployments manage the lifecycle of a set of replicas for a given application, ensuring that the desired number of instances are running and available. It offers features like rolling updates, rollbacks, and self-healing mechanisms.

# Best Practices
- Use labels and selectors for easy management and identification of pods.
- Set up resource limits and requests for optimal use of system resources.
- Use rolling updates for minimal downtime during application updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: example-app
  labels:
    app: example
spec:
  replicas: 3
  selector:
    matchLabels:
      app: example
  template:
    metadata:
      labels:
        app: example
    spec:
      containers:
      - name: example-container
        image: example:latest
        ports:
        - containerPort: 80
```
This YAML example creates a Kubernetes Deployment named `example-app` using the `apps/v1` API. It sets up three replicas and uses the `example` label for identification. The container in the template uses the `example:latest` image with port `80` for external access.
