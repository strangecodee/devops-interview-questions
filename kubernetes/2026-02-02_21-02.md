 # Kubernetes Concept
Deployment is a Kubernetes object that creates and manages replicas of a containerized application. It ensures that a specified number of replicas are running at any given time and replaces any unhealthy or crashed containers.

# Explanation
A Deployment maintains the desired state of an application by creating or updating replicas based on a specified image tag, container port, and number of desired replicas. Kubernetes continuously rolls out updates to the replicas in batches, allowing for easier rollbacks if issues are encountered.

# Best Practices
- Use `rolling-update` strategy for smaller updates and `recreate` strategy for major updates.
- Set up resource limits and requests to ensure efficient resource utilization and prevent container starvation.
- Use Label Selectors and selectors in selectors for efficient scaling and management of the application.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: registry.example.com/phoenix:v1.0.0
        ports:
        - containerPort: 8080
          name: http
          protocol: TCP
      imagePullSecrets:
      - name: registry-secret
```
