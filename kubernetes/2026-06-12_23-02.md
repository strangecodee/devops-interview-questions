 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications.

# Explanation
A Deployment creates and manages the lifecycle of a group of replicas, ensuring availability and scaling of an application. It can perform rolling updates and rollbacks, and it can automatically replace unhealthy containers.

# Best Practices
- Use labels to select and manage a group of pods.
- Use replicas to ensure high availability and scaling.
- Use rolling updates to minimize downtime and maximize availability.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
          name: http
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
This Deployment creates three replicas of a container called `my-app-container`, which runs the image `my-registry/my-app:latest`. The container listens on port 80 and has a liveness probe and a readiness probe. The YAML follows best practices by using labels to manage and select pods, and by using rolling updates to ensure minimal downtime.
