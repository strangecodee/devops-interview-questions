 # Kubernetes Concept
Deployment is a Kubernetes object used to create and manage containerized applications. It ensures that a specified number of replicas of a container image are running in the cluster at any given time.

# Explanation
A Deployment in Kubernetes provides declarative updates for your applications. When you change the desired state of the application, the Deployment controller changes the actual state of the cluster to the desired state at a controlled rate. This is accomplished by creating new replicas, removing old ones, and rolling out updates.

# Best Practices
- Use rolling updates to minimize downtime and apply changes gradually.
- Set up readiness and liveness probes to monitor the health of your containers and only mark them as ready when they are ready to serve traffic.
- Use labels and selectors to manage and maintain your deployments effectively.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse-deployment
  labels:
    app: eclipse
spec:
  replicas: 3
  selector:
    matchLabels:
      app: eclipse
  template:
    metadata:
      labels:
        app: eclipse
    spec:
      containers:
      - name: eclipse
        image: eclipse:latest
        ports:
        - containerPort: 8443
          name: http
        readinessProbe:
          httpGet:
            path: /
            port: 8443
          initialDelaySeconds: 5
          periodSeconds: 5
          failureThreshold: 3
        livenessProbe:
          httpGet:
            path: /
            port: 8443
          initialDelaySeconds: 15
          periodSeconds: 10
          failureThreshold: 3
```
