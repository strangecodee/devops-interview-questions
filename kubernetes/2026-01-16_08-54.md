 # Kubernetes Concept
Deployment is a Kubernetes object used for deploying and managing containerized applications. It ensures a specified number of replicas of a container image are running and maintains their availability.

# Explanation
Deployments manage the lifecycle of a set of Pods, creating new ones when needed and removing old ones when they are no longer necessary. They also perform rolling updates and rollbacks, allowing for seamless application upgrades and easy disaster recovery. Deployments provide a declarative update mechanism for managing the desired state of a running application in a cluster.

# Best Practices
- Define a rollout strategy for your Deployment to minimize application downtime during updates.
- Use a readiness probe to ensure your application is ready to receive traffic before scaling or exposing it to end-users.
- Use a liveness probe to monitor the health of your containers and automatically restart unhealthy instances.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-sre-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
      environment: sre
  template:
    metadata:
      labels:
        app: nebula
        environment: sre
    spec:
      containers:
      - name: nebula
        image: nebula:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 30
          periodSeconds: 15
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
          initialDelaySeconds: 30
          periodSeconds: 15
```
