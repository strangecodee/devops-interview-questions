# Kubernetes Concept
Deployment is a way to create, update, and manage containers in a Kubernetes cluster.

# Explanation
A Kubernetes Deployment manages the lifecycle of a set of replica Pods, creating new ones as needed to maintain the desired state, and scaling them horizontally or vertically based on the workload. This ensures high availability and resilience to failures.

# Best Practices
- Practice 1: Use Rolling Updates for minimal downtime when updating your application.
- Practice 2: Set up Health Checks to monitor the readiness and liveness of your containers.
- Practice 3: Configure Horizontal Pod Autoscaling to automatically scale your application based on resource usage or CPU/Memory utilization.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: quantum-sre-app
  labels:
    app: quantum
spec:
  replicas: 3
  selector:
    matchLabels:
      app: quantum
  template:
    metadata:
      labels:
        app: quantum
    spec:
      containers:
        - name: quantum-container
          image: myregistry/quantum:latest
          ports:
            - containerPort: 80
          imagePullSecrets:
            - name: my-registry-secret
          livenessProbe:
            httpGet:
              path: /healthz
              port: 80
          readinessProbe:
            httpGet:
              path: /ready
              port: 80
```
In this example, we create a Deployment named 'quantum-sre-app' with three replicas, using the 'quantum' image, and specify a container port and image pull secret. We also configure liveness and readiness probes to check the health of our application.
