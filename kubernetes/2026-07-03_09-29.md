 # Kubernetes Concept
Kubernetes DaemonSet ensures that a specified number of replicas of a pod are running on each node in the cluster.

# Explanation
A DaemonSet maintains a pod replica on each node, making it suitable for workloads that require a pod instance on every node, such as logging or monitoring daemons. DaemonSets are managed at the cluster level, and the nodes are responsible for the pod lifecycle.

# Best Practices
- Use resource limits and requests to ensure efficient and fair resource allocation.
- Configure rolling updates carefully to minimize the impact on the cluster's stability and availability.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: mylogdaemonset
spec:
  selector:
    matchLabels:
      name: my-log-daemon
  template:
    metadata:
      labels:
        name: my-log-daemon
    spec:
      containers:
      - name: my-log-container
        image: mylogimage:latest
        ports:
        - containerPort: 514
        securityContext:
          privileged: true
          seLinuxOptions:
            level: "s0"
            seContextType: "scontext_t"
          readOnlyRootFilesystem: false
---
apiVersion: v1
kind: Service
metadata:
  name: mylogservice
spec:
  selector:
    name: my-log-daemon
  ports:
  - port: 1514
    targetPort: 514
  type: ClusterIP
```
