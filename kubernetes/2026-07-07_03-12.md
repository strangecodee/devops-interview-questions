 # Kubernetes Concept
Deployment is a Kubernetes resource for managing containerized applications. It keeps a specified number of replicas running and ensures their availability and readiness.

# Explanation
A Deployment creates or updates a set of replicas of a container image based on a defined image tag or a commit hash in a Git repository using a rollout. This process ensures that the application remains available during updates or rollbacks. Kubernetes monitors the replicas' readiness and availability, and if a replica fails, it automatically creates a new one.

# Best Practices
- Use labels for better management and organization of your Deployments.
- Set up Rolling updates for minimal downtime during updates.
- Use Liveness and Readiness probes for efficient monitoring and self-healing capabilities.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: example-app
  labels:
    app: example
spec:
  replicas: 3
  selector:
    matchLabels:
      app: example
  template:
    metadata:
      labels:
        app: example
    spec:
      containers:
      - name: example-container
        image: example-image:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
