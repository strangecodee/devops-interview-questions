 # Kubernetes Concept
This is an example of a Kubernetes DaemonSet for monitoring the health and readiness of nodes in a cluster using the Prometheus vector database and Grafana stack.

# Explanation
A DaemonSet ensures that a specified number of replicas of a pod are running on each node in the cluster. In this case, we use DaemonSets to deploy Prometheus and Grafana on every node for centralized monitoring. Prometheus collects metrics from the cluster and stores them in a time-series database, while Grafana provides a user interface for visualizing those metrics.

# Best Practices
- Use RBAC to secure access to your DaemonSets and other sensitive Kubernetes resources.
- Regularly update the images used in your DaemonSets to maintain security and functionality.
- Monitor the resource usage of your DaemonSets to ensure they're not consuming excessive resources.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: prometheus
  labels:
    app: prometheus
spec:
  selector:
    matchLabels:
      app: prometheus
  template:
    metadata:
      labels:
        app: prometheus
    spec:
      containers:
      - name: prometheus
        image: quay.io/prometheus/prometheus:v2.31.0
        ports:
        - containerPort: 9090
          name: prometheus-web
        args:
        - "--config.file=/etc/prometheus/prometheus.yml"
        volumeMounts:
        - name: prometheus-storage
          mountPath: /prometheus
          subPath: prometheus
      volumes:
      - name: prometheus-storage
        persistentVolumeClaim:
          claimName: prometheus-pvc
---
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: grafana
  labels:
    app: grafana
spec:
  selector:
    matchLabels:
      app: grafana
  template:
    metadata:
      labels:
        app: grafana
    spec:
      containers:
      - name: grafana
        image: grafana/grafana:8.3.5
        ports:
        - containerPort: 3000
          name: grafana-web
        env:
        - name: GF_INSTALL_PLUGINS
          value: "grafana-piechart-panel,grafana-statistics-panel"
        volumeMounts:
        - name: grafana-storage
          mountPath: /var/lib/grafana
      volumes:
      - name: grafana-storage
        persistentVolumeClaim:
          claimName: grafana-pvc
```
This YAML example creates two DaemonSets for Prometheus and Grafana. Prometheus collects metrics, while Grafana visualizes those metrics. Both DaemonSets use persistent volume claims to ensure data persistence between restarts.
