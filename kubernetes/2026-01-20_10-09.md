 # Kubernetes Concept
Deployment is a Kubernetes object used for updating, scaling, and managing containers. It maintains a desired state by creating or updating replica sets and rolling out updates.

# Explanation
A Kubernetes Deployment creates or updates replica sets ensuring a specific number of replicas are running and available. It performs rolling updates and self-healing, ensuring the desired state is maintained.

# Best Practices
- Use rolling updates in smaller increments to minimize downtime or potential issues.
- Set up readiness and liveness probes to ensure containers are healthy and ready to serve traffic.
- Use labels for easier management and scaling of pods.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: eclipse
  labels:
    app: eclipse
spec:
  replicas: 3
  selector:
    matchLabels:
      app: eclipse
  template:
    metadata:
      labels:
        app: eclipse
    spec:
      containers:
      - name: eclipse
        image: eclipse:latest
        ports:
        - containerPort: 4040
        readinessProbe:
          probes:
          - exec:
              command: ["/usr/bin/wc", "-c", "/tmp/health"]
              intervalSeconds: 15
          timeoutSeconds: 5
        livenessProbe:
          probes:
          - exec:
              command: ["/usr/bin/pwsh", "-Command", "& { Start-Sleep -s 30 }"]
              intervalSeconds: 30
          timeoutSeconds: 15
```
