 # Kubernetes Concept
This Kubernetes YAML example demonstrates a Deployment for a monitoring application using Prometheus and Grafana, plus a corresponding Service and ConfigMap.

# Explanation
The Deployment creates and manages the containers for Prometheus and Grafana, while the Service exposes their external endpoints on specific ports. The ConfigMap stores the initial configuration files for these applications.

# Best Practices
- Use `kubeseal` or `helm` for securing Kubernetes manifests
- Implement RBAC roles and bindings for access control
- Use `kubicorn` for declarative cluster management

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: monitoring
  labels:
    app: monitoring
spec:
  replicas: 3
  selector:
    matchLabels:
      app: monitoring
  template:
    metadata:
      labels:
        app: monitoring
    spec:
      securityContext:
        runAsUser: 1000
      containers:
      - name: prometheus
        image: prom/prometheus:v2.31.0
        ports:
        - containerPort: 9090
        volumeMounts:
        - mountPath: /prometheus
          name: prometheus-config
        env:
        - name: PROMETHEUS_CONFIG_FILE
          value: prometheus.yml
        volume:
          name: prometheus-config
          configMap:
            name: prometheus-config
      - name: grafana
        image: grafana/grafana:7.5.3
        ports:
        - containerPort: 3000
        env:
        - name: GF_INSTALL_PLUGINS
          value: admin-dashboard-plugin
        volumeMounts:
        - mountPath: /var/lib/grafana
          name: grafana-data
        volume:
          name: grafana-data
  volumeClaimTemplates:
  - metadata:
      name: prometheus-config
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          configMaps: 1
  - metadata:
      name: grafana-data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          persistentVolumeClclaim: 10Gi
---
apiVersion: v1
kind: Service
metadata:
  name: monitoring
spec:
  selector:
    app: monitoring
  ports:
  - name: prometheus
    port: 9090
    targetPort: 9090
  - name: grafana
    port: 3010
    targetPort: 3000
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: prometheus-config
data:
  prometheus.yml: |
    scrape_configs:
    - job_name: 'prometheus'
      static_configs:
      - targets: ['localhost:9090']
```
