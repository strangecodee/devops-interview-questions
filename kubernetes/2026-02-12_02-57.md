 # Kubernetes Concept
Deployment is a Kubernetes resource for creating, managing, and updating containers. It maintains a specified number of replicas and their availability.

# Explanation
A Deployment ensures that a specified number of replicas of a container image are running at any given time. When a new container image is released, Kubernetes can create a new ReplicaSet, update the containers in the old ReplicaSet, and rollout the update gradually, minimizing downtime.

# Best Practices
- Use rolling updates for container images to minimize downtime.
- Use a config map or secret to store sensitive information in a centralized location.
- Monitor the progress of the update using the `kubectl rollout status` command.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-deployment
spec:
  selector:
    matchLabels:
      app: nebula
  replicas: 3
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula
        image: nebula:latest
        ports:
        - containerPort: 8080
        readinessProbe:
          probes:
          - exec:
              command: ["/usr/bin/curl", "--fail", "http://localhost:8080/"]
              intervalSeconds: 5
              timeoutSeconds: 2
          failureThreshold: 3
```
