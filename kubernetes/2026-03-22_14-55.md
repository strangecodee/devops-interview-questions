 # Kubernetes Concept
Kubernetes DaemonSet is a Kubernetes object used to ensure a copy of a pod is running on all nodes in the cluster.

# Explanation
A DaemonSet ensures that a specified number of replicas of a pod are running on each node in the cluster. This is useful for deploying services such as logging agents, monitoring agents, or network proxies. In case a node is drained or a pod is terminated, DaemonSet automatically schedules a new pod to run on the node.

# Best Practices
- Ensure that the container image used in the DaemonSet is updated regularly to keep the security patches and features up to date.
- Use labels for efficient management and scheduling of DaemonSets.
- Implement resource limits and requests to control the usage of resources on the nodes.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: eclipse-logging-agent
  labels:
    app: eclipse-logging-agent
spec:
  selector:
    matchLabels:
      app: eclipse-logging-agent
  template:
    metadata:
      labels:
        app: eclipse-logging-agent
    spec:
      containers:
      - name: eclipse-logging-agent
        image: eclipse-logging-agent:latest
        ports:
        - containerPort: 24224
        resources:
          limits:
            cpu: "0.5"
            memory: "512Mi"
          requests:
            cpu: "250m"
            memory: "256Mi"
        readinessProbe:
          exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:8080/health || exit 1"]
          intervalSeconds: 30
---
apiVersion: v1
kind: Service
metadata:
  name: eclipse-logging-agent-service
spec:
  selector:
    app: eclipse-logging-agent
  ports:
  - port: 80
    targetPort: 24224
```
This DaemonSet deploys the eclipse-logging-agent container on all nodes in the cluster. The container listens on port 24224 and exposes a service on port 80 for external access. The readiness probe is used to check the health of the container before it's considered ready to serve traffic. Resource limits and requests are set to control the usage of resources on the nodes.
