 # Kubernetes Concept
This is an example of a Kubernetes Deployment for a simple web application using a container image, with a focus on scalability and readiness probes.

# Explanation
A Kubernetes Deployment manages the rollout and scaling of containerized applications. In this example, we will create a Deployment for a web application using a container image. We will also set up readiness and liveness probes for monitoring the application's health and scalability.

# Best Practices
- Use rolling updates for minimal downtime during Deployment updates.
- Set up appropriate resource limits and requests to ensure efficient resource usage.
- Use horizontal pod autoscaling to automatically adjust the number of replicas based on the load.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-web-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-web-app
  template:
    metadata:
      labels:
        app: my-web-app
    spec:
      containers:
      - name: my-web-container
        image: my-container-registry/my-web-app:latest
        ports:
        - containerPort: 80
        readinessProbes:
        - exec:
            command: ["curl", "--fail", "/"]
            intervalSeconds: 5
        livenessProbes:
        - exec:
            command: ["curl", "--fail", "/"]
            intervalSeconds: 30
```
