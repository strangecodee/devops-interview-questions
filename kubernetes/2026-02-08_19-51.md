 # Kubernetes Concept
Deployment is a Kubernetes resource for managing the rollout and scaling of containerized applications.

# Explanation
The Kubernetes Deployment resource ensures that a specified number of replicas of a container image are running at any given time. It also manages the updates of the containers, rolling out new versions in a controlled manner. The rolling update strategy can include rolling updates, blue-green deployments, or canary deployments.

# Best Practices
- Use a `rolling-update` strategy with a `maxSurge` and `maxUnavailable` to control the number of new and old pods that can be running at a time.
- Define a `readinessProbe` and `livenessProbe` for your container to ensure the containers are running healthy and ready to receive traffic.
- Use `imagePullSecrets` to securely store and access Docker registry credentials.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
spec:
  selector:
    matchLabels:
      app: my-app
  replicas: 3
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
        - name: my-app-container
          image: my-registry/my-app:latest
          ports:
            - containerPort: 80
          readinessProbes:
            - probe:
                exec:
                  command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
                intervalSeconds: 5
                timeoutSeconds: 2
                failureThreshold: 3
          livenessProbes:
            - probe:
                exec:
                  command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
                intervalSeconds: 30
                timeoutSeconds: 5
                failureThreshold: 3
      imagePullSecrets:
        - name: my-registry-secret
```
