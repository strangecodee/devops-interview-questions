 # Kubernetes Concept
This YAML example demonstrates a deployment and service for a simple application using Kubernetes Terraform configuration.

# Explanation
Kubernetes Terraform is a provider for deploying and managing Kubernetes resources using Hashicorp's Terraform tool. In this example, we will create a deployment and service for an Nginx web server. The deployment will be managed using a container image, and the service will provide a stable IP address for accessing the container.

# Best Practices
- Use a separate Kubernetes namespace for your application to keep resources organized and secure.
- Set resource limits and requests for your containers to optimize resource usage and prevent container contention.
- Use secure container images and configure RBAC roles and bindings to restrict access to sensitive resources.

# YAML Example
```yaml
provider "kubernetes" {
  config_path = "path/to/kubeconfig"
  version = "2.0.4"
}

data "kubernetes_namespace" "default" {
  metadata {
    name = "default"
  }
}

resource "kubernetes_namespace" "nebula" {
  metadata {
    name = "nebula"
  }
}

resource "kubernetes_deployment" "nginx" {
  metadata {
    name      = "nginx"
    namespace = kubernetes_namespace.nebula.metadata.0.name
  }

  spec {
    selector {
      match_labels = {
        App = "nginx"
      }
    }

    template {
      metadata {
        labels = {
          App = "nginx"
        }
      }

      spec {
        container {
          name  = "nginx"
          image = "nginx:latest"

          resources {
            requests = {
              cpu    = "100m"
              memory = "128Mi"
            }
            limits = {
              cpu    = "250m"
              memory = "256Mi"
            }
          }

          port {
            container_port = 80
          }
        }
      }
    }
  }
}

resource "kubernetes_service" "nginx" {
  metadata {
    name      = "nginx"
    namespace = kubernetes_namespace.nebula.metadata.0.name
  }

  spec {
    selector = {
      App = "nginx"
    }

    port {
      port        = 80
      target_port  = 80
      protocol     = "TCP"
      name        = "http"
    }

    type = "ClusterIP"
  }
}
```
This YAML example uses Kubernetes Terraform to create a deployment and service for an Nginx web server. The deployment runs the latest Nginx container image in a new namespace called "nebula", and sets resource limits and requests for CPU and memory. The service provides a stable IP address for accessing the Nginx container using port 80.
