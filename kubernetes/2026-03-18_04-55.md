 # Kubernetes Deployment
Create and manage containerized applications in a platform-agnostic way using Kubernetes Deployments.

# Explanation
Kubernetes Deployments manage the lifecycle of a set of replicas for a desired number of available instances of a containerized application. They ensure that a specified number of replicas are running at any given time to maintain desired availability and scalability.

# Best Practices
- Use Rollouts to update Deployments progressively, minimizing downtime.
- Configure Automated Rollbacks to quickly revert to a previous state in case of issues.
- Implement Blue-Green or Canary deployments for zero-downtime application updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-app:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
```
