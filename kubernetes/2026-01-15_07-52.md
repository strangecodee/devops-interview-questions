 # Kubernetes Concept
Kubernetes DaemonSet: A way to ensure a copy of a pod runs on all nodes in a cluster.

# Explanation
DaemonSets ensure that a specific pod is running on all nodes in a Kubernetes cluster, maintaining a consistent and uniform state across the entire cluster. This is particularly useful for processes like monitoring agents, logging agents, or network attachments that should be available on every node.

# Best Practices
- Use labels to match nodes that meet certain criteria for DaemonSet assignment.
- Use rolling updates for DaemonSets to minimize disruptions and ensure a smooth deployment process.
- Monitor the status of DaemonSets and their associated pods to identify and address any issues promptly.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: my-daemonset
spec:
  selector:
    matchLabels:
      app: my-daemon
  template:
    metadata:
      labels:
        app: my-daemon
    spec:
      containers:
      - name: my-daemon
        image: my-image:latest
        ports:
        - containerPort: 80
        - containerPort: 443
        readinessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
        - initialDelaySeconds: 30
        livenessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
        - initialDelaySeconds: 60
---
kind: Service
apiVersion: v1
metadata:
  name: my-daemonset-service
spec:
  selector:
    app: my-daemon
  ports:
  - port: 80
    targetPort: 80
```
