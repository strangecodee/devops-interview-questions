 # Kubernetes Concept
Service is a Kubernetes resource that provides a network access point for a running application. It is responsible for load balancing and service discovery.

# Explanation
Services define a policy for accessing a set of Pods in a Kubernetes cluster, providing a stable IP address and DNS name for external traffic. Kubernetes uses a load balancing algorithm to distribute incoming traffic to the available Pods.

# Best Practices
- Use a single service per microservice to maintain simplicity and improve observability.
- Use external IP for services that need to be accessible from the internet.
- Use Cluster IP for services that need to be accessible only within the cluster.

# YAML Example
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-web-app
spec:
  selector:
    app: my-web
  ports:
  - name: http
    port: 80
    targetPort: 8080
  type: ClusterIP
```
This example creates a Cluster IP Service named `my-web-app` for a microservice with the label `app: my-web` that listens on port 8080. The Service exposes port 80 for external access.
