 # Kubernetes Concept
Deployment is a Kubernetes object used for declarative updates for a set of Pods. It ensures a specified number of replicas are running and ready to serve.

# Explanation
A Deployment creates or updates Pods in a cluster based on a desired state defined by the user. It continuously attempts to maintain this state by rolling out updates to new replicas while maintaining a stable set of replicas to ensure high availability. This is accomplished through a process called rolling updates.

# Best Practices
- Use rolling updates to minimize downtime and ensure a smooth transition from one version to another.
- Set up a strategy for updating all your replicas at once using the "Recreate" update strategy for smaller deployments or "Blue/Green" for larger ones.
- Monitor the health of your Deployment using the Kubernetes Dashboard or external monitoring tools.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: forge-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: forge
  template:
    metadata:
      labels:
        app: forge
    spec:
      containers:
      - name: forge
        image: forge:latest
        ports:
        - containerPort: 80
      imagePullSecrets:
      - name: regcred
      readinessProbes:
      - probe:
          exec:
            command: ["curl", "--fail", "http://:80/healthz"]
          initialDelaySeconds: 5
          periodSeconds: 5
      livenessProbes:
      - probe:
          exec:
            command: ["curl", "--fail", "http://:80/healthz"]
          initialDelaySeconds: 15
          periodSeconds: 10
---
kind: Service
apiVersion: v1
metadata:
  name: forge-service
spec:
  selector:
    app: forge
  ports:
  - port: 80
    targetPort: 80
  type: LoadBalancer
```
This example consists of a Deployment and a Service. The Deployment manages three replicas of a container named "forge," which runs the "forge:latest" image. The Service exposes the Deployment on port 80 using a LoadBalancer type. Both the Deployment and the Service use readiness and liveness probes to ensure their health and readiness to serve.
