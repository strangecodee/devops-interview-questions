 # Kubernetes Concept
Deployment is a type of Kubernetes resource that creates and manages containerized applications. It ensures a specified number of replicas are running and available, automatically restarts containers that fail, and updates containers when new images are available.

# Explanation
The Deployment resource in Kubernetes creates and manages instances of a containerized application. It maintains the desired state by creating or removing replicas as needed. Kubernetes continually rolls out updates to replicas to minimize downtime and ensures high availability through readiness and liveness probes.

# Best Practices
- Use rolling updates for minimal downtime and zero-downtime updates.
- Define resource limits and requests to maintain resource usage efficiency.
- Use readiness and liveness probes to ensure applications are ready and healthy.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:latest
        ports:
        - containerPort: 8080
          name: http
        readinessProbe:
          httpGet:
            path: /health
            port: 8080
        livenessProbe:
          httpGet:
            path: /liveness
            port: 8080
```
