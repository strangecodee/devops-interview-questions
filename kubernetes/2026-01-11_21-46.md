 # Kubernetes Concept
This is an example of a Kubernetes DaemonSet for running a log processing agent called `nebula-agent` with automatic node scaling based on CPU utilization.

# Explanation
A DaemonSet ensures that a specific number of replicas of a Pod are running on all nodes in a cluster. In this case, we'll use it to manage the `nebula-agent` Pods. The `nebula-agent` is designed to process and analyze log data in real-time for our organization's infrastructure. By using the DaemonSet, we ensure that each node has an instance of this agent running, thus providing a uniform log processing solution across the entire cluster.

To improve scalability, we'll set up a Horizontal Pod Autoscaler (HPA) that scales the number of replicas based on CPU utilization. This way, when nodes join or leave the cluster, or when the workload increases, the DaemonSet automatically adjusts the number of replicas to maintain optimal performance and resource usage.

# Best Practices
- Use labels consistently to manage and identify your DaemonSets and their associated Pods.
- Implement resource limits to prevent container contention and ensure fair resource usage within the cluster.
- Regularly review and update your DaemonSets to ensure they're running with the latest container images and configurations.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: nebula-daemonset
spec:
  selector:
    matchLabels:
      app: nebula
      role: agent
  template:
    metadata:
      labels:
        app: nebula
        role: agent
    spec:
      containers:
        - name: nebula-agent
          image: nebula/nebula-agent:latest
          resources:
            limits:
              cpu: "1"
              memory: "512Mi"
            requests:
              cpu: "0.5"
              memory: "256Mi"
          ports:
            - containerPort: 8080
          livenessProbe:
            httpGet:
              path: /healthz
              port: 8080
          readinessProbe:
            httpGet:
              path: /healthz
              port: 8080
---
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler
metadata:
  name: nebula-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: DaemonSet
    name: nebula-daemonset
  minReplicas: 1
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        averageUtilization: 50
```
This YAML example consists of a DaemonSet for running the `nebula-agent` container and a Horizontal Pod Autoscaler to manage the number of replicas based on CPU utilization. The example includes appropriate labels, container resources, and probes for ensuring a healthy and efficient deployment.
