 # Kubernetes Concept
Deployment is a Kubernetes object used for creating and managing containerized applications. It ensures a specified number of replicas are running and replacing the unhealthy ones.

# Explanation
A Kubernetes Deployment is used for declarative management of applications by creating and updating replicas of containerized applications. It provides a way to ensure a specific number of replicas are running and scaling the application accordingly. Deployments also support rolling updates and rollbacks to manage application updates and manage risk.

# Best Practices
- Use rolling updates with a suitable update strategy to minimize downtime and ensure smooth application updates.
- Use readiness and liveness probes to ensure the application is ready to receive traffic and to automatically restart unhealthy replicas.
- Use resource limits and requests to ensure the application runs efficiently and does not consume more resources than required.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:latest
        ports:
        - containerPort: 80
        readinessProbe:
          probes:
          - exec:
              command: ["nc", "-z", "--wait", "localhost", "80"]
              intervalSeconds: 5
          timeoutSeconds: 3
        livenessProbe:
          probes:
          - exec:
              command: ["nc", "-z", "--wait", "localhost", "80"]
              intervalSeconds: 15
              timeoutSeconds: 3
```
