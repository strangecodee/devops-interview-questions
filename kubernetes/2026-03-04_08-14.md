 # Kubernetes Concept
This is an example of a Kubernetes Deployment for a monitoring application using Prometheus as a probe.

# Explanation
A Deployment in Kubernetes is used to create and manage applications. In this example, we will create a Deployment for Prometheus, an open-source monitoring system. We will use a Probe to ensure the Prometheus server is running and healthy.

# Best Practices
- Use `replicas: 3` to ensure high availability of the monitoring system.
- Configure horizontal pod autoscaling based on resource usage.
- Use `imagePullSecrets` to securely pull container images from a registry.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: monitoring-prometheus
spec:
  selector:
    matchLabels:
      app: prometheus
  replicas: 3
  template:
    metadata:
      labels:
        app: prometheus
    spec:
      containers:
      - name: prometheus
        image: prom/prometheus:v2.31.0
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 9090
      probes:
      - livenessProbe:
          httpGet:
            path: /
            port: 9090
          initialDelaySeconds: 15
          periodSeconds: 5
      imagePullSecrets:
      - name: registry-secret
```
