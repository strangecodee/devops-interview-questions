 # Kubernetes Concept
This example demonstrates a Kubernetes `DaemonSet` configuration for running the Chaos Mesh `chaos-agent` pod as a daemon set in the cluster for chaos engineering purposes.

# Explanation
A `DaemonSet` ensures that a specified number of replicas of a pod are running on each node in the cluster. In this case, we want to run the `chaos-agent` pod as a daemon set to apply chaos engineering experiments at the node level. This allows us to test and identify potential issues at the infrastructure level.

# Best Practices
- Ensure you have the [Chaos Mesh](https://chaos.link/) installed and configured in your Kubernetes cluster.
- Configure the `chaos-agent` to use a dedicated namespace for running the experiments.
- Set the `replicas` to the desired number of pods per node.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: chaos-agent
  namespace: chaos-mesh
  labels:
    app: chaos-agent
spec:
  selector:
    matchLabels:
      app: chaos-agent
  template:
    metadata:
      labels:
        app: chaos-agent
    spec:
      containers:
      - name: chaos-agent
        image: chaos-mesh/chaos-agent:0.11.2
        ports:
        - containerPort: 8080
          name: chaos-agent
        - containerPort: 10250
          name: chaos-agent-grpc
        livenessProbe:
          exec:
            command:
              - /bin/sh
              - -c
              - "curl --fail --silent --head --max-time 1s http://localhost:8080/health || exit 1"
          intervalSeconds: 30
        readinessProbe:
          exec:
            command:
              - /bin/sh
              - -c
              - "curl --fail --silent --head --max-time 1s http://localhost:8080/health || exit 1"
          intervalSeconds: 15
      replicas: 1
```
This YAML file defines a Kubernetes `DaemonSet` named `chaos-agent` running in the `chaos-mesh` namespace. The `spec.template.spec.containers` section defines the `chaos-agent` container with the required ports and probes. The `spec.template.spec.replicas` sets the number of replicas to 1 per node.
