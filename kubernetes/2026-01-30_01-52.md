 # Kubernetes Concept
This YAML example demonstrates a Deployment and a related Service for a simple application using Kubernetes.

# Explanation
A Deployment in Kubernetes manages the rollout and scaling of containerized applications. It ensures that a specified number of replicas are running at any given time, and automates the process of updating the application with new versions. A Service provides a stable network identity and endpoints for the Deployment.

# Best Practices
- Use `labels` to easily identify and manage your deployments and services.
- Use `replicas` to ensure high availability and scalability.
- Configure `livenessProbes` and `readinessProbes` to monitor the application's health and readiness.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
          initialDelaySeconds: 15
          periodSeconds: 5
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
          initialDelaySeconds: 15
          periodSeconds: 5
---
apiVersion: v1
kind: Service
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  ports:
  - port: 80
    targetPort: 80
  type: ClusterIP
```
