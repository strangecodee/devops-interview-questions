 # Kubernetes Concept
This is an example of a Kubernetes Deployment for a simple Node.js application using a Docker image.

# Explanation
A Deployment in Kubernetes is used to create and manage replicas of a desired state for a Pod. In this example, we define a Deployment that will ensure a specified number of replicas of our Node.js application are running in the cluster. The Kubernetes controller will ensure that the number of replicas matches the desired count, replacing any replicas that fail or become unhealthy.

# Best Practices
- Use a rolling update strategy to minimize downtime when updating the application.
- Set up a health check using a LivenessProbe and a ReadinessProbe to ensure the application is running correctly.
- Use labels to selectively target and manage pods based on specific criteria.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nodejs-deployment
  labels:
    app: nodejs
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nodejs
  template:
    metadata:
      labels:
        app: nodejs
    spec:
      containers:
      - name: nodejs
        image: myregistry/nodejs:latest
        ports:
        - containerPort: 8080
        env:
        - name: NODE_ENV
          value: production
        livenessProbe:
          httpGet:
            path: /healthz
            port: 8080
          initialDelaySeconds: 15
          periodSeconds: 5
        readinessProbe:
          httpGet:
            path: /ready
            port: 8080
          initialDelaySeconds: 15
          periodSeconds: 5
```
