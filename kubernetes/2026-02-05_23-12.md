 # Kubernetes Concept: Kubernetes Pod Security Policies (PSPs)
Secure access control for containers in Kubernetes by defining and enforcing Pod Security Policies.

# Explanation
Pod Security Policies define a set of rules that control what containers are allowed to do based on their security context. These rules can restrict capabilities, SELinux context, and other security-related features to help prevent potential security vulnerabilities. PSPs are optional and should be used to increase the overall security posture of your Kubernetes clusters.

# Best Practices
- Create a base PSP with minimal restrictions for non-sensitive workloads.
- Define additional, more restrictive PSPs for sensitive workloads.
- Regularly review and update your PSPs as new threats emerge.

# YAML Example: Base Pod Security Policy
apiVersion: security.k8s.io/v1beta1
kind: PodSecurityPolicy
metadata:
  name: base-psp
spec:
  allowPrivilegeEscalation: false
  seLinux:
    rule: RunAsAny
  supplementalGroups:
    rule: RunAsAny
  runAsUser:
    rule: RunAsAny
  fsGroup:
    rule: RunAsAny
  net:
    pod:
      allowedCPUs: [0-100]
      allowedMem: [512Mi, 2Gi]
      ports:
      - containerPort: 80
      - containerPort: 443
      - containerPort: 22
      podNetworkPolicies: []
      allowedProtocols: ["TCP", "UDP"]
      hostNetwork: false
      hostPorts: []
      hostIPC: false
  volumes: []
  seLinux:
    rule: RunAsAny
  readOnlyRootFilesystem: false
  privileged: false
  usernsMode: "Hard"
  activeSecurityContext:
    fsGroup: 1000
    runAsGroup: 1000
    runAsUser: 1000
  hostSelinux:
    type: "Permissive"
  audit:
    logSubresourceRequest: true
    logEvents:
    - type: "ContainerImagePull"
      message: '{"message":"Container image \'%{imageName}\' for container \'%{containerName}\' in pod \'%{podName}\' pulled"}'
    - type: "ContainerImagePullFailure"
      message: '{"message":"Failed to pull image \'%{imageName}\' for container \'%{containerName}\' in pod \'%{podName}\'"}'
    - type: "ContainerImageLoad"
      message: '{"message":"Container image \'%{imageName}\' loaded"}'
    - type: "ContainerCreate"
      message: '{"message":"Container \'%{containerName}\' in pod \'%{podName}\' created"}'
    - type: "ContainerDelete"
      message: '{"message":"Container \'%{containerName}\' in pod \'%{podName}\' deleted"}'
    - type: "ContainerRuntimeStart"
      message: '{"message":"Container runtime for container \'%{containerName}\' in pod \'%{podName}\' started"}'
    - type: "ContainerRuntimeStop"
      message: '{"message":"Container runtime for container \'%{containerName}\' in pod \'%{podName}\' stopped"}'
    - type: "KubeletEvent"
      message: '{"message":"Kubelet event for pod \'%{podName}\' - %{eventType}"}'
    - type: "PodScheduled"
      message: '{"message":"Pod \'%{podName}\' scheduled on node \'%{nodeName}\'"}'
    - type: "PodStarted"
      message: '{"message":"Pod \'%{podName}\' started"}'
    - type: "PodStopped"
      message: '{"message":"Pod \'%{podName}\' stopped"}'
    - type: "ContainerLog"
      message: '{"message":"Container log for container \'%{containerName}\' in pod \'%{podName}\': %{message}"}'
    - type: "ContainerLogRotation"
      message: '{"message":"Container log for container \'%{containerName}\' in pod \'%{podName}\' rotated"}'
    - type: "ContainerCrash"
      message: '{"message":"Container \'%{containerName}\' in pod \'%{podName}\' crashed"}'
  restrictAdmins: false
  defaultAllowPrivileges: []
  seLinuxOptions: {}
  enable: true
