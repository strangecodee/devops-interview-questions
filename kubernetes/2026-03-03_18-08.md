 # Kubernetes Concept
Kubernetes DaemonSet is a deployment type to ensure a specified number of replicas are running and scheduled on each node in the cluster.

# Explanation
A DaemonSet ensures that all or a specific number of nodes run a pod with the same label selectors. It's useful for deploying system daemons or services that need to run on all nodes in the cluster. In case a node is drained or recreated, the DaemonSet will automatically create a new pod on the node.

# Best Practices
- Use DaemonSets for essential services that need to run on every node.
- Deploy a rolling update strategy to minimize downtime.
- Implement liveness and readiness probes to monitor and manage the health of the pods.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: my-daemonset
spec:
  selector:
    matchLabels:
      app: my-daemon
  template:
    metadata:
      labels:
        app: my-daemon
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
        livenessProbe:
          exec:
            command: ["/usr/local/bin/check-health.sh"]
          periodSeconds: 15
        readinessProbe:
          exec:
            command: ["/usr/local/bin/check-readiness.sh"]
          periodSeconds: 5
```
