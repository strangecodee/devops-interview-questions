 # Kubernetes Deployment
Create and manage containerized applications in a cluster.

# Explanation
A Kubernetes Deployment manages the lifecycle of a set of replica Pods, creating new instances as needed to maintain the desired state. It provides rolling updates and rolling back, as well as automatic rollouts and rollbacks based on user-defined conditions.

# Best Practices
- Use rolling updates to minimize downtime and ensure a smooth transition between versions.
- Define resource limits and requests for controlled resource utilization.
- Implement readiness and liveness probes for efficient scaling and error handling.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  selector:
    matchLabels:
      app: my-app
  replicas: 3
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
      imagePullSecrets:
      - name: my-secret
      readinessProbes:
      - probe:
          exec:
            command: ["/app/healthcheck.sh"]
          intervalSeconds: 5
      livenessProbes:
      - probe:
          exec:
            command: ["/app/liveness.sh"]
          intervalSeconds: 15
      resources:
        limits:
          cpu: "0.5"
          memory: "512Mi"
        requests:
          cpu: "250m"
          memory: "256Mi"
```
