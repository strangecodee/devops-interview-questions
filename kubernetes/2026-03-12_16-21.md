 # Kubernetes Concept: Deployment
Creates and manages the rollout and scaling of containerized applications.

# Explanation
Deployments in Kubernetes handle creating and updating containerized applications by managing the desired state of a set of pods, providing automatic rollouts, rollbacks, and self-healing.

# Best Practices
- Use labels for selectors to identify and manage groups of pods.
- Use rolling updates for updating applications with minimal downtime.
- Implement liveness and readiness probes for monitoring the health of your containers.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
  labels:
    app: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-app:latest
        ports:
        - containerPort: 80
      livenessProbe:
        httpGet:
          path: /healthz
          port: 80
      readinessProbe:
        httpGet:
          path: /ready
          port: 80
```
