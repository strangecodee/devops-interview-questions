 # Kubernetes Concept
This example demonstrates a Kubernetes Service of type LoadBalancer for a Deployment named "nebula-web" using a YAML manifest.

# Explanation
A Kubernetes Service of type LoadBalancer provides an external IP to access a set of pods in a cluster. In this example, the "nebula-web" Deployment consists of multiple replicas, and the Service routes incoming traffic to one of the available pods.

# Best Practices
- Use a Service of type LoadBalancer when you need an external IP to access your application.
- Set up appropriate labels for your pods to ensure they are correctly targeted by the Service.
- Monitor and scale your Deployment using Kubernetes Horizontal Pod Autoscaler for optimal performance and availability.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula-web
  labels:
    app: nebula
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula
        image: nebula/web:latest
        ports:
        - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: nebula-web
spec:
  type: LoadBalancer
  ports:
  - port: 80
    targetPort: 80
  selector:
    app: nebula
```
