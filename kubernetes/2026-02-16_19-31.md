 # Kubernetes Concept
This is an example of a Kubernetes Deployment for a simple Node.js application using an Eclipse Java EE web container, WAKFU OpenJDK, deployed on Amazon Elastic Kubernetes Service (EKS).

# Explanation
A Kubernetes Deployment is the primary means of deploying and managing containerized applications on a Kubernetes cluster. In this example, we will create a Kubernetes deployment that runs an Eclipse Java EE web application in a container using WAKFU OpenJDK. This deployment will be managed by Amazon Elastic Kubernetes Service (EKS), which simplifies the process of managing a Kubernetes environment on AWS.

# Best Practices
- Use a container image with a small base image to minimize the attack surface.
- Configure the container to use the latest security patches.
- Use a secret to store and manage sensitive information, such as database credentials.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nodejs-app
spec:
  replicas: 1
  selector:
    matchLabels:
      app: nodejs
  template:
    metadata:
      labels:
        app: nodejs
    spec:
      containers:
      - name: nodejs
        image: eclipse-openj9:alpine-jre11-openj9-jre-headless
        ports:
        - containerPort: 8080
        env:
        - name: JAVA_OPTS
          value: -XX:MaxPermSize=256m -XX:MaxHeapFreeRatio=70 -XX:MinHeapFreeRatio=40
        readinessProbe:
          probes:
          - exec:
              command: ["/bin/sh", "-c", "nc -z 0.0.0.0 8080 < /dev/null"]
              intervalSeconds: 5
            timeoutSeconds: 2
---
apiVersion: v1
kind: Service
metadata:
  name: nodejs-app
spec:
  selector:
    app: nodejs
  ports:
  - port: 80
    targetPort: 8080
  type: LoadBalancer
```
This YAML example defines a Kubernetes Deployment for a Node.js application running in a container based on Eclipse OpenJDK. It also includes a Kubernetes Service that exposes the application on port 80 using a LoadBalancer.

The deployment uses a single replica and is configured to use the `eclipse-openj9:alpine-jre11-openj9-jre-headless` container image, which is based on Alpine Linux and includes OpenJDK 11. Environment variables are set to configure the JVM memory settings. The readiness probe is used to check if the application is ready to receive traffic. The Kubernetes Service exposes the application on port 80 using a LoadBalancer to distribute traffic.
