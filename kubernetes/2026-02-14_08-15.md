 # Kubernetes Concept
Deployment is a Kubernetes object used for deploying and managing containerized applications. It ensures availability, scalability, and rollbacks.

# Explanation
A Deployment creates and manages replicas of a specified Pod template. It rolls out updates following a rollout strategy, such as blue-green or canary, and supports progressive delivery. It also offers automated rollbacks in case of failures or user intervention.

# Best Practices
- Use Rolling updates for minimum downtime.
- Set up a Deployment strategy (Blue-Green or Canary) for smooth updates.
- Monitor health with Liveness and Readiness probes.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  selector:
    matchLabels:
      app: nginx
  replicas: 3
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
        livenessProbe:
          httpGet:
            path: /
            port: 80
        readinessProbe:
          httpGet:
            path: /
            port: 80
```
