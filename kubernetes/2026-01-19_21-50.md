 # Kubernetes Concept
Kubernetes DaemonSet is a type of Kubernetes deployment that ensures a copy of the specified Pod is running on all nodes in the cluster.

# Explanation
A DaemonSet creates and manages a set of Pods, one per node in the cluster by default, ensuring that each node runs a specified number of replicas of a given Pod. DaemonSets are useful for deploying system components or daemons that require access to the node's resources and should run as close as possible to the pod's nodes.

# Best Practices
- Use DaemonSets for critical applications or system components that require consistent availability and access to specific node resources.
- Configure readiness and liveness probes to ensure the DaemonSet's stability and availability.
- Use labels to manage and target specific nodes or node labels.

# YAML Example
---
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: my-daemonset
  labels:
    app: my-daemonset
spec:
  selector:
    matchLabels:
      app: my-daemonset
  template:
    metadata:
      labels:
        app: my-daemonset
    spec:
      containers:
      - name: my-daemon-container
        image: my-image:latest
        ports:
        - containerPort: 80
        readinessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
        livenessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:80/ || exit 1"]
          initialDelaySeconds: 30
          periodSeconds: 30
---
