 # Kubernetes Concept
Deployment is a type of Kubernetes resource for creating and updating replicas of a container application.

# Explanation
A Deployment in Kubernetes manages the lifecycle of a set of pods, creating new replicas as needed to maintain the specified number of available instances. It also provides rolling updates and rollbacks, ensuring high availability and minimal downtime.

# Best Practices
- Use `replicas: 3` for high availability
- Use `strategy.type: RollingUpdate` for rolling updates
- Use `strategy.rollingUpdate.maxSurge: 1` and `strategy.rollingUpdate.maxUnavailable: 1` for smooth updates

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
spec:
  selector:
    matchLabels:
      app: phoenix
  replicas: 3
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 1
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: example/phoenix:latest
        ports:
        - containerPort: 8080
```
