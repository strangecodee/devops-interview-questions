 # Kubernetes Concept
Kubernetes DaemonSet is a type of Kubernetes deployment that ensures a copy of the specified pod is running on all nodes in the cluster.

# Explanation
DaemonSets are particularly useful for deploying system daemons, as they ensure each node runs a consistent set of daemons. They create and manage a pod for each node in the cluster, and if a pod goes down, they automatically create a new one.

# Best Practices
- Use DaemonSets for critical system services that need to run on all nodes in the cluster.
- Configure DaemonSets to use a rolling update strategy with minimal downtime.
- Use labels effectively to manage DaemonSets and target specific nodes.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: nebula-daemonset
spec:
  selector:
    matchLabels:
      app: nebula
      tier: daemon
  template:
    metadata:
      labels:
        app: nebula
        tier: daemon
    spec:
      containers:
      - name: nebula
        image: nebula:latest
        ports:
        - containerPort: 12345
          protocol: TCP
        readinessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl -f http://localhost:12345/healthz || exit 1"]
            intervalSeconds: 5
            timeoutSeconds: 2
```
This DaemonSet deploys a container named "nebula" on every node in the cluster, with the specified label "app: nebula" and "tier: daemon". The container runs on port 12345 and uses a readiness probe to ensure the container is healthy before it is considered ready to receive traffic.
