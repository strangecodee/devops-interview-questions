 # Kubernetes Concept
This example demonstrates a Kubernetes Deployment for a scalable application named "nebula" utilizing Horizontal Pod Autoscaling (HPA).

# Explanation
The Kubernetes Deployment creates and manages a set of replicas of the "nebula" application. HPA automatically scales the number of replicas based on observed CPU utilization. This ensures the application can handle increased load efficiently.

# Best Practices
- Practically set up resource limits and requests for the containers to avoid container starvation and improve the overall cluster resource management.
- Monitor the application's performance using appropriate tools such as Prometheus or Grafana.
- Implement rolling updates to minimize downtime when deploying new versions.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nebula
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nebula
  template:
    metadata:
      labels:
        app: nebula
    spec:
      containers:
      - name: nebula
        image: nebula:latest
        ports:
        - containerPort: 80
        resources:
          limits:
            cpu: "1"
            memory: "512Mi"
          requests:
            cpu: "500m"
            memory: "256Mi"
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
---
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler
metadata:
  name: nebula
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: nebula
  minReplicas: 3
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 50
```
