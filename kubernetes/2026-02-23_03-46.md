 # Kubernetes Concept
This example demonstrates a Helm chart for deploying a Phoenix application on a Kubernetes cluster.

# Explanation
Helm is a popular package manager for Kubernetes, and this chart streamlines the process of deploying a Phoenix application with its dependencies, such as PostgreSQL and Elixir, onto a Kubernetes cluster. This example utilizes the official Phoenix Helm chart from the Elixir-lang community.

# Best Practices
- Ensure your Kubernetes cluster has the required dependencies installed, such as Helm and the Elixir-lang Helm repository.
- Use environment variables to configure application settings, enabling easy customization.
- Ensure proper resource allocation (CPU, memory) to maintain application performance.

# YAML Example
```yaml
apiVersion: v2
name: phoenix-chart
version: 0.1.0
description: A Helm chart for deploying a Phoenix application on Kubernetes

values:
  # Configure application settings using environment variables
  replicaCount: 1
  image:
    repository: elixir-lang/phoenix
    tag: latest
  service:
    name: phoenix
    externalPort: 4000
    targetPort: 4000
    type: ClusterIP

  postgres:
    image:
      repository: postgres
      tag: latest
    service:
      name: postgres
      externalPort: 5432
      targetPort: 5432
      type: ClusterIP

  elixir:
    image:
      repository: elixir
      tag: latest
    service:
      name: elixir
      externalPort: 8000
      targetPort: 8000
      type: ClusterIP

  deploy:
    replicas: ${replicaCount}
    selector:
      matchLabels:
        app: phoenix
    template:
      metadata:
        labels:
          app: phoenix
      spec:
        containers:
          - name: phoenix
            image: "${values.image.repository}:${values.image.tag}"
            ports:
              - containerPort: ${values.service.targetPort}
                protocol: TCP
                name: http
            env:
              - name: DB_HOST
                value: ${values.postgres.service.name}
              - name: DB_PORT
                value: ${values.postgres.service.externalPort}
              - name: DB_NAME
                value: myapp
              - name: DB_USER
                value: myuser
              - name: DB_PASS
                value: mypass
            volumeMounts:
              - name: elixir-volume
                mountPath: /app/elixir
              - name: phoenix-volume
                mountPath: /app/phoenix
          - name: elixir
            image: "${values.elixir.image.repository}:${values.elixir.image.tag}"
            volumeMounts:
              - name: elixir-volume
                mountPath: /elixir
        volumes:
          - name: elixir-volume
            persistentVolumeClaim:
              claimName: elixir-pvc
          - name: phoenix-volume
            persistentVolumeClaim:
              claimName: phoenix-pvc
```
This YAML file defines a Helm chart for deploying a Phoenix application on Kubernetes. It includes configurations for the Phoenix, Elixir, and PostgreSQL containers, along with their respective services and persistent volume claims.
