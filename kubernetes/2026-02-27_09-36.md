 # Kubernetes Concept
This Kubernetes YAML example demonstrates a Chaos Engineering approach using a `Kubernetes DaemonSet` for running ` Chaos-T` Vector141 agent pods across the entire cluster.

# Explanation
Chaos Engineering is a practice that aims to build confidence in a system's capability to withstand turbulent conditions in production. By intentionally injecting failure and observing the response, we improve our resilience and prepare for potential future disruptions. DaemonSets ensure that a specified number of replicas run on each node in the cluster, making it ideal for deploying critical services like Chaos-T.

# Best Practices
- Use a separate namespace for Chaos Engineering activities to maintain isolation and prevent unintended consequences.
- Monitor and manage Chaos Engineering experiments through a dedicated platform or tooling.
- Regularly review and update your chaos experiments to ensure they remain effective.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: chaos-daemonset
  namespace: chaos-engineering
spec:
  selector:
    matchLabels:
      app: chaos-t
  template:
    metadata:
      labels:
        app: chaos-t
    spec:
      containers:
      - name: chaos-t
        image: chaos-tools/chaostest:0.13.0
        args:
        - "--logtostderr"
        ports:
        - containerPort: 8080
          name: http
          protocol: TCP
          nodePort: 30001
        readinessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:8080/ready || exit 1"]
            intervalSeconds: 5
        livenessProbes:
        - exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:8080/ready || exit 1"]
            intervalSeconds: 30
```
In this YAML example, we create a DaemonSet named `chaos-daemonset` that deploys `Chaos-T` agent pods across the entire `chaos-engineering` namespace. The agent listens on nodePort 30001 for incoming chaos experiments and runs readiness and liveness probes to ensure the container is ready and running as expected.
