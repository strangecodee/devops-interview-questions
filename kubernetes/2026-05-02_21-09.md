# Kubernetes Concept
Kubernetes DaemonSet is a way to ensure a copy of a pod runs on all nodes in a cluster.

# Explanation
DaemonSets maintain a consistent daemon process on all nodes in the cluster, ensuring high availability and reducing the risk of data loss. They are often used for services like logging, monitoring, or cluster management.

# Best Practices
- Use read-only file systems for DaemonSets that don't write data to persistent storage.
- Restrict DaemonSets to specific nodes using node selectors.
- Use a rolling update strategy to minimize downtime.

# YAML Example
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: log-daemonset
  labels:
    app: log-daemonset
spec:
  selector:
    matchLabels:
      app: log-daemonset
  template:
    metadata:
      labels:
        app: log-daemonset
    spec:
      containers:
      - name: log-container
        image: my-log-image:latest
        securityContext:
          runAsUser: 1001
          fsGroup: 5000
        ports:
        - containerPort: 514
        readinessProbes:
        - exec:
            command: ["/usr/local/bin/check-log-ready.sh"]
        livenessProbes:
        - exec:
            command: ["/usr/local/bin/check-log-alive.sh"]
      nodeselector:
        beta.kubernetes.io/os: linux
      tolerations:
      - key: node.kubernetes.io/not-ready
        operator: Exists
        effect: NoExecute
      - key: node.kubernetes.io/unreachable
        operator: Exists
        effect: NoExecute
