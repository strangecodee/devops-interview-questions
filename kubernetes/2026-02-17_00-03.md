 # Kubernetes Concept
This YAML example demonstrates a Monitoring DaemonSet for Prometheus, a popular open-source monitoring system for containers.

# Explanation
The DaemonSet ensures that a specified number of replicas of a pod run on each node in the cluster. In this case, it will ensure that a Prometheus monitoring instance runs on each node. The containers are managed and updated using the Kubernetes rollout strategy.

# Best Practices
- Use `node-selector` in the DaemonSet to ensure that the pods are scheduled on specific nodes.
- Set resource limits and requests to ensure that the Prometheus containers receive adequate resources.
- Use `livenessProbe` and `readinessProbe` to monitor the health and readiness of the Prometheus containers.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: prometheus-monitoring
spec:
  selector:
    matchLabels:
      app: prometheus
  template:
    metadata:
      labels:
        app: prometheus
    spec:
      nodeSelector:
        beta.kubernetes.io/os: linux
      containers:
      - name: prometheus
        image: quay.io/prometheus/prometheus:v2.31.0
        ports:
        - containerPort: 9090
        resources:
          limits:
            cpu: '0.5'
            memory: '512Mi'
          requests:
            cpu: '250m'
            memory: '256Mi'
        volumeMounts:
        - name: prometheus-storage
          mountPath: /prometheus
          subPath: prometheus
        livenessProbe:
          exec:
            command: ["/bin/sh", "/usr/local/bin/prometheus-reloader.sh", "/etc/prometheus/prometheus.yml"]
          initialDelaySeconds: 30s
          periodSeconds: 15s
        readinessProbe:
          exec:
            command: ["/bin/sh", "-c", "curl --fail http://localhost:9090/api/v1/query?query=up || exit 1"]
          initialDelaySeconds: 30s
          periodSeconds: 15s
      volumes:
      - name: prometheus-storage
        persistentVolumeClaim:
          claimName: prometheus-pvc
```
This YAML example uses the Prometheus container image with version `v2.31.0`, sets resource limits and requests, and includes both a liveness probe and a readiness probe. The `nodeSelector` ensures that the pods are scheduled on Linux nodes. The `persistentVolumeClaim` named `prometheus-pvc` is used for persistent storage.
