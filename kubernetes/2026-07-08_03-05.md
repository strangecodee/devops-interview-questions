 # Kubernetes Concept
Kubernetes Secret is an object used to store and manage sensitive information such as passwords, OAuth tokens, and SSL certificates.

# Explanation
Secrets in Kubernetes are encrypted at rest and decrypted only when they are used. This ensures the confidentiality of sensitive data. The Kubernetes Secret is defined using a YAML manifest file that includes the data in base64-encoded format.

# Best Practices
- Create a separate namespace for storing secrets.
- Use Kubernetes RBAC to restrict access to secrets.
- Rotate secrets periodically to maintain security.

# YAML Example
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: my-secret
  namespace: my-namespace
data:
  username: cGFzc3dvcmQ=
  password: cGFzc3dvcmQ=
```
This YAML example defines a Kubernetes Secret named "my-secret" in the "my-namespace" namespace. The Secret contains two base64-encoded strings, "cGFzc3dvcmQ=" decodes to "admin" for the username and "cGFzc3dvcmQ=" decodes to "password123" for the password.
