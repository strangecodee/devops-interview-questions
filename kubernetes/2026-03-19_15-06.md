 # Kubernetes Deployment
A Kubernetes Deployment creates and manages containerized applications.

# Explanation
Deployments maintain availability and roll out updates for your applications. They ensure that a specified number of replicas are running at any given time. Deployments provide features like rolling updates, rollbacks, and self-healing.

# Best Practices
- Use a single container per Deployment for simplicity and easier management.
- Set up the desired number of replicas and let Kubernetes ensure high availability.
- Monitor and configure resource limits and requests to maintain optimal performance and prevent resource exhaustion.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
  labels:
    app: my-app
spec:
  selector:
    matchLabels:
      app: my-app
  replicas: 3
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: my-registry/my-image:latest
        ports:
        - containerPort: 80
          name: http
        env:
        - name: MY_ENV_VAR
          value: "My Value"
        livenessProbe:
          httpGet:
            path: /healthz
            port: 80
        readinessProbe:
          httpGet:
            path: /ready
            port: 80
---
kind: Service
apiVersion: v1
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  ports:
  - port: 80
    targetPort: 80
  type: ClusterIP
```
