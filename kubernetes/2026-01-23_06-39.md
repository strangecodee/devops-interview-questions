 # Kubernetes Concept
This is an example of a Kubernetes `Service` configuration for a simple web application using a `LoadBalancer` type service for external access.

# Explanation
A Kubernetes `Service` acts as a stable, global load balancer and DNS name for a set of pods. In this example, we define a `LoadBalancer` type service to expose the web application to external traffic. Kubernetes automatically creates and manages the load balancer for us.

# Best Practices
- Configure `Service` selector to target only the desired pods.
- Set appropriate `Service` ports and target ports.
- Use `externalTrafficPolicy` to control external traffic flow.

# YAML Example
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-webapp
  labels:
    app: my-webapp
spec:
  selector:
    app: my-webapp
  ports:
    - name: http
      port: 80
      targetPort: 8080
  type: LoadBalancer
```
