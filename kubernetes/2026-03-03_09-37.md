 # Kubernetes Concept
Deployment is a Kubernetes object used to roll out and manage containerized applications.

# Explanation
A Deployment creates and manages replicas of a containerized application, ensuring a specified number of replicas are running at any given time. It also provides a way to update or roll back an application by updating the image tag in the YAML manifest.

# Best Practices
- Use rolling updates to minimize downtime.
- Set up a readiness and liveness probe to check application health.
- Use labels for easy identification and scaling.

# YAML Example
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: phoenix-deployment
  labels:
    app: phoenix
spec:
  replicas: 3
  selector:
    matchLabels:
      app: phoenix
  template:
    metadata:
      labels:
        app: phoenix
    spec:
      containers:
      - name: phoenix
        image: myregistry/phoenix:latest
        ports:
        - containerPort: 8080
          protocol: TCP
      readinessProbe:
        tcpSocket:
          port: 8080
      livenessProbe:
        httpGet:
          path: /health
          port: 8080
```
