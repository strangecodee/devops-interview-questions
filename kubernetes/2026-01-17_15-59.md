 # Kubernetes Concept
Kubernetes DaemonSet is a type of Kubernetes deployment that ensures a copy of the specified Pod is running on all nodes in the cluster.

# Explanation
DaemonSets are particularly useful for running system daemons that require access to specific node resources or need to be running on all nodes for the cluster's functionality. In case of a node failure, DaemonSets automatically create a new Pod on a replacement node.

# Best Practices
- Set up proper labels and selectors for DaemonSets to ensure they are only deployed on the intended nodes.
- Ensure readiness and liveness probes are properly configured for the container in the DaemonSet.
- Keep container images up-to-date by using an automated update strategy or rolling updates.

# YAML Example
```yaml
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: my-daemonset
spec:
  selector:
    matchLabels:
      app: my-daemon-app
  template:
    metadata:
      labels:
        app: my-daemon-app
    spec:
      containers:
      - name: my-container
        image: my-image:latest
        ports:
        - containerPort: 80
        readinessProbes:
        - probe:
            exec:
              command: ["/usr/local/bin/check-readiness.sh"]
            intervalSeconds: 5
            failureThreshold: 3
        livenessProbes:
        - probe:
            exec:
              command: ["/usr/local/bin/check-liveness.sh"]
            intervalSeconds: 30
            failureThreshold: 3
```
